O Linkzee funciona com **qualquer agente compatível com MCP**, não só o Claude.
Se a sua ferramenta tem suporte a MCP, você pode conectá-la ao Linkzee e
gerenciar sua página em linguagem natural: **ChatGPT**, **Cursor**, ferramentas
de automação e muito mais.

## Conecte o seu cliente

<Steps>
  <Step title="Crie uma chave de API">
    No seu painel, abra **Configurações**, **API e MCP**, e crie uma chave de API.
    Escolha **write** se o agente vai alterar sua página (ela também lê), ou
    **read** para um agente só de leitura. Veja [Chaves de API](/pt-BR/integrations/api/api-keys)
    para o passo a passo completo.
  </Step>
  <Step title="Adicione um servidor MCP">
    No seu cliente, adicione um novo servidor MCP (Streamable HTTP) apontando para:

    ```
    https://api.linkz.ee/mcp
    ```
  </Step>
  <Step title="Informe a sua chave de API">
    Envie a sua chave no cabeçalho de autorização:

    ```
    Authorization: Bearer lzk_your_key
    ```

    Em clientes configurados por JSON, o bloco costuma ficar assim:

    ```json
    {
      "mcpServers": {
        "linkzee": {
          "type": "http",
          "url": "https://api.linkz.ee/mcp",
          "headers": { "Authorization": "Bearer lzk_your_key" }
        }
      }
    }
    ```
  </Step>
  <Step title="Peça em linguagem natural">
    Depois de conectado, converse com o seu agente como você conversaria com um
    assistente: "adiciona esse produto", "o que está agendado esta semana?" ou
    "muda o meu tema".
  </Step>
</Steps>

<Note>
  Cada cliente adiciona servidores MCP de um jeito um pouco diferente. Consulte a
  documentação do próprio cliente para saber onde colar o endpoint e o
  cabeçalho. Entrar com a sua conta Linkzee (OAuth), sem chave, funciona com o
  conector do Claude e com apps que rodam no seu próprio computador. Outros
  clientes hospedados usam uma chave de API.
</Note>

## Envio de fotos e vídeos

Muitos apps de chat mostram seus anexos ao modelo, mas não entregam o arquivo às
ferramentas. Quando o agente não tem uma URL pública para uma foto ou vídeo, ele
usa um **link de envio**:

1. O agente chama `create_upload_link` e passa para você uma página como
   `https://linkz.ee/u/...`.
2. Você abre no celular ou no computador e escolhe os arquivos (até 10; fotos de
   até 8 MB, vídeos de até 40 MB). O link fica aberto por 15 minutos.
3. Você avisa o agente que terminou. Ele lê os arquivos com `get_upload` e usa
   cada `uploadId` no lugar certo da sua página.

Agentes que rodam com acesso a arquivos (Cursor, scripts, automações) também
podem enviar os arquivos direto para o mesmo link. Quando uma foto já está
online, o agente só passa a URL pública dela. Veja [Envio de arquivos](/pt-BR/integrations/mcp/sending-files).
