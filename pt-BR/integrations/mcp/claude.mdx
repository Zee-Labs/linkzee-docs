Conecte o Linkzee ao **Claude** e gerencie sua página simplesmente pedindo:
"monta minha bio", "adiciona esse produto", "o que eu tenho agendado essa
semana?", "troca meu tema". O Claude conversa com o Linkzee através do MCP,
então você nunca sai do chat.

Há duas formas de conectar. Use o **conector** no claude.ai e nos apps do
Claude, e uma **chave de API** no Claude Code.

## claude.ai e os apps do Claude (conector)

Nenhuma chave para copiar: você entra no Linkzee e aprova o acesso.

<Steps>
  <Step title="Adicione o Linkzee como conector">
    No Claude, abra **Configurações**, depois **Conectores**, e adicione um
    conector personalizado com a URL `https://api.linkz.ee/mcp`.
  </Step>
  <Step title="Entre e escolha o acesso">
    O Claude abre o Linkzee. Entre, escolha a loja e defina o que o Claude pode
    usar: **content** (sua página, sempre incluído) e, opcionalmente,
    **agenda**, **leads** e **finance**. Os grupos opcionais pedem um login
    recente.
  </Step>
  <Step title="Peça ao Claude em linguagem natural">
    Abra um chat e descreva o que você quer. Para montar uma página nova, diga
    "Monte minha bio no Linkzee." O Claude pergunta o resto.
  </Step>
</Steps>

Você pode ver e desconectar todos os apps conectados em **Configurações**,
**API e MCP**, na seção **Conexões**. A desconexão vale na hora.

<Note>
  O conector nunca vê três ferramentas: pixels de rastreamento e GTM
  (`configure_tracking`), a chave PIX das gorjetas (`configure_tips`) e a
  desconexão do Google Agenda (`disconnect_agenda_google`). Use uma chave de API
  para elas, ou altere-as no painel.
</Note>

## Claude Code (chave de API)

<Steps>
  <Step title="Crie uma chave de API">
    No seu painel, abra **Configurações**, **API e MCP**, e crie uma chave com o
    escopo **write** (ela também lê). Copie-a quando ela for exibida. Veja
    [Chaves de API](/pt-BR/integrations/api/api-keys) para o passo a passo completo.
  </Step>
  <Step title="Adicione o servidor">
    Rode isto no seu terminal, com sua chave no lugar de `lzk_your_key`:

    ```bash
    claude mcp add --transport http linkzee https://api.linkz.ee/mcp \
      --header "Authorization: Bearer lzk_your_key"
    ```
  </Step>
  <Step title="Peça ao Claude">
    Inicie o Claude Code e peça, por exemplo, "lista meus links e esconde os que
    apontam para promoções antigas".
  </Step>
</Steps>

## Fotos e vídeos a partir do chat

Quando você anexa uma foto no claude.ai, o Claude vê a imagem, mas não recebe o
arquivo para enviá-lo. Nesse caso, o Claude cria um **link de envio** e passa
para você: abra-o, escolha as fotos ou vídeos no seu celular ou computador e
avise o Claude quando terminar. O Claude Code consegue enviar arquivos locais
para esse link sozinho. Veja [Envio de arquivos](/pt-BR/integrations/mcp/sending-files).

<Warning>
  Sua chave de API age na sua loja. Nunca cole ela em um chat público nem a
  compartilhe. Trate-a como uma senha.
</Warning>
