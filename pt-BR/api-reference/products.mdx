Os produtos são os itens da sua vitrine pública. Cada produto tem um nome, um
preço opcional, uma imagem e um link de afiliado ou de produto. Use estes
endpoints para manter seu catálogo em sincronia a partir dos seus próprios
sistemas.

Todas as requisições vão para `https://api.linkz.ee` e devem incluir sua chave de API:

```
Authorization: Bearer lzk_your_key
```

<Note>
Ler produtos (`GET`) exige o escopo **read**. Criar, atualizar, excluir ou
reordenar um produto exige uma chave com o escopo **write**.
</Note>

## Ordem da vitrine

A vitrine tem dois modos de ordem:

- **Mais novos primeiro** (padrão): os produtos mais recentes vêm primeiro.
- **Manual**: ligado pela primeira reordenação (veja "Reordenar produtos" abaixo)
  que muda a ordem que os visitantes veem. A partir daí a vitrine segue o
  `order` de cada produto, e os produtos novos entram no topo.

`GET /v1/products`, a ferramenta MCP `list_products` e a página pública sempre
retornam os produtos na ordem que os visitantes veem. Não há endpoint para voltar
a mais novos primeiro.

## Listar produtos

```
GET /v1/products
```

Retorna todos os produtos da sua loja, na ordem da vitrine.

### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/products
```

## Obter um produto

```
GET /v1/products/{id}
```

Retorna um único produto pelo ID. A resposta é uma lista de permissões dos
campos do produto (a mesma visão da ferramenta MCP `get_product`); campos
internos nunca são retornados.

### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/products/665f1a2b9c4e1f0012a3b4c5
```

### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `id` | string (path) | Sim | O ID do produto. |

## Criar um produto

```
POST /v1/products
```

Cria um produto na sua vitrine. Exige o escopo **write**.

Você pode enviar os campos do produto diretamente, ou enviar só uma `url` de
marketplace e deixar o Linkzee buscar o nome, o preço e a imagem para você. Se a
busca automática voltar incompleta, envie pelo menos `name` para que o produto
possa ser salvo.

### Requisição

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: sync-SKU-1042" \
  -d '{
    "name": "Wireless Headphones XYZ",
    "description": "Bluetooth 5.3, 30h battery",
    "price": 99.9,
    "priceOriginal": 149.9,
    "imageUrl": "https://example.com/headphones.jpg",
    "externalLink": "https://shopee.com.br/product/123",
    "badge": "Deal",
    "isFeatured": true,
    "externalId": "SKU-1042"
  }' \
  https://api.linkz.ee/v1/products
```

### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `name` | string | Condicional | Nome do produto (máx. 160). Opcional quando `url` é enviada: é preenchido pela busca no marketplace. |
| `url` | string | Não | URL do marketplace. Quando enviada sem `name` ou `price`, o Linkzee tenta preenchê-los automaticamente. |
| `slug` | string | Não | Slug personalizado (máx. 80). Derivado do nome quando omitido; único por loja. |
| `description` | string | Não | Descrição curta (máx. 2000). |
| `price` | number | Não | Preço atual em R$. Deixe de fora para um produto "sem preço". |
| `priceOriginal` | number | Não | Preço original, usado para mostrar um desconto. |
| `installments` | string | Não | Texto de parcelamento, por exemplo `3x of R$ 33.30` (máx. 80). |
| `imageUrl` | string | Não | URL da imagem principal (http ou https). URLs externas são copiadas para a CDN do Linkzee. |
| `gallery` | string[] | Não | Até 10 URLs de imagens extras. |
| `externalLink` | string | Não | Link de afiliado ou do produto (http ou https). Um produto sem link fica como rascunho oculto. |
| `buttonText` | string | Não | Rótulo da chamada para ação (máx. 60), por exemplo `Buy`. |
| `badge` | string | Não | Selo promocional curto (máx. 28), por exemplo `Deal`. |
| `categoryId` | string | Não | ID da categoria à qual este produto pertence. |
| `isActive` | boolean | Não | Se o produto fica visível na vitrine. Padrão `true`. |
| `isFeatured` | boolean | Não | Adiciona o produto ao carrossel de destaques. |
| `highlightFx` | string | Não | Destaque animado (Premium): `""`, `"shake"`, `"shine"`, `"pulse"` ou `"bounce"`. |
| `cardSize` | string | Não | `normal` ou `wide` (um card `wide` ocupa as duas colunas da grade). |
| `offerEndsAt` | string | Não | Data de fim da oferta (ISO 8601). |
| `offerDurationMinutes` | number | Não | Duração do contador de escassez, em minutos (relativa, reinicia por visitante). |
| `showCountdown` | boolean | Não | Mostra o contador regressivo no card. |
| `externalId` | string | Não | Sua própria referência para este produto (um id de CRM ou ERP, ou um SKU) para casá-lo com seus sistemas (máx. 64). Nunca aparece na sua página pública. |
| `barcode` | string | Não | Código de barras do produto: EAN, GTIN ou UPC (máx. 32). Nunca aparece publicamente. |

<Note>
Envie um cabeçalho `Idempotency-Key` para repetir com segurança: repetir a
requisição com a mesma chave e o mesmo corpo em até 24 horas retorna o produto
criado da primeira vez, em vez de uma duplicata. A mesma chave com um corpo
diferente retorna `409`. Veja [Limites de requisições](/pt-BR/api-reference/rate-limits).
</Note>

### Resposta

```json
{
  "error": false,
  "message": "Product created successfully",
  "data": {
    "id": "665f1a2b9c4e1f0012a3b4c5",
    "name": "Wireless Headphones XYZ",
    "slug": "wireless-headphones-xyz",
    "price": 99.9,
    "priceOriginal": 149.9,
    "imageUrl": "https://cdn.linkz.ee/u/abc/products/665f1a2b.webp",

    "isActive": true,
    "isFeatured": true,

  }

```

## Atualizar um produto

```
PATCH /v1/products/{id}
```

Atualiza qualquer subconjunto dos campos de um produto. Exige o escopo **write**.
Só os campos que você envia são alterados.

### Requisição

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "price": 89.9,
    "badge": "Flash sale",
    "isActive": false
  }' \
  https://api.linkz.ee/v1/products/665f1a2b9c4e1f0012a3b4c5
```

### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `id` | string (path) | Sim | O ID do produto. |

O corpo aceita os mesmos campos de **Criar um produto**, exceto `url` (a busca
automática só roda na criação). Todos os campos são opcionais. Envie
`categoryId: null` para tirar o produto da categoria e `offerEndsAt: null` para
limpar a data de fim da oferta.

### Resposta

```json
{
  "error": false,
  "message": "Product updated successfully",
  "data": {
    "id": "665f1a2b9c4e1f0012a3b4c5",
    "name": "Wireless Headphones XYZ",
    "price": 89.9,
    "badge": "Flash sale",
    "isActive": false
  }
}
```

## Excluir um produto

```
DELETE /v1/products/{id}
```

Remove um produto da sua vitrine. Exige o escopo **write**.

### Requisição

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/products/665f1a2b9c4e1f0012a3b4c5
```

### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `id` | string (path) | Sim | O ID do produto. |

### Resposta

```json
{
  "error": false,
  "message": "Product deleted successfully"
}
```

## Reordenar produtos

```
PUT /v1/products/order
```

Define a posição dos produtos na vitrine. Exige o escopo **write**. Cada item vai
para a posição dada por `order` (`0` é o topo):

- Envie a lista **completa** para uma ordem exata.
- Envie só os produtos que quer mover: os outros mantêm a ordem relativa.

A primeira reordenação que muda o que os visitantes veem passa a vitrine para a
ordem manual (veja "Ordem da vitrine" acima).

### Requisição

```bash
curl -X PUT \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "items": [
      { "id": "665f1a2b9c4e1f0012a3b4c5", "order": 0 },
      { "id": "665f1a2b9c4e1f0012a3b4c6", "order": 1 }
    ]
  }' \
  https://api.linkz.ee/v1/products/order
```

### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `items` | array | Sim | De 1 a 5000 itens. |
| `items[].id` | string | Sim | O ID do produto. |
| `items[].order` | integer | Sim | Nova posição (`0` é o topo). |

### Resposta

Retorna os produtos na nova ordem, no mesmo formato de `GET /v1/products`.
