Os endpoints de Agenda permitem operar sua agenda de reservas de forma
programática: definir os **serviços** que as pessoas podem reservar, sua
**equipe**, os **bloqueios** de quando você está indisponível, consultar a
**disponibilidade** real para criar e gerenciar **agendamentos**, moderar as
**avaliações** que você recebe e gerenciar a **lista de espera**.

Todos os caminhos ficam sob `https://api.linkz.ee/v1/agenda`. Toda requisição
precisa do cabeçalho `Authorization: Bearer lzk_your_key`, e as operações de
escrita (POST/PATCH/DELETE) exigem uma chave com o escopo **write**.

<Note>
As leituras (`GET`) funcionam com qualquer chave válida. Criar, atualizar,
transicionar, remarcar ou excluir qualquer coisa exige o escopo **write**.
</Note>

## Serviços

Um serviço (oferta) é algo que as pessoas podem reservar — um corte de cabelo,
uma consultoria, uma chamada. Cada serviço tem uma duração e, opcionalmente, um
preço.

### Listar serviços

```
GET /v1/agenda/offerings
```

Retorna todos os serviços da sua agenda, na ordem de exibição.

#### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/offerings
```

#### Resposta

```json
{
  "error": false,
  "message": "Services retrieved successfully",
  "data": [
    {
      "_id": "665f0a1b2c3d4e5f60718293",
      "name": "Strategy call",
      "durationMin": 45,
      "price": 150,
      "description": "A focused 45-minute planning session.",
      "color": "#2f80ed",
      "bufferAfterMin": 15,
      "meetEnabled": true,
      "order": 0,
      "isActive": true
    }
  ]
}
```

### Criar um serviço

```
POST /v1/agenda/offerings
```

Adiciona um novo serviço reservável.

#### Requisição

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"name":"Strategy call","durationMin":45,"price":150,"meetEnabled":true}' \
  https://api.linkz.ee/v1/agenda/offerings
```

#### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `name` | string | Sim | Nome do serviço (máx. 80 caracteres). |
| `durationMin` | integer | Sim | Duração em minutos (5–720). |
| `price` | number | Não | Preço em R$. Omita ou envie `null` para gratuito. |
| `description` | string | Não | Descrição curta (máx. 300 caracteres). |
| `color` | string | Não | Cor em hexadecimal para a agenda, ex.: `#2f80ed`. |
| `bufferAfterMin` | integer | Não | Intervalo em minutos após cada reserva (0–240). |
| `meetEnabled` | boolean | Não | Cria um link do Google Meet para cada reserva. |
| `isActive` | boolean | Não | Se o serviço está reservável. O padrão é `true`. |
| `kind` | string | Não | `single` (padrão) ou `combo`. Um combo agrupa vários serviços individuais em um único pacote reservável. |
| `comboItemIds` | array of string | Não | Obrigatório quando `kind` é `combo`: os IDs de 2–6 serviços individuais incluídos no combo. |
| `chargeMode` | string | Não | Cobrança online: `none` (padrão, paga presencialmente), `deposit` (valor parcial adiantado) ou `full` (preço inteiro adiantado — exige um `price` maior que 0). |
| `chargeDepositType` | string | Não | Como o sinal é calculado quando `chargeMode` é `deposit`: `percent` ou `fixed`. |
| `chargeDepositValue` | number | Não | O valor do sinal: uma porcentagem de 1 a 100 quando `chargeDepositType` é `percent`, ou um valor fixo na moeda da sua loja quando é `fixed`. |

#### Resposta

```json
{
  "error": false,
  "message": "Service created successfully",
  "data": {
    "_id": "665f0a1b2c3d4e5f60718293",
    "name": "Strategy call",
    "durationMin": 45,
    "price": 150,
    "bufferAfterMin": 0,
    "meetEnabled": true,
    "order": 0,
    "isActive": true
  }
}
```

### Atualizar um serviço

```
PATCH /v1/agenda/offerings/{id}
```

Atualiza um serviço. Envie o conjunto completo de campos, como ao criar.

#### Requisição

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"name":"Strategy call","durationMin":60,"price":180}' \
  https://api.linkz.ee/v1/agenda/offerings/665f0a1b2c3d4e5f60718293
```

#### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `id` | string | Sim | O ID do serviço (no caminho). |

O corpo aceita os mesmos campos de [Criar um serviço](#create-a-service).

#### Resposta

```json
{
  "error": false,
  "message": "Service updated successfully",
  "data": {
    "_id": "665f0a1b2c3d4e5f60718293",
    "name": "Strategy call",
    "durationMin": 60,
    "price": 180,
    "isActive": true
  }
}
```

### Excluir um serviço

```
DELETE /v1/agenda/offerings/{id}
```

Remove um serviço. Ele deixa de ser reservável; os agendamentos existentes não
são afetados.

#### Requisição

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/offerings/665f0a1b2c3d4e5f60718293
```

#### Resposta

```json
{
  "error": false,
  "message": "Service deleted successfully",
  "data": { "id": "665f0a1b2c3d4e5f60718293" }
}
```

### Criar um atendente

```
POST /v1/agenda/staff
```

#### Requisição

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"name":"Ana Souza","title":"Senior consultant","offeringIds":["665f0a1b2c3d4e5f60718293"]}' \
  https://api.linkz.ee/v1/agenda/staff
```

#### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `name` | string | Sim | Nome do atendente (máx. 80 caracteres). |
| `title` | string | Não | Função ou cargo (máx. 80 caracteres). |
| `avatarUrl` | string | Não | URL da foto (máx. 500 caracteres). |
| `hours` | array | Não | Horários semanais de trabalho (veja abaixo). Envie `null` para herdar o horário do seu negócio. |
| `offeringIds` | array of string | Não | Serviços que esta pessoa atende. `null` significa todos os serviços. |
| `isActive` | boolean | Não | Se a pessoa está reservável. O padrão é `true`. |

Cada entrada em `hours` descreve um dia da semana:

| Campo | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `day` | integer | Sim | Dia da semana, `0` = domingo até `6` = sábado. |
| `closed` | boolean | Não | Defina `true` para marcar o dia como folga. |
| `ranges` | array | Não | Janelas de trabalho, cada uma com `startMin` e `endMin` (minutos a partir da meia-noite, 0–1440). |

#### Resposta

```json
{
  "error": false,
  "message": "ok",
  "data": {
    "_id": "665f0c9a8b7d6e5f40312a11",
    "name": "Ana Souza",
    "title": "Senior consultant",
    "hours": null,
    "offeringIds": ["665f0a1b2c3d4e5f60718293"],
    "isActive": true
  }
}
```

#### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `id` | string | Sim | O ID do atendente (no caminho). |

## Bloqueios

Um bloqueio é um período em que você (ou um atendente) está indisponível — um
feriado, férias ou folga. Nenhuma reserva pode cair dentro de um bloqueio.

<Note>
Bloqueios não têm endpoint de atualização. Para alterar um, exclua-o e crie um
novo.
</Note>

### Listar bloqueios

```
GET /v1/agenda/blocks
```

#### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/blocks
```

#### Resposta

```json
{
  "error": false,
  "message": "ok",
  "data": [
    {
      "_id": "665f0e5511aa22bb33cc44dd",
      "staffId": null,
      "startDate": "2026-12-24",
      "endDate": "2026-12-26",
      "allDay": true,
      "reason": "Holidays"
    }
  ]
}
```

### Criar um bloqueio

```
POST /v1/agenda/blocks
```

#### Requisição

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"startDate":"2026-12-24","endDate":"2026-12-26","allDay":true,"reason":"Holidays"}' \
  https://api.linkz.ee/v1/agenda/blocks
```

#### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `startDate` | string | Sim | Primeiro dia bloqueado, `YYYY-MM-DD`. |
| `endDate` | string | Sim | Último dia bloqueado, `YYYY-MM-DD`. |

| `endMin` | integer | Não | Minuto de fim a partir da meia-noite para um bloqueio parcial (0–1440). |
| `reason` | string | Não | Rótulo curto (máx. 120 caracteres). |

#### Resposta

```json

  "message": "ok",
  "data": {
```

## Disponibilidade

```
GET /v1/agenda/availability
```

Retorna os dias abertos e horários reais de um serviço ao longo de um intervalo
de datas — o mesmo mecanismo que alimenta sua página pública de reservas, então
já considera os horários de trabalho, os agendamentos existentes e os bloqueios.

#### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  "https://api.linkz.ee/v1/agenda/availability?offeringId=665f0a1b2c3d4e5f60718293&from=2026-07-21&to=2026-07-25&detail=slots"
```

#### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `offeringId` | string | Sim | O serviço a consultar. |
| `from` | string | Sim | Data inicial, `YYYY-MM-DD` (no fuso horário da sua agenda). |
| `to` | string | Sim | Data final, `YYYY-MM-DD`. |
| `staffId` | string | Não | Limita a disponibilidade a um atendente (modo equipe). |
| `extraOfferingIds` | string | Não | IDs separados por vírgula de até 4 serviços extras reservados junto com o principal (um carrinho). A disponibilidade então considera a duração combinada. |
| `detail` | string | Não | `days` (padrão) retorna apenas o estado por dia; `slots` também retorna os horários de início reserváveis. |

#### Resposta

```json
{
  "error": false,
  "message": "Availability retrieved successfully",
  "data": {
    "days": [
      { "date": "2026-07-21", "state": "free", "density": "low" },
      { "date": "2026-07-22", "state": "full", "density": "high" },
      { "date": "2026-07-23", "state": "closed", "density": "none" }
    ],
    "slots": [
      { "startAt": "2026-07-21T12:00:00.000Z" },
      { "startAt": "2026-07-21T12:45:00.000Z" }
    ],
    "charge": {
      "mode": "deposit",
      "amountDueCents": 5000,
      "totalCents": 15000,
      "currency": "brl"
    },
    "stepMin": 15,
    "timezone": "America/Sao_Paulo"
  }
}
```

O `state` de cada dia é `free` (tem horários abertos), `full` (totalmente
reservado) ou `closed` (não é dia de trabalho); `density` (`none`, `low`,
`medium`, `high`) indica quão ocupado o dia já está. Os horários são retornados
em UTC (`Z`).

Quando o serviço tem cobrança online configurada, `charge` descreve o que o
visitante paga ao reservar: `mode` (`none`, `deposit` ou `full`),
`amountDueCents` (o valor devido no momento da reserva, em centavos),
`totalCents` (o preço completo do serviço, em centavos) e `currency`. Sem
cobrança configurada, `mode` é `none` e os valores são `0`.

### Criar um agendamento

```
POST /v1/agenda/appointments
```

Cria um agendamento manualmente, usando as mesmas regras da reserva pública — o
horário precisa estar realmente disponível ou a requisição é rejeitada.

#### Requisição

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"offeringId":"665f0a1b2c3d4e5f60718293","startAt":"2026-07-21T13:00:00.000Z","name":"João Lima","phone":"+5511999998888"}' \
  https://api.linkz.ee/v1/agenda/appointments
```

#### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `offeringId` | string | Sim | O serviço sendo reservado. |
| `startAt` | string | Sim | Horário de início em ISO 8601, ex.: `2026-07-21T13:00:00.000Z`. |
| `name` | string | Sim | Nome do visitante (máx. 120 caracteres). |
| `phone` | string | Sim | Telefone do visitante (máx. 30 caracteres). |
| `email` | string | Não | E-mail do visitante (máx. 160 caracteres). |
| `notes` | string | Não | Notas internas (máx. 500 caracteres). |
| `leadId` | string | Não | Vincula o agendamento a um cliente (lead) existente em vez de criar um registro duplicado. |
| `staffId` | string | Não | O atendente que vai realizar o agendamento (modo equipe). Ignorado nos modos solo/pool. |

#### Resposta

```json
{
  "error": false,
  "message": "Appointment created successfully",
  "data": {
    "id": "665f1122aa33bb44cc55dd66",
    "manageToken": "8f3a1c22b90e4d1f",
    "status": "confirmed",
    "startAt": "2026-07-21T13:00:00.000Z",
    "endAt": "2026-07-21T13:45:00.000Z",
    "offeringName": "Strategy call",
    "timezone": "America/Sao_Paulo"
  }
}
```

## Google Calendar


### Desconectar o Google Calendar

```
DELETE /v1/agenda/google
```

Desconecta seu Google Calendar. A sincronização para; os agendamentos
existentes permanecem.

#### Requisição

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/google
```

#### Resposta

```json
{ "error": false, "message": "ok", "data": { "connected": false } }
```

<Warning>
Conectar um Google Calendar acontece por um fluxo de login no painel do Linkzee
e não pode ser feito pela API. A API só consegue ler o status e desconectar.
</Warning>

## Avaliações

Depois de um agendamento concluído, os visitantes podem deixar uma avaliação.
Avaliações **nunca são editadas ou excluídas** — a única ação de moderação é
ocultar uma da sua página pública (ela continua visível para você, e você pode
exibi-la de novo a qualquer momento).

### Listar avaliações

```
GET /v1/agenda/reviews
```

Retorna todas as avaliações que sua agenda recebeu, **incluindo as ocultas**.

#### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/reviews
```

#### Resposta

```json
{
  "error": false,
  "message": "Reviews retrieved successfully",
  "data": [
    {
      "id": "665f33aa11bb22cc33dd44ee",
      "rating": 5,
      "comment": "Great service, highly recommend!",
      "visitorName": "João Lima",
      "visitorPhone": "+5511999998888",
      "visitorEmail": "joao@example.com",
      "offeringId": "665e11bb22cc33dd44ee55ff",
      "offeringName": "Corte",
      "staffId": null,
      "appointmentAt": "2026-07-22T14:00:00.000Z",
      "hidden": false,
      "featured": false,
      "followedUpAt": null,
      "createdAt": "2026-07-22T18:30:00.000Z"
    }
  ]
}
```

#### Campos

| Campo | Descrição |
| --- | --- |
| `rating` | De 1 a 5 estrelas. |
| `comment` | O que o cliente escreveu. Nunca editável. |
| `visitorName` / `visitorPhone` / `visitorEmail` | O cliente que agendou, para você dar retorno. Os mesmos dados do agendamento. |
| `offeringId` / `offeringName` | O serviço avaliado. |
| `staffId` | O profissional que atendeu, quando você tem equipe. |
| `appointmentAt` | Quando o atendimento aconteceu (ISO 8601, UTC). |
| `hidden` | `true` significa que não conta na sua média pública. |
| `featured` | `true` significa que vem primeiro no bloco de avaliações da sua página. |
| `followedUpAt` | Quando você marcou a avaliação como tratada, ou `null`. |

<Note>
  `visitorPhone` e `visitorEmail` são os dados de contato do seu cliente — os
  mesmos devolvidos pelo endpoint de agendamentos. Trate a resposta como dado
  pessoal e mantenha a sua chave de API privada.
</Note>

### Ocultar ou exibir uma avaliação

```
PATCH /v1/agenda/reviews/{id}
```

Alterna a visibilidade de uma avaliação na sua página pública. Exige o escopo
**write**.

Avaliações nunca são editadas nem apagadas pela API — ocultar é a única ação de
moderação disponível aqui. Destacar uma avaliação e marcá-la como tratada são
ações do seu painel.

#### Requisição

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"hidden":true}' \
  https://api.linkz.ee/v1/agenda/reviews/665f33aa11bb22cc33dd44ee
```

#### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `id` | string | Sim | O ID da avaliação (no caminho). |
| `hidden` | boolean | Sim | `true` oculta a avaliação da página pública; `false` a exibe de novo. |

#### Resposta

```json
{
  "error": false,
  "message": "Review updated successfully",
  "data": { "id": "665f33aa11bb22cc33dd44ee", "hidden": true }
}
```

<Note>
Não existe endpoint para editar ou excluir uma avaliação — ocultar é a única
ação de moderação, para que as notas continuem confiáveis.
</Note>

## Lista de espera

Quando um período não tem horários livres, os visitantes podem entrar na lista
de espera. Assim que um horário compatível abre, o sistema o oferece
automaticamente à primeira entrada compatível.

### Listar a lista de espera

```
GET /v1/agenda/waitlist
```

Retorna a fila atual de visitantes aguardando um horário.

#### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/waitlist
```

#### Resposta

```json
{
  "error": false,
  "message": "Waitlist retrieved successfully",
  "data": [
    {
      "id": "665f44bb55cc66dd77ee88ff",
      "position": 1,
      "name": "Maria Alves",
      "phone": "+5511988887777",
      "dateFrom": "2026-07-21",
      "dateTo": "2026-07-25",
      "periods": ["morning", "afternoon"],
      "status": "waiting",
      "offeringId": "665f0a1b2c3d4e5f60718293",
      "createdAt": "2026-07-19T10:12:00.000Z"
    }
  ]
}
```

As entradas são ordenadas por chegada (`position` começa em 1). `periods` lista
as partes do dia preferidas pelo visitante (`morning`, `afternoon`, `evening`);
`status` é `waiting` ou `offered` (um horário foi oferecido e aguarda
resposta).

### Remover uma entrada da lista de espera

```
DELETE /v1/agenda/waitlist/{id}
```

Remove uma entrada da fila. Exige o escopo **write**.

#### Requisição

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/waitlist/665f44bb55cc66dd77ee88ff
```

#### Resposta

```json
{ "error": false, "message": "Waitlist entry removed", "data": { "id": "665f44bb55cc66dd77ee88ff" } }
```

## Recebimentos

### Consultar o resumo de recebimentos

`GET /v1/agenda/earnings` — exige o escopo **`finance`** (nunca incluído em uma
chave por padrão; veja [Autenticação](/pt-BR/api-reference/authentication)).

Números agregados de um período: bruto, estornos, taxas e líquido, além de uma
série diária e cortes por forma de pagamento e por serviço. A resposta não
contém **nenhum dado de cliente** — a lista de transações com nomes e telefones
só está disponível no dashboard.

| Parâmetro de query | Tipo | Descrição |
| --- | --- | --- |
| `from` | `YYYY-MM-DD` | Início do período. |
| `to` | `YYYY-MM-DD` | Fim do período. |

```bash
curl "https://api.linkz.ee/v1/agenda/earnings?from=2026-08-01&to=2026-08-31" \
  -H "Authorization: Bearer lzk_..."
```
