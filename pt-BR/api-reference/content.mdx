Os endpoints de conteúdo expõem tudo o que um visitante vê na zona de links de uma
página — links avulsos, coleções (grupos de links) e itens do Concierge — além de um
bloco `meta` que resume a vitrine de produtos (contadores, chips de categoria,
produtos em destaque e a primeira página do catálogo).

Todas as requisições vão para `https://api.linkz.ee` e devem incluir sua chave de API:

```
Authorization: Bearer lzk_your_key
```

<Note>
Os produtos não fazem parte da árvore reordenável. A vitrine é ordenada
automaticamente (mais recentes primeiro), então a reordenação afeta apenas links,
coleções e itens do Concierge. Entradas de produto enviadas ao endpoint de
reordenação são ignoradas.
</Note>

## Obter árvore de conteúdo

```
GET /v1/content
```

Retorna a árvore de conteúdo público da sua página, além de um resumo `meta` da
vitrine de produtos.

### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/content
```

### Resposta

O objeto `data` tem duas partes: `meta` (resumo da vitrine) e `root` (a lista
ordenada de entradas de conteúdo). Cada entrada de `root` é do tipo `link`,

## Reordenar conteúdo

```
PUT /v1/content/order
```

Define a ordem de toda a zona de links em uma única chamada. Envie a árvore completa
na ordem que você quer — a posição de cada entrada no array se torna a sua nova ordem.
Requer uma chave com o escopo **write**.

### Requisição

```bash
curl -X PUT \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "root": [
      { "type": "link", "id": "507f1f77bcf86cd799439011" },
      {
        "type": "collection",
        "id": "507f1f77bcf86cd799439020",
        "children": [
          { "type": "link", "id": "507f1f77bcf86cd799439012" },
          { "type": "concierge", "id": "507f1f77bcf86cd799439030" }
        ]
      }
    ]
  }' \
  https://api.linkz.ee/v1/content/order
```

### Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `root` | array | Sim | Entradas de nível superior na sua nova ordem. Pode ser vazio. |
| `root[].type` | string | Sim | Um dos valores `link`, `collection`, `concierge` ou `product`. |
| `root[].id` | string | Sim | O ID da entrada. |
| `root[].children` | array | Não | Itens filhos, em ordem. Usado apenas quando `type` é `collection`. |
| `root[].children[].type` | string | Sim | Um dos valores `link`, `concierge` ou `product`. |
| `root[].children[].id` | string | Sim | O ID do item filho. |

<Warning>
Entradas de produto (na raiz ou dentro de uma coleção) são aceitas, mas ignoradas —
a vitrine se ordena sozinha. Envie apenas entradas `link`, `collection` e `concierge`
para alterar o que realmente é reordenado. IDs desconhecidos são ignorados
silenciosamente.
</Warning>

### Resposta

```json
{
  "error": false,
  "message": "Conteúdo reordenado com sucesso",
  "data": { "ok": true }
}
```
