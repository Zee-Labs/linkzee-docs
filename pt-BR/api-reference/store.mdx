A loja é o coração de uma conta Linkzee: seu nome, bio, perfis de redes sociais,
tema, campos de SEO, pixels de rastreamento e configurações de marketing. Estes
endpoints permitem ler o perfil completo, aplicar mudanças, listar os temas
prontos e obter um resumo rápido de desempenho.

Todas as requisições vão para `https://api.linkz.ee` e devem incluir sua chave de API:

```
Authorization: Bearer lzk_your_key
```

<Note>
  Leituras funcionam com qualquer chave. Atualizações exigem uma chave com o escopo **write**.
</Note>

## Obter o perfil da loja

```
GET /v1/store
```

Retorna o perfil completo da loja à qual a chave pertence — identidade, tema,
redes sociais, SEO e configurações de marketing.

### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/store
```

### Resposta

```json
{
  "error": false,
  "message": "Loja carregada com sucesso",
  "data": {
    "id": "665f1c9a4b2e8a0012a3c9d1",
    "slug": "achadinhos-da-gabi",
    "name": "Achadinhos da Gabi",
    "bio": "As melhores ofertas dos marketplaces, todo dia.",
    "titleStyle": "text",
    "themeId": "aurora",
    "themeMode": "dark",
    "socialsPosition": "top",
    "socialOrder": ["instagram", "tiktok", "whatsapp"],
    "productsPosition": "top",
    "social": {
      "instagram": "achadinhosdagabi",
      "tiktok": "achadinhosdagabi"
    },
    "seoTitle": "Achadinhos da Gabi",
    "seoDescription": "Ofertas selecionadas de Shopee, Amazon e Mercado Livre.",
    "gtmId": "GTM-ABC123",
    "capiTokenConfigured": true,
    "capiTokenPreview": "9f3a",
    "isActive": true
  }
}
```

<Note>
  O token da Conversion API nunca é retornado por completo — você vê apenas
  `capiTokenConfigured` e os últimos quatro caracteres em `capiTokenPreview`.
</Note>

## Atualizar o perfil da loja

```
PATCH /v1/store
```

Atualiza um ou mais campos da loja. Envie apenas os campos que você quer
alterar — qualquer coisa que você omitir permanece como está. As mudanças entram
no ar na página pública imediatamente.

### Requisição

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
        "name": "Achadinhos da Gabi",
        "bio": "As melhores ofertas dos marketplaces.",
        "themeId": "aurora",
        "socialsPosition": "top",
        "seoTitle": "Achadinhos da Gabi"
      }' \
  https://api.linkz.ee/v1/store
```

### Parâmetros

Todos os campos são opcionais; envie apenas o que você quer alterar.

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| `name` | string | Nome de exibição da loja (máx. 120 caracteres). |
| `bio` | string | Descrição curta exibida abaixo do nome (máx. 500 caracteres). |
| `titleStyle` | string | Estilo do título do cabeçalho: `text` ou `logo`. |
| `logoUrl` | string | URL da imagem do logo (http/https). |
| `bannerUrl` | string | URL da imagem do banner (http/https). |
| `themeId` | string | Id de um tema pronto (veja [temas](#browse-the-theme-catalog)); string vazia significa um design personalizado. |
| `themeMode` | string | Modo de cor: `dark` ou `light`. |
| `socialsPosition` | string | Onde a linha de redes sociais aparece: `top` ou `bottom`. |
| `socialOrder` | string[] | Ordem de exibição das redes sociais. |
| `productsPosition` | string | Posição da vitrine em relação aos links: `top` ou `bottom`. |
| `social` | object | Perfis de redes sociais, ex.: `{ "instagram": "handle", "tiktok": "handle" }`. |
| `mainLink` | string | Link principal da loja (http/https). |
| `seoTitle` | string | Título da página pública para mecanismos de busca (máx. 70 caracteres). |
| `seoDescription` | string | Meta description da página pública (máx. 160 caracteres). |
| `gtmId` | string | Id do container do Google Tag Manager, ex.: `GTM-ABC123`. |
| `utmSource` | string | UTM source padrão adicionada aos links de saída. |
| `utmMedium` | string | UTM medium padrão. |
| `utmCampaign` | string | UTM campaign padrão. |
| `pixels` | object | Ids dos pixels de rastreamento: `metaPixelId`, `tiktokPixelId`, `gaMeasurementId`. |
| `capiToken` | string | Token da Meta Conversion API. Enviado em texto puro, armazenado criptografado. Vazio significa "manter o atual". |
| `isActive` | boolean | Se a página está publicada e no ar. |

<Warning>
  O `slug` da loja não pode ser alterado pela API. Enviá-lo não tem efeito —
  ele é ignorado para que o link da sua bio publicada nunca quebre.
</Warning>

### Resposta

```json
{
  "error": false,
  "message": "Loja atualizada com sucesso",
  "data": {
    "id": "665f1c9a4b2e8a0012a3c9d1",
    "slug": "achadinhos-da-gabi",
    "name": "Achadinhos da Gabi",
    "bio": "As melhores ofertas dos marketplaces.",
    "themeId": "aurora",
    "socialsPosition": "top",
    "seoTitle": "Achadinhos da Gabi",
    "isActive": true
  }
}
```

## Navegar pelo catálogo de temas

```
GET /v1/themes
```

Lista os temas prontos que você pode aplicar com `themeId`. Cada entrada inclui
uma descrição curta para ajudar você a combinar um visual com o estilo da loja.

### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/themes
```

### Resposta

```json
{
  "error": false,
  "message": "Temas carregados",
  "data": [
    {
      "id": "pure",
      "name": "Puro",
      "mode": "light",
      "description": "Claro minimalista, fundo quase branco, foco total nos produtos."
    },
    {
      "id": "noir",
      "name": "Noir",
      "mode": "dark",
      "description": "Escuro sóbrio, cinza-grafite, elegante e neutro."
    },
    {
      "id": "aurora",
      "name": "Aurora",
      "mode": "dark",
      "description": "Gradiente violeta/azul animado, moderno e premium."
    }
  ]
}
```

<Note>
  Use qualquer `id` desta lista como o `themeId` ao atualizar a loja.
</Note>

## Obter um resumo de desempenho

```
GET /v1/analytics/summary
```

Retorna as métricas principais da vitrine — totais mais os produtos em destaque
e os mais recentes.

### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/analytics/summary
```

### Resposta

```json
{
  "error": false,
  "message": "Dashboard carregado",
  "data": {
    "totalProducts": 42,
    "totalCategories": 6,
    "totalClicks": 1873,
    "topProducts": [
      {
        "id": "665f2a114b2e8a0012a3ca07",
        "name": "Fone Bluetooth TWS",
        "price": 79.9,
        "clicks": 312
      }
    ],
    "latestProducts": [
      {
        "id": "665f2b884b2e8a0012a3ca19",
        "name": "Luminária de mesa articulada",
        "price": 129.9,
        "clicks": 4
      }
    ]
  }
}
```

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `totalProducts` | number | Total de produtos na vitrine. |
| `totalCategories` | number | Total de categorias. |
| `totalClicks` | number | Soma de todos os cliques em produtos. |
| `topProducts` | array | Até 5 produtos mais clicados. |
| `latestProducts` | array | Até 5 produtos adicionados mais recentemente. |
