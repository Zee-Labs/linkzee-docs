Uma loja guarda uma página pública: nome, bio, perfis de redes sociais, design,
cards especiais, campos de SEO, configurações de rastreamento e de marketing. Uma
conta Linkzee pode ter **várias lojas**, então estes endpoints sempre agem em
**uma** delas: a loja à qual a sua chave de API está presa.

Todas as requisições vão para `https://api.linkz.ee` e devem incluir sua chave de API:

```
Authorization: Bearer lzk_your_key
```

<Note>
  Leituras exigem o escopo **read**. Atualizações exigem uma chave com o escopo
  **write**. Para trabalhar com outra loja, use uma chave criada naquela loja.
  Veja [Autenticação](/pt-BR/api-reference/authentication).
</Note>

## Obter o perfil da loja

```
GET /v1/store
```

Retorna a visão do dono da loja. É uma **lista de permissões**: só os campos
abaixo são retornados, e segredos nunca são. É a mesma visão que a ferramenta MCP
`get_store` retorna.

### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/store
```

### O que a visão inclui

| Grupo | Campos |
| --- | --- |
| Perfil | `id`, `name`, `slug`, `bio`, `bioSignature`, `seoTitle`, `seoDescription`, `timezone`, `location`, `publicPreferences`, `publicUrl`, `pageHidden` |
| Design | `themeId`, `overrides`, cores (`themeColor`, `buttonColor`, `buttonTextColor`, `buttonShadowColor`, `textColor`), `themeMode`, campos de fundo (`background`, `bgColor2`, `bgFill`, `bgAngle`, `gradientPreset`, `bgAnimated`, `wallpaperUrl` e as opções dele, opções de aurora, mesh e padrão), botões (`buttonStyle`, `buttonRadius`, `buttonShadow`, `buttonText`), `fontId`, `fontPairId`, `cardStyle`, `cardRadius`, `texture`, `motionLevel`, `stageMode`, `saleStyle`, `socialStyle`, `avatarFx`, `wallpaperVideo` |
| Cabeçalho | `headerLayout`, `titleStyle`, `logoUrl`, `bannerUrl`, `headerSettings` (`heroMedia`, `heroAvatar`, `shapeId`, `shapeColor`, `wordmarkUrl`, `heroPhotoUrl`, `cutoutUrl`, `heroVideo`) |
| Redes sociais | `social`, `whatsapp`, `socialsPosition`, `socialOrder`, `socialCards` |
| Vitrine e cards | `vitrineEnabled`, `vitrineStyle`, `gridDensity`, `vitrineLayout`, `vitrinePhotoFit`, `mapAddress`, `mapTheme`, `mapLayout`, `openingHours`, `servicesEnabled`, `packagesEnabled`, `instagramEnabled`, `googleReviewEnabled`, `googleReviewUrl`, `reviewsBlock` |
| Assistente de IA | `aiAssistantTone`, `aiEmoji` |
| Gorjetas PIX | `tips` como resumo: `enabled`, `pixKeyType`, `pixKeyPreview` (últimos 4 caracteres), `recipientName`. Nunca a chave. |
| Agenda | Configurações de `agenda` (sem dados pessoais). |
| Webhook de leads | `leadWebhook` só com `host` e `enabled`. Nunca o caminho nem o segredo de assinatura. |
| Rastreamento | `tracking`: ids de pixels, `gtmId`, UTMs padrão e `capiTokenConfigured`. Nunca o token da Conversion API. |

<Note>
  `pageHidden: true` significa que a página pública está desligada
  (`isActive: false`). O campo legado de raiz `instagram` ainda é retornado para
  leitores antigos; use `social.instagram`.
</Note>

## Atualizar o perfil da loja

```
PATCH /v1/store
```

Atualiza um ou mais campos da loja. Envie só os campos que quiser alterar; o que
você omitir fica como está. As mudanças vão ao ar na página pública na hora.

### Requisição

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
        "bio": "Brows and lashes in Pinheiros. Book online in two taps.",
        "themeId": "editorial",
        "socialsPosition": "top",
        "publicPreferences": { "locale": "en" }
      }' \
  https://api.linkz.ee/v1/store
```

### Parâmetros

Todos os campos são opcionais; envie só o que quiser alterar.

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| `name` | string | Nome de exibição da loja (máx. 120 caracteres). |
| `bio` | string | Descrição curta exibida abaixo do nome (máx. 500 caracteres). |
| `bioSignature` | string | Assinatura de uma linha abaixo da bio (máx. 60 caracteres, sem quebras de linha). |
| `titleStyle` | string | Estilo do título do cabeçalho: `text` ou `logo`. |
| `logoUrl`, `bannerUrl`, `wallpaperUrl` | string | URLs de imagens. Envie-as antes com [`POST /v1/uploads/image`](/pt-BR/api-reference/uploads). |
| `headerLayout` | string | `classic`, `hero`, `banner`, `cutout` ou `shape`. |
| `headerSettings` | object | Detalhes do cabeçalho: `wordmarkUrl`, `heroPhotoUrl`, `cutoutUrl`, `heroMedia`, `heroAvatar`, `shapeId`, `shapeColor`, `frames` e `media` (layouts e slots fora da lista permitida são descartados, e os valores são limitados). |
| `themeId` | string | Id de um tema pronto (veja o catálogo de temas abaixo). |
| `overrides` | string[] | Avançado: as seções de design personalizadas sobre o `themeId`. |
| Campos de design | vários | Os mesmos campos de design da ferramenta MCP `update_design`: cores, `themeMode`, fundo, botões, `fontId`, `fontPairId`, `cardStyle`, `cardRadius`, `texture`, `motionLevel`, `stageMode`, `saleStyle`, `vitrineStyle`, `socialStyle`, `avatarFx`. |
| `social` | object | Usuários das redes sociais, por exemplo `{ "instagram": "handle", "tiktok": "handle" }`. Uma string vazia remove uma rede. |
| `whatsapp` | string | Número com o código do país, só dígitos. |
| `socialsPosition` | string | Onde a linha de redes sociais aparece: `top` ou `bottom`. |
| `socialOrder` | string[] | Ordem de exibição dos ícones sociais. Só chaves de rede válidas (`whatsapp`, `instagram`, `tiktok`, `youtube` e as demais). |
| `productsPosition` | string | Posição da vitrine em relação aos links: `top` ou `bottom`. |
| `vitrineEnabled`, `vitrineLayout`, `vitrineStyle`, `gridDensity`, `vitrinePhotoFit` | vários | Configurações da vitrine. `vitrineLayout`: `grid`, `masonry` ou `carousel`. `vitrineStyle`: `classic` ou `spotlight`. |
| `servicesEnabled`, `packagesEnabled`, `instagramEnabled` | boolean | Liga ou desliga os cards de serviços, pacotes e Instagram. |
| `googleReviewEnabled`, `googleReviewUrl` | boolean, string | Card de avaliação do Google (link do Google Maps, `g.page` ou `g.co`). |
| `reviewsBlock` | object | Card de avaliações: `added`, `enabled`, `layout`, `limit` (de 1 a 10), `minRating` (de 1 a 5). |
| `mapAddress`, `mapTheme`, `mapLayout` | string | Card de mapa. Um `mapAddress` vazio o remove; `mapLayout` é `map` ou `card`. |
| `openingHours` | object | O selo "aberto agora": `source`, `showStatus`, `week`, `closedDates`. |
| `agenda` | object | Configurações de agendamento, mescladas parcialmente. Veja a [referência de Agendamento](/pt-BR/api-reference/agenda). |
| `tips` | object | Card de gorjetas PIX: `enabled`, `pixKey`, `pixKeyType` (`email` ou `random`), `recipientName` (máx. 25), `recipientCity` (máx. 15), `message`, `amounts`, `thanksMessage`, `highlight`. Com uma chave, o nome e a cidade são obrigatórios. O dono recebe um e-mail quando a chave muda. |
| `timezone` | string | Fuso horário IANA, por exemplo `America/Sao_Paulo`. Um nome inválido retorna `400`. |
| `location` | object | `countryCode` (ISO de 2 letras), `state`, `city`. Define o calendário de feriados. |
| `publicPreferences` | object | `locale` da página pública (`pt-BR`, `en`, `es`, `fr`, `de`) e `translationFallback` (`original` ou `dashboardLocale`). **Mesclado** com o que está salvo: enviar só `locale` mantém o fallback. |
| `seoTitle` | string | Título da página pública para buscadores (máx. 70 caracteres). |
| `seoDescription` | string | Meta description da página pública (máx. 160 caracteres). |
| `gtmId` | string | Id do contêiner do Google Tag Manager, por exemplo `GTM-ABC123`. |
| `utmSource`, `utmMedium`, `utmCampaign` | string | Parâmetros UTM padrão adicionados aos links de saída. |
| `pixels` | object | Ids dos pixels de rastreamento: `metaPixelId`, `tiktokPixelId`, `gaMeasurementId`. |
| `capiToken` | string | Token da Conversion API da Meta. Enviado em texto puro, guardado criptografado. Vazio significa "manter o atual". |
| `isActive` | boolean | Se a página pública está no ar. `false` a oculta. |

### Herança do tema

As atualizações pela API seguem as mesmas regras do editor:

- `themeId` **sem** `overrides` aplica o preset limpo: as personalizações e o
  nível de movimento salvos antes são zerados.
- Qualquer outro campo de design em uma loja com preset personaliza **só a seção
  dele** (cores, papel de parede, botões, texto, degradê, card, textura,
  movimento), que parte da paleta do tema. O resto continua seguindo o tema.
- Cores iguais às da paleta do preset não contam como cores personalizadas, então
  não caem no bloqueio premium. Valores pagos (botões de vidro, fundos de imagem,
  mesh, duotone ou vídeo, degradês animados ou prontos, cores personalizadas,
  fontes pagas, `stageMode`) retornam `403` com `code: "PLAN_REQUIRED"` em um
  plano gratuito.
- Envie `overrides` quando quiser listar você mesmo as seções personalizadas.

<Warning>
  O `slug` da loja não pode ser alterado pela API. Enviá-lo não tem efeito: ele é
  ignorado para que o link publicado da sua bio nunca quebre.
</Warning>

### Resposta

A resposta é a mesma visão de lista de permissões do `GET /v1/store`, mais
`agentNotes` quando há algo a informar:

```json
{
  "error": false,
  "message": "Store updated successfully",
  "data": {
    "id": "665f1c9a4b2e8a0012a3c9d1",
    "name": "Studio Ana",
    "bio": "Brows and lashes in Pinheiros. Book online in two taps.",
    "themeId": "editorial",
    "overrides": [],
    "socialsPosition": "top",
    "publicPreferences": { "locale": "en", "translationFallback": "original" },
    "pageHidden": false,
    "agentNotes": {
      "warnings": []
    }
  }
}
```

`agentNotes.warnings` lista campos que foram salvos, mas ainda não aparecem (por
exemplo um cabeçalho `cutout` sem a imagem recortada, ou um `wallpaperUrl` sem
fundo de imagem). Quando a chave PIX ou o número de WhatsApp muda, `agentNotes`
também traz a mudança só com os últimos 4 caracteres.

<Note>
  A ordem da vitrine não é um campo da loja. Ela é dos mais novos primeiro até o
  primeiro [`PUT /v1/products/order`](/pt-BR/api-reference/products) que a muda; a
  partir daí a vitrine segue a sua ordem manual.
</Note>

## Navegar pelo catálogo de temas

```
GET /v1/themes
```

Lista os **23** temas prontos que você pode aplicar com `themeId`. Cada entrada
traz uma descrição curta para ajudar a combinar um visual com o estilo da loja, e
`premium` para os pagos.

### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/themes
```

### Resposta

```json
{
  "error": false,
  "message": "Themes loaded",
  "data": [
    {
      "id": "pure",
      "name": "Pure",
      "mode": "light",
      "description": "Minimal light, near-white background, full focus on the products.",
      "premium": false
    },
    {
      "id": "noir",
      "name": "Noir",
      "mode": "dark",
      "description": "Sober dark, graphite grey, elegant and neutral.",
      "premium": false
    }
  ]
}
```

O catálogo completo tem 23 temas. Grátis: `pure`, `noir`, `gesso`, `solar`, `midnight`, `groove`, `carbon`, `oceano`, `neon`, `pessego`, `selva`, `aurora`, `brutalista`, `editorial`, `pista`. Pagos: `motion-neon`, `motion-clean`, `motion-achadinhos`, `motion-boutique`, `onix`, `cinema`, `perola`, `iridescente`.

<Note>
  Use qualquer `id` desta lista como `themeId` ao atualizar a loja. Os `id`s são
  estáveis; `name` e `description` são informativos e retornados em inglês.
</Note>

## Obter um resumo de desempenho

```
GET /v1/analytics/summary
```

Retorna as principais métricas da vitrine: totais, mais os produtos mais clicados
e os mais recentes.

### Requisição

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/analytics/summary
```

### Resposta

```json
{
  "error": false,
  "message": "Dashboard retrieved successfully",
  "data": {
    "totalProducts": 42,
    "totalCategories": 6,
    "totalClicks": 1873,
    "topProducts": [
      {
        "id": "665f2a114b2e8a0012a3ca07",
        "name": "Bluetooth earbuds",
        "price": 79.9,
        "clicks": 312
      }
    ],
    "latestProducts": [
      {
        "id": "665f2b884b2e8a0012a3ca19",
        "name": "Desk lamp",
        "price": 129.9,
        "clicks": 4
      }
    ]
  }
}
```

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `totalProducts` | number | Total de produtos na vitrine. |
| `totalCategories` | number | Total de categorias. |
| `totalClicks` | number | Soma de todos os cliques em produtos. |
| `topProducts` | array | Até 5 produtos mais clicados. |
| `latestProducts` | array | Até 5 produtos adicionados mais recentemente. |
