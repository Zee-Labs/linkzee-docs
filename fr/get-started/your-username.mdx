Votre page Linkzee se trouve à une adresse publique construite à partir de votre
nom d'utilisateur : `linkz.ee/your-name`. C'est le lien que vous partagerez dans
votre bio Instagram, TikTok ou WhatsApp, alors autant bien le choisir.

## Règles du nom d'utilisateur

Votre nom d'utilisateur doit respecter quelques règles pour que votre lien
fonctionne partout :

- Au moins **3 caractères**.
- **Minuscules** uniquement.
- Lettres, chiffres et traits d'union — **pas d'espaces ni d'accents**.
- **Unique** sur Linkzee — si quelqu'un l'a déjà, il vous en faudra un autre.

## Conseils pour un bon nom d'utilisateur

- Gardez-le **court et facile à retenir** pour que les gens puissent le taper de mémoire.
- Faites-le correspondre à votre **@ sur les réseaux sociaux** quand c'est possible,
  pour que votre audience vous reconnaisse instantanément sur chaque plateforme.

## Quand le choisir

Vous choisissez votre nom d'utilisateur pendant l'**onboarding**, juste après
avoir créé votre compte. Vous pouvez le **modifier plus tard** depuis les
paramètres de votre compte quand vous le souhaitez.

<Note>
  Modifier votre nom d'utilisateur change votre lien public partout — l'ancien
  `linkz.ee/your-name` cessera de fonctionner. Pensez à le mettre à jour dans toutes vos bios.
</Note>
