L'écran **Liens** est l'endroit où vous construisez votre page — c'est le point
de départ de votre Linkzee. C'est d'ici que vous ajoutez tout ce que vos abonnés
verront et que vous l'organisez exactement comme vous le souhaitez.

## Ajoutez votre premier élément

En haut de l'écran, vous trouverez un bouton **+ Ajouter** en pleine largeur.
Appuyez dessus pour ajouter l'un des trois types d'éléments :

<CardGroup cols={3}>
  <Card title="Lien" icon="link" href="/fr/your-page/links">
    Un bouton qui pointe vers n'importe quelle adresse web.
  </Card>
  <Card title="Produit" icon="store" href="/fr/products/overview">
    Une offre de marketplace dans votre vitrine de produits.
  </Card>
  <Card title="Réseau social" icon="share-nodes" href="/fr/your-page/social-networks">
    Des icônes qui renvoient vers vos profils de réseaux sociaux.
  </Card>
</CardGroup>

## Autres blocs que vous pouvez ajouter

Au-delà des liens, des produits et des icônes de réseaux sociaux, le menu
**+ Ajouter** propose des blocs qui apparaissent sous forme de cartes sur
votre page. Chacun peut être glissé à n'importe quelle position, comme un
lien :

| Bloc | Ce qu'il fait |
| --- | --- |
| **Avis** | Vos avis vérifiés provenant de rendez-vous réels — voir [Bloc d'avis](/fr/your-page/reviews-block) |
| **Carte** | L'adresse de votre activité, avec une carte qui ouvre l'itinéraire |
| **Avis sur Google** | Un bouton qui envoie les visiteurs directement vers votre page d'avis Google |
| **Soutien PIX** | Une carte de pourboire pour que vos fans vous soutiennent directement — voir [Partager et soutenir](/fr/your-page/share-and-support) |
| **Réservation** | La carte qui ouvre votre agenda, ajoutée quand vous activez l'[Agenda](/fr/scheduling/overview) |

<Note>
  Les blocs n'apparaissent que lorsqu'ils ont quelque chose à montrer. Le bloc
  d'avis reste masqué tant que vous n'avez pas d'avis ; la carte a besoin
  d'une adresse. Votre page n'affiche jamais de section vide.
</Note>

### Le bloc Carte

Ajoutez votre **adresse** et la carte affiche un plan avec un bouton
**Itinéraire** qui ouvre l'application de cartes du visiteur. Vous pouvez
choisir l'apparence de la carte — **claire**, **sombre**, ou **auto** pour
suivre le thème de votre page.

### Évaluez-nous sur Google

Collez votre **URL d'avis Google** (depuis votre fiche d'établissement
Google) et la carte envoie les visiteurs directement vers votre formulaire
d'avis — un moyen simple de transformer les clients satisfaits en avis
publics. Les clics sur la carte sont mesurés comme pour n'importe quel lien.

## Gérez chaque élément

Chaque élément de l'écran Liens vous offre le même ensemble de contrôles :

| Contrôle | Ce qu'il fait |
| --- | --- |
| Poignée de déplacement | Réordonner l'élément au sein de son groupe |
| Crayon | Modifier le titre directement |
| URL | L'adresse vers laquelle pointe l'élément |
| Bouton d'activation | Afficher ou masquer l'élément sur votre page |
| Compteur de clics | Voir combien de clics l'élément a reçus |
| Supprimer | Retirer l'élément — une confirmation vous sera demandée |

## Comment les éléments sont regroupés

Les éléments restent organisés en groupes fixes pour que votre page reste
toujours bien rangée :

- **Les produits restent toujours regroupés ensemble** dans votre vitrine, à une
  position fixe.
- **Les liens restent regroupés ensemble** dans leur propre section.

Le glisser-déposer réordonne vos **liens** *au sein* de leur section — il ne
mélange jamais les produits avec les liens. Votre vitrine de produits est classée
automatiquement, avec vos produits les plus récents en premier.

<Note>
  Tout ce que vous modifiez est enregistré automatiquement — il n'y a pas de
  bouton **Enregistrer**. Sur ordinateur, votre page se met à jour en direct dans
  l'aperçu du téléphone à droite ; sur mobile, l'aperçu apparaît sous l'éditeur.
</Note>
