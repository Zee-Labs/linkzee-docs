Quand toutes les visites arrivent par le même lien, impossible de savoir si votre
client vous a trouvé sur Instagram, sur WhatsApp ou grâce à la plaque sur votre
comptoir. Linkzee règle cela avec **un lien court pour chaque endroit** où vous
partagez votre page. Tous ouvrent votre page habituelle — rien ne change pour vos
visiteurs — et les [statistiques](/fr/analytics/overview) montrent d'où vient
chaque visite.

## Partagez votre page

Touchez **Partager** (dans le menu latéral, ou en haut de l'écran sur votre
téléphone) pour ouvrir la fenêtre de partage :

<Steps>
  <Step title="Choisissez où vous allez le coller">
    Sous **Où allez-vous le coller ?**, choisissez le réseau ou l'endroit :
    Instagram, TikTok, WhatsApp, YouTube, Facebook, **QR imprimé**,
    **Réservation** ou **Ailleurs**. **Plus de réseaux** ajoute Threads, X,
    LinkedIn, Pinterest et E-mail.
  </Step>
  <Step title="Choisissez l'emplacement sur ce réseau">
    Quand un réseau propose plusieurs emplacements, choisissez-le — pour
    Instagram : **Bio**, **Stories** ou **Message privé**. Une astuce vous indique
    exactement où coller le lien.
  </Step>
  <Step title="Copiez">
    Touchez **Copier le lien** (ou **Envoyer** sur votre téléphone pour l'envoyer
    directement dans une application).
  </Step>
</Steps>

Chaque lien est votre adresse suivie d'un code court — par exemple
`linkz.ee/votre-nom/ig` pour la bio Instagram et `linkz.ee/votre-nom/igs` pour les
Stories. Ces liens sont **gratuits dans tous les forfaits**.

| Endroit | Emplacements |
| --- | --- |
| Instagram | Bio · Stories · Message privé |
| TikTok | Bio |
| WhatsApp | Message · Statut |
| YouTube | Chaîne · Description |
| Facebook, Threads, X, LinkedIn, Pinterest | Profil |
| E-mail | Signature |
| QR imprimé | Imprimé · Réseaux sociaux |

- **Réservation** vous donne un lien qui ouvre **directement votre agenda**, en
  indiquant d'où vient le client (Instagram, WhatsApp, une publicité ou ailleurs).
- **Ailleurs** est votre adresse habituelle, `linkz.ee/votre-nom`. Les visites par
  ce lien apparaissent en **Direct** ou sous le site d'où elles viennent.
- **Lien pour Google Analytics et les publicités** (sous le lien court) mène au
  même endroit, avec les paramètres UTM écrits en entier, pour les plateformes
  publicitaires et les outils qui en ont besoin.

<Note>
  Les visites arrivées par un lien court apparaissent dans **Statistiques → D'où
  ils viennent** sous ce réseau et cet emplacement — par exemple **Instagram ·
  Stories**. Les chiffres se renouvellent environ toutes les heures.
</Note>

## Liens de campagne

Un lien de campagne est un lien à vous pour **une promotion, un partenariat ou une
carte imprimée**. Vous choisissez son nom et sa fin — par exemple
`linkz.ee/votre-nom/blackfriday` — et les statistiques montrent les visites, le %
qui a cliqué et les réservations (ou contacts) qu'il a apportés.

| Forfait | Liens de campagne actifs |
| --- | --- |
| Free | — |
| Essential | Jusqu'à 10 |
| Pro et Scale | Illimités |

Pour en créer un, ouvrez la fenêtre de partage et touchez **Créer un lien de
campagne** :

1. Saisissez le **Nom de la campagne**. Il apparaît aussi dans l'adresse pour
   ceux qui ouvrent le lien.
2. Sous **Où vous allez l'utiliser**, choisissez le réseau et l'emplacement.
3. Vérifiez la **Fin du lien** proposée par Linkzee, ou tapez la vôtre (de 2 à 24
   lettres minuscules, chiffres ou tirets).
4. Si vous le souhaitez, ouvrez **Personnaliser les paramètres UTM** (avancé).
5. Touchez **Créer et copier**. Vous pouvez aussi télécharger tout de suite le QR
   code du lien.

Vous pouvez aussi créer et gérer vos liens de campagne dans **Statistiques → D'où
ils viennent → Liens de campagne**, où chacun propose copier, QR code, archiver et
une vue détaillée.

<Note>
  Les liens de campagne ne sont jamais supprimés, seulement **archivés** — ainsi
  rien de ce que vous avez imprimé ne se met à pointer ailleurs, et une fin de lien
  n'est jamais réutilisée. Un lien archivé continue d'ouvrir votre page, et le
  désarchiver le fait de nouveau compter dans la limite de votre forfait. Pour
  modifier les paramètres d'un lien, créez-en un nouveau. Si vous changez de
  forfait, les liens déjà partagés continuent de fonctionner.
</Note>

## QR code et plaque

Dans la fenêtre de partage, touchez le bouton **QR code** en haut, ou choisissez
**QR imprimé** puis **QR code et plaque**. Choisissez l'usage :

| Usage | Formats | Fichiers |
| --- | --- | --- |
| **À imprimer** | **Plaque A5** · **Carré** (autocollant) | **PDF pour l'imprimeur** avec 3 mm de fond perdu, ou **PNG** en 300 dpi pour imprimer chez vous |
| **Pour les réseaux** | **Story** · **Publication** | **PNG**, prêt à publier |

- **Style** : **Clair** ou **Sombre**. La plaque est en noir et blanc, elle
  s'imprime donc bien partout ; le code lui-même est toujours foncé sur une carte
  blanche, ce que les appareils photo des téléphones lisent le mieux.
- **Titre** : choisissez un titre prêt à l'emploi — par exemple *« Réservez votre
  créneau »* (si votre page a l'agenda), *« Découvrez nos services »* ou
  *« Parlez-nous »*. La plaque est rédigée dans la langue de votre page.
- La plaque affiche votre logo (ou vos initiales), votre adresse et *« Créé avec
  Linkzee »*.

Les visites venant du code imprimé apparaissent dans les statistiques sous **QR
imprimé**, et celles de la version pour les réseaux sous **QR imprimé · Réseaux
sociaux**.

<Warning>
  Le QR code contient votre adresse. Si vous changez de nom d'utilisateur, prévoyez
  une réimpression : si vous avez déjà téléchargé un QR code ou une plaque, Linkzee
  vous prévient sur l'écran de l'adresse avant le changement. Voir [Votre nom d'utilisateur](/fr/get-started/your-username).
</Warning>

## Confidentialité

Les liens suivis utilisent la mesure propre et anonyme de Linkzee, sans cookies
tiers. La provenance de chaque visite sert uniquement aux statistiques de votre
boutique et n'est jamais partagée.
