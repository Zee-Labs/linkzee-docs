Linkzee fonctionne avec **n'importe quel agent compatible MCP**, pas seulement
Claude. Si votre outil prend en charge MCP, vous pouvez le connecter à Linkzee et
gérer votre page en langage naturel : **ChatGPT**, **Cursor**, des outils
d'automatisation et bien d'autres.

## Connectez votre client

<Steps>
  <Step title="Créez une clé API">
    Dans votre tableau de bord, ouvrez **Paramètres**, **API et MCP**, et créez
    une clé API. Choisissez **write** si l'agent doit modifier votre page (elle
    permet aussi de lire), ou **read** pour un agent en lecture seule. Consultez
    [Clés API](/fr/integrations/api/api-keys) pour le guide complet.
  </Step>
  <Step title="Ajoutez un serveur MCP">
    Dans votre client, ajoutez un nouveau serveur MCP (Streamable HTTP) pointant vers :

    ```
    https://api.linkz.ee/mcp
    ```
  </Step>
  <Step title="Fournissez votre clé API">
    Envoyez votre clé dans l'en-tête d'autorisation :

    ```
    Authorization: Bearer lzk_your_key
    ```

    Pour les clients configurés en JSON, le bloc ressemble généralement à ceci :

    ```json
    {
      "mcpServers": {
        "linkzee": {
          "type": "http",
          "url": "https://api.linkz.ee/mcp",
          "headers": { "Authorization": "Bearer lzk_your_key" }
        }
      }
    }
    ```
  </Step>
  <Step title="Demandez en langage naturel">
    Une fois connecté, parlez à votre agent comme vous parleriez à un assistant :
    « ajoute ce produit », « qu'est-ce qui est réservé cette semaine ? » ou
    « change mon thème ».
  </Step>
</Steps>

<Note>
  Chaque client ajoute les serveurs MCP d'une manière légèrement différente.
  Consultez la documentation de votre client pour savoir où coller le point de
  terminaison et l'en-tête. La connexion avec votre compte Linkzee (OAuth), sans
  clé, fonctionne avec le connecteur Claude et avec les applications qui
  s'exécutent sur votre propre ordinateur. Les autres clients hébergés utilisent
  une clé API.
</Note>

## Envoyer des photos et des vidéos

Beaucoup d'applications de conversation montrent vos pièces jointes au modèle mais
ne transmettent pas le fichier aux outils. Lorsque l'agent n'a pas d'URL publique
pour une photo ou une vidéo, il utilise un **lien d'envoi** :

1. L'agent appelle `create_upload_link` et vous donne une page comme
   `https://linkz.ee/u/...`.
2. Vous l'ouvrez sur votre téléphone ou votre ordinateur et choisissez les
   fichiers (jusqu'à 10 ; photos jusqu'à 8 Mo, vidéos jusqu'à 40 Mo). Le lien
   reste ouvert pendant 15 minutes.
3. Vous prévenez l'agent que vous avez terminé. Il lit les fichiers avec
   `get_upload` et utilise chaque `uploadId` au bon endroit de votre page.

Les agents qui ont accès aux fichiers (Cursor, scripts, automatisations) peuvent
aussi envoyer les fichiers directement vers ce même lien. Lorsqu'une photo est déjà
en ligne, l'agent transmet simplement son URL publique. Voir
[Envoyer des fichiers](/fr/integrations/mcp/sending-files).
