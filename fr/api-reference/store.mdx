Une boutique porte une page publique : son nom, sa bio, ses identifiants de
réseaux sociaux, son design, ses cartes spéciales, ses champs SEO, ses paramètres
de suivi et de marketing. Un même compte Linkzee peut réunir **plusieurs
boutiques**, ces endpoints agissent donc toujours sur **une seule** d'entre elles :
celle à laquelle votre clé d'API est liée.

Toutes les requêtes sont adressées à `https://api.linkz.ee` et doivent inclure
votre clé d'API :

```
Authorization: Bearer lzk_your_key
```

<Note>
  Les lectures nécessitent la portée **read**. Les modifications nécessitent une
  clé disposant de la portée **write**. Pour travailler sur une autre boutique,
  utilisez une clé créée dans cette boutique. Voir
  [Authentification](/fr/api-reference/authentication).
</Note>

## Récupérer le profil de la boutique

```
GET /v1/store
```

Renvoie la vue propriétaire de la boutique. C'est une **liste autorisée** : seuls
les champs ci-dessous sont renvoyés, et jamais les secrets. C'est la même vue que
celle renvoyée par l'outil MCP `get_store`.

### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/store
```

### Ce que contient la vue

| Groupe | Champs |
| --- | --- |
| Profil | `id`, `name`, `slug`, `bio`, `bioSignature`, `seoTitle`, `seoDescription`, `timezone`, `location`, `publicPreferences`, `publicUrl`, `pageHidden` |
| Design | `themeId`, `overrides`, couleurs (`themeColor`, `buttonColor`, `buttonTextColor`, `buttonShadowColor`, `textColor`), `themeMode`, champs de fond (`background`, `bgColor2`, `bgFill`, `bgAngle`, `gradientPreset`, `bgAnimated`, `wallpaperUrl` et ses options, options aurora, mesh et pattern), boutons (`buttonStyle`, `buttonRadius`, `buttonShadow`, `buttonText`), `fontId`, `fontPairId`, `cardStyle`, `cardRadius`, `texture`, `motionLevel`, `stageMode`, `saleStyle`, `socialStyle`, `avatarFx`, `wallpaperVideo` |
| En-tête | `headerLayout`, `titleStyle`, `logoUrl`, `bannerUrl`, `headerSettings` (`heroMedia`, `heroAvatar`, `shapeId`, `shapeColor`, `wordmarkUrl`, `heroPhotoUrl`, `cutoutUrl`, `heroVideo`) |
| Réseaux sociaux | `social`, `whatsapp`, `socialsPosition`, `socialOrder`, `socialCards` |
| Vitrine et cartes | `vitrineEnabled`, `vitrineStyle`, `gridDensity`, `vitrineLayout`, `vitrinePhotoFit`, `mapAddress`, `mapTheme`, `mapLayout`, `openingHours`, `servicesEnabled`, `packagesEnabled`, `instagramEnabled`, `googleReviewEnabled`, `googleReviewUrl`, `reviewsBlock` |
| Assistant IA | `aiAssistantTone`, `aiEmoji` |
| Pourboires PIX | `tips` sous forme de résumé : `enabled`, `pixKeyType`, `pixKeyPreview` (4 derniers caractères), `recipientName`. Jamais la clé. |
| Agenda | Réglages `agenda` (sans données personnelles). |
| Webhook de leads | `leadWebhook` avec uniquement `host` et `enabled`. Jamais le chemin ni le secret de signature. |
| Suivi | `tracking` : identifiants des pixels, `gtmId`, UTM par défaut et `capiTokenConfigured`. Jamais le jeton de l'API Conversions. |

<Note>
  `pageHidden: true` signifie que la page publique est désactivée
  (`isActive: false`). L'ancien champ racine `instagram` est encore renvoyé pour
  les anciens lecteurs ; utilisez `social.instagram`.
</Note>

## Modifier le profil de la boutique

```
PATCH /v1/store
```

Modifie un ou plusieurs champs de la boutique. N'envoyez que les champs que vous
souhaitez changer ; tout ce que vous omettez reste inchangé. Les modifications
sont appliquées immédiatement sur la page publique.

### Requête

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
        "bio": "Brows and lashes in Pinheiros. Book online in two taps.",
        "themeId": "editorial",
        "socialsPosition": "top",
        "publicPreferences": { "locale": "en" }
      }' \
  https://api.linkz.ee/v1/store
```

### Paramètres

Chaque champ est facultatif ; n'envoyez que ce que vous souhaitez changer.

| Paramètre | Type | Description |
| --- | --- | --- |
| `name` | string | Nom d'affichage de la boutique (120 caractères max.). |
| `bio` | string | Courte description affichée sous le nom (500 caractères max.). |
| `bioSignature` | string | Signature sur une ligne sous la bio (60 caractères max., sans saut de ligne). |
| `titleStyle` | string | Style du titre de l'en-tête : `text` ou `logo`. |
| `logoUrl`, `bannerUrl`, `wallpaperUrl` | string | URL d'images. Envoyez-les d'abord avec [`POST /v1/uploads/image`](/fr/api-reference/uploads). |
| `headerLayout` | string | `classic`, `hero`, `banner`, `cutout` ou `shape`. |
| `headerSettings` | object | Détails de l'en-tête : `wordmarkUrl`, `heroPhotoUrl`, `cutoutUrl`, `heroMedia`, `heroAvatar`, `shapeId`, `shapeColor`, `frames` et `media` (les dispositions et emplacements hors de la liste autorisée sont écartés, et les valeurs sont bornées). |
| `themeId` | string | Id d'un thème prêt à l'emploi (voir le catalogue de thèmes ci-dessous). |
| `overrides` | string[] | Avancé : les sections de design personnalisées par-dessus `themeId`. |
| Champs de design | divers | Les mêmes champs de design que l'outil MCP `update_design` : couleurs, `themeMode`, fond, boutons, `fontId`, `fontPairId`, `cardStyle`, `cardRadius`, `texture`, `motionLevel`, `stageMode`, `saleStyle`, `vitrineStyle`, `socialStyle`, `avatarFx`. |
| `social` | object | Identifiants des réseaux sociaux, par exemple `{ "instagram": "handle", "tiktok": "handle" }`. Une chaîne vide retire un réseau. |
| `whatsapp` | string | Numéro avec l'indicatif du pays, chiffres uniquement. |
| `socialsPosition` | string | Emplacement de la rangée de réseaux sociaux : `top` ou `bottom`. |
| `socialOrder` | string[] | Ordre d'affichage des icônes de réseaux sociaux. Uniquement des clés de réseau valides (`whatsapp`, `instagram`, `tiktok`, `youtube` et les autres). |
| `productsPosition` | string | Position de la vitrine par rapport aux liens : `top` ou `bottom`. |
| `vitrineEnabled`, `vitrineLayout`, `vitrineStyle`, `gridDensity`, `vitrinePhotoFit` | divers | Réglages de la vitrine. `vitrineLayout` : `grid`, `masonry` ou `carousel`. `vitrineStyle` : `classic` ou `spotlight`. |
| `servicesEnabled`, `packagesEnabled`, `instagramEnabled` | boolean | Active ou désactive les cartes des services, des forfaits et d'Instagram. |
| `googleReviewEnabled`, `googleReviewUrl` | boolean, string | Carte d'avis Google (lien Google Maps, `g.page` ou `g.co`). |
| `reviewsBlock` | object | Carte des avis : `added`, `enabled`, `layout`, `limit` (de 1 à 10), `minRating` (de 1 à 5). |
| `mapAddress`, `mapTheme`, `mapLayout` | string | Carte de localisation. Un `mapAddress` vide la retire ; `mapLayout` vaut `map` ou `card`. |
| `openingHours` | object | Le badge « ouvert maintenant » : `source`, `showStatus`, `week`, `closedDates`. |
| `agenda` | object | Réglages de réservation, fusionnés partiellement. Voir la [référence Agenda](/fr/api-reference/agenda). |
| `tips` | object | Carte de pourboires PIX : `enabled`, `pixKey`, `pixKeyType` (`email` ou `random`), `recipientName` (25 max.), `recipientCity` (15 max.), `message`, `amounts`, `thanksMessage`, `highlight`. Avec une clé, le nom et la ville sont obligatoires. Le propriétaire reçoit un e-mail lorsque la clé change. |
| `timezone` | string | Fuseau horaire IANA, par exemple `America/Sao_Paulo`. Un nom invalide renvoie `400`. |
| `location` | object | `countryCode` (ISO 2 lettres), `state`, `city`. Détermine le calendrier des jours fériés. |
| `publicPreferences` | object | `locale` de la page publique (`pt-BR`, `en`, `es`, `fr`, `de`) et `translationFallback` (`original` ou `dashboardLocale`). **Fusionné** avec ce qui est enregistré : n'envoyer que `locale` conserve la valeur de secours. |
| `seoTitle` | string | Titre de la page publique pour les moteurs de recherche (70 caractères max.). |
| `seoDescription` | string | Méta-description de la page publique (160 caractères max.). |
| `gtmId` | string | Id du conteneur Google Tag Manager, par exemple `GTM-ABC123`. |
| `utmSource`, `utmMedium`, `utmCampaign` | string | Paramètres UTM par défaut ajoutés aux liens sortants. |
| `pixels` | object | Ids des pixels de suivi : `metaPixelId`, `tiktokPixelId`, `gaMeasurementId`. |
| `capiToken` | string | Jeton de l'API Conversions de Meta. Envoyé en clair, stocké chiffré. Une valeur vide signifie « conserver l'actuel ». |
| `isActive` | boolean | Indique si la page publique est en ligne. `false` la masque. |

### Héritage du thème

Les modifications via l'API suivent les mêmes règles que l'éditeur :

- `themeId` **sans** `overrides` applique le thème prédéfini en repartant de
  zéro : les personnalisations et le niveau d'animation enregistrés auparavant
  sont réinitialisés.
- Tout autre champ de design sur une boutique avec thème prédéfini personnalise
  **uniquement sa section** (couleurs, fond d'écran, boutons, texte, dégradé,
  carte, texture, animation), qui part de la palette du thème. Le reste continue
  de suivre le thème.
- Les couleurs identiques à la palette du thème ne comptent pas comme couleurs
  personnalisées, elles ne déclenchent donc pas le contrôle premium. Les valeurs
  payantes (boutons en verre, fonds image, mesh, duotone ou vidéo, dégradés
  animés ou prédéfinis, couleurs personnalisées, polices payantes, `stageMode`)
  renvoient `403` avec `code: "PLAN_REQUIRED"` sur une offre gratuite.
- Envoyez `overrides` lorsque vous voulez lister vous-même les sections
  personnalisées.

<Warning>
  Le `slug` de la boutique ne peut pas être modifié via l'API. L'envoyer n'a
  aucun effet : il est ignoré afin que votre lien de bio publié ne soit jamais
  cassé.
</Warning>

### Réponse

La réponse est la même vue en liste autorisée que `GET /v1/store`, plus
`agentNotes` lorsqu'il y a quelque chose à signaler :

```json
{
  "error": false,
  "message": "Store updated successfully",
  "data": {
    "id": "665f1c9a4b2e8a0012a3c9d1",
    "name": "Studio Ana",
    "bio": "Brows and lashes in Pinheiros. Book online in two taps.",
    "themeId": "editorial",
    "overrides": [],
    "socialsPosition": "top",
    "publicPreferences": { "locale": "en", "translationFallback": "original" },
    "pageHidden": false,
    "agentNotes": {
      "warnings": []
    }
  }
}
```

`agentNotes.warnings` liste les champs enregistrés mais pas encore visibles (par
exemple un en-tête `cutout` sans image détourée, ou un `wallpaperUrl` sans fond
de type image). Lorsque la clé PIX ou le numéro WhatsApp change, `agentNotes`
indique aussi le changement avec uniquement les 4 derniers caractères.

<Note>
  L'ordre de la vitrine n'est pas un champ de la boutique. Il suit les plus
  récents d'abord jusqu'au premier
  [`PUT /v1/products/order`](/fr/api-reference/products) qui le modifie ; à
  partir de là, la vitrine suit votre ordre manuel.
</Note>

## Parcourir le catalogue de thèmes

```
GET /v1/themes
```

Liste les **23** thèmes prêts à l'emploi que vous pouvez appliquer avec
`themeId`. Chaque entrée inclut une courte description pour vous aider à associer
un style à l'esprit d'une boutique, et `premium` pour les thèmes payants.

### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/themes
```

### Réponse

```json
{
  "error": false,
  "message": "Themes loaded",
  "data": [
    {
      "id": "pure",
      "name": "Pure",
      "mode": "light",
      "description": "Minimal light, near-white background, full focus on the products.",
      "premium": false
    },
    {
      "id": "noir",
      "name": "Noir",
      "mode": "dark",
      "description": "Sober dark, graphite grey, elegant and neutral.",
      "premium": false
    }
  ]
}
```

Le catalogue complet compte 23 thèmes. Gratuits : `pure`, `noir`, `gesso`, `solar`, `midnight`, `groove`, `carbon`, `oceano`, `neon`, `pessego`, `selva`, `aurora`, `brutalista`, `editorial`, `pista`. Payants : `motion-neon`, `motion-clean`, `motion-achadinhos`, `motion-boutique`, `onix`, `cinema`, `perola`, `iridescente`.

<Note>
  Utilisez n'importe quel `id` de cette liste comme `themeId` lorsque vous
  modifiez la boutique. Les `id` sont stables ; `name` et `description` sont
  informatifs et renvoyés en anglais.
</Note>

## Récupérer un résumé des performances

```
GET /v1/analytics/summary
```

Renvoie les indicateurs clés de la vitrine : les totaux ainsi que les produits les
plus populaires et les plus récents.

### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/analytics/summary
```

### Réponse

```json
{
  "error": false,
  "message": "Dashboard retrieved successfully",
  "data": {
    "totalProducts": 42,
    "totalCategories": 6,
    "totalClicks": 1873,
    "topProducts": [
      {
        "id": "665f2a114b2e8a0012a3ca07",
        "name": "Bluetooth earbuds",
        "price": 79.9,
        "clicks": 312
      }
    ],
    "latestProducts": [
      {
        "id": "665f2b884b2e8a0012a3ca19",
        "name": "Desk lamp",
        "price": 129.9,
        "clicks": 4
      }
    ]
  }
}
```

| Champ | Type | Description |
| --- | --- | --- |
| `totalProducts` | number | Nombre total de produits dans la vitrine. |
| `totalCategories` | number | Nombre total de catégories. |
| `totalClicks` | number | Somme de tous les clics sur les produits. |
| `topProducts` | array | Jusqu'à 5 produits les plus cliqués. |
| `latestProducts` | array | Jusqu'à 5 produits ajoutés le plus récemment. |
