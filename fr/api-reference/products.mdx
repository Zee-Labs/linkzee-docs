Les produits sont les articles de votre vitrine publique. Chaque produit possède un
nom, un prix facultatif, une image et un lien d'affiliation ou de produit. Utilisez
ces endpoints pour garder votre catalogue synchronisé depuis vos propres systèmes.

Toutes les requêtes sont adressées à `https://api.linkz.ee` et doivent inclure votre clé API :

```
Authorization: Bearer lzk_your_key
```

<Note>
La lecture des produits (`GET`) nécessite la portée **read**. La création, la
modification, la suppression ou le réordonnancement d'un produit nécessite une clé
disposant de la portée **write**.
</Note>

## Ordre de la vitrine

La vitrine a deux modes d'ordre :

- **Les plus récents d'abord** (par défaut) : les produits les plus récents
  apparaissent en premier.
- **Manuel** : activé par le premier réordonnancement (voir « Réordonner les
  produits » ci-dessous) qui modifie l'ordre que voient les visiteurs. À partir de
  là, la vitrine suit l'`order` de chaque produit, et les nouveaux produits
  arrivent en haut.

`GET /v1/products`, l'outil MCP `list_products` et la page publique renvoient
toujours les produits dans l'ordre que voient les visiteurs. Il n'existe pas
d'endpoint pour revenir à l'ordre des plus récents d'abord.

## Lister les produits

```
GET /v1/products
```

Renvoie tous les produits de votre boutique, dans l'ordre de la vitrine.

### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/products
```

## Récupérer un produit

```
GET /v1/products/{id}
```

Renvoie un seul produit par son ID. La réponse est une liste autorisée des champs
du produit (la même vue que l'outil MCP `get_product`) ; les champs internes ne
sont jamais renvoyés.

### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/products/665f1a2b9c4e1f0012a3b4c5
```

### Paramètres

| --- | --- | --- | --- |
| `id` | string (path) | Oui | L'ID du produit. |

## Créer un produit

```
POST /v1/products
```

Crée un produit dans votre vitrine. Nécessite la portée **write**.

Vous pouvez soit envoyer directement les champs du produit, soit envoyer uniquement
une `url` de marketplace et laisser Linkzee récupérer pour vous le nom, le prix et
l'image. Si la recherche automatique revient incomplète, envoyez au moins `name`
pour que le produit puisse être enregistré.

### Requête

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: sync-SKU-1042" \
  -d '{
    "name": "Wireless Headphones XYZ",
    "description": "Bluetooth 5.3, 30h battery",
    "price": 99.9,
    "priceOriginal": 149.9,
    "imageUrl": "https://example.com/headphones.jpg",
    "externalLink": "https://shopee.com.br/product/123",
    "badge": "Deal",
    "isFeatured": true,
    "externalId": "SKU-1042"
  }' \
  https://api.linkz.ee/v1/products
```

### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `name` | string | Conditionnel | Nom du produit (160 max.). Facultatif lorsque `url` est envoyé : il est rempli à partir de la recherche sur la marketplace. |
| `url` | string | Non | URL de la marketplace. Lorsqu'elle est envoyée sans `name` ni `price`, Linkzee tente de les remplir automatiquement. |
| `slug` | string | Non | Slug personnalisé (80 max.). Dérivé du nom lorsqu'il est omis ; unique par boutique. |
| `description` | string | Non | Description courte (2000 max.). |
| `price` | number | Non | Prix actuel en R$. Omettez-le pour un produit « sans prix ». |
| `priceOriginal` | number | Non | Prix d'origine, utilisé pour afficher une remise. |
| `installments` | string | Non | Texte de paiement en plusieurs fois, par exemple `3x of R$ 33.30` (80 max.). |
| `imageUrl` | string | Non | URL de l'image principale (http ou https). Les URL externes sont copiées sur le CDN de Linkzee. |
| `gallery` | string[] | Non | Jusqu'à 10 URL d'images supplémentaires. |
| `externalLink` | string | Non | Lien d'affiliation ou de produit (http ou https). Un produit sans lien reste un brouillon masqué. |
| `buttonText` | string | Non | Libellé de l'appel à l'action (60 max.), par exemple `Buy`. |
| `badge` | string | Non | Étiquette promo courte (28 max.), par exemple `Deal`. |
| `categoryId` | string | Non | ID de la catégorie à laquelle appartient ce produit. |
| `isActive` | boolean | Non | Indique si le produit est visible dans la vitrine. Vaut `true` par défaut. |
| `isFeatured` | boolean | Non | Ajoute le produit au carrousel des produits mis en avant. |
| `highlightFx` | string | Non | Mise en avant animée (Premium) : `""`, `"shake"`, `"shine"`, `"pulse"` ou `"bounce"`. |
| `cardSize` | string | Non | `normal` ou `wide` (une carte `wide` s'étend sur les deux colonnes de la grille). |
| `offerEndsAt` | string | Non | Date de fin de l'offre (ISO 8601). |
| `offerDurationMinutes` | number | Non | Durée du compte à rebours d'urgence, en minutes (relative, redémarre pour chaque visiteur). |
| `showCountdown` | boolean | Non | Affiche le compte à rebours sur la carte. |
| `externalId` | string | Non | Votre propre référence pour ce produit (un identifiant CRM ou ERP, ou un SKU) afin de le faire correspondre à vos systèmes (64 max.). Jamais affichée sur votre page publique. |
| `barcode` | string | Non | Code-barres du produit : EAN, GTIN ou UPC (32 max.). Jamais affiché publiquement. |

<Note>
Envoyez un en-tête `Idempotency-Key` pour réessayer sans risque : répéter la
requête avec la même clé et le même corps dans les 24 heures renvoie le produit
créé la première fois au lieu d'un doublon. La même clé avec un corps différent
renvoie `409`. Voir [Limites de débit](/fr/api-reference/rate-limits).
</Note>

### Réponse

  "message": "Product created successfully",
  "data": {
    "id": "665f1a2b9c4e1f0012a3b4c5",
    "name": "Wireless Headphones XYZ",

## Modifier un produit

```
PATCH /v1/products/{id}
```

Met à jour n'importe quel sous-ensemble des champs d'un produit. Nécessite la
portée **write**. Seuls les champs que vous envoyez sont modifiés.

### Requête

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "price": 89.9,
    "badge": "Flash sale",
    "isActive": false
  }' \
  https://api.linkz.ee/v1/products/665f1a2b9c4e1f0012a3b4c5
```

### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `id` | string (path) | Oui | L'ID du produit. |

Le corps accepte les mêmes champs que **Créer un produit**, à l'exception de `url`
(la recherche automatique ne s'exécute qu'à la création). Tous les champs sont
facultatifs. Envoyez `categoryId: null` pour retirer le produit de sa catégorie et
`offerEndsAt: null` pour effacer la date de fin de l'offre.

### Réponse

```json
{
  "error": false,
  "message": "Product updated successfully",
  "data": {
    "id": "665f1a2b9c4e1f0012a3b4c5",
    "name": "Wireless Headphones XYZ",
    "price": 89.9,
    "badge": "Flash sale",
    "isActive": false
  }
}
```

## Supprimer un produit

```
DELETE /v1/products/{id}
```

Retire un produit de votre vitrine. Nécessite la portée **write**.

### Requête

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/products/665f1a2b9c4e1f0012a3b4c5
```

### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `id` | string (path) | Oui | L'ID du produit. |

### Réponse

```json
{
  "error": false,
  "message": "Product deleted successfully"
}
```

## Réordonner les produits

```
PUT /v1/products/order
```

Définit la position des produits dans la vitrine. Nécessite la portée **write**.
Chaque élément se place à la position indiquée par `order` (`0` est le haut) :

- Envoyez la liste **complète** pour un ordre exact.
- Envoyez uniquement les produits que vous voulez déplacer : les autres gardent
  leur ordre relatif.

Le premier réordonnancement qui modifie ce que voient les visiteurs fait passer la
vitrine en ordre manuel (voir « Ordre de la vitrine » ci-dessus).

### Requête

```bash
curl -X PUT \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "items": [
      { "id": "665f1a2b9c4e1f0012a3b4c5", "order": 0 },
      { "id": "665f1a2b9c4e1f0012a3b4c6", "order": 1 }
    ]
  }' \
  https://api.linkz.ee/v1/products/order
```

### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `items` | array | Oui | De 1 à 5000 éléments. |
| `items[].id` | string | Oui | L'ID du produit. |
| `items[].order` | integer | Oui | Nouvelle position (`0` est le haut). |

### Réponse

Renvoie les produits dans le nouvel ordre, au même format que
`GET /v1/products`.
