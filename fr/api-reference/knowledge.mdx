La base de connaissances est un ensemble de documents PDF que votre assistant IA
lit pour répondre aux questions des visiteurs. Importez des manuels de produits,
des FAQ, des catalogues ou des politiques, et l'assistant y puise ses réponses.

Le texte importé est extrait immédiatement, puis indexé de façon asynchrone afin
que l'assistant puisse le rechercher. Une boutique peut contenir jusqu'à
**10 PDF** par défaut (chacun jusqu'à **10&nbsp;Mo**).

<Note>
Toutes les requêtes utilisent l'URL de base `https://api.linkz.ee` et envoient
l'en-tête `Authorization: Bearer lzk_your_key`. L'import, la suppression et la
réindexation nécessitent une clé avec la portée **write**.
</Note>

## Lister les PDF

```
GET /v1/knowledge/files
```

Renvoie tous les PDF de votre base de connaissances, ainsi que la limite de
fichiers actuelle.

### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/knowledge/files
```

### Réponse

```json
{
  "error": false,
  "message": "Files listed",
  "data": {
    "files": [
      {
        "fileId": "8f3c1a7e-2b64-49d0-9d1e-5a2f0b7c4e11",
        "name": "product-catalog-2026.pdf",
        "sizeBytes": 482133,
        "pages": 12,
        "status": "ready",
        "createdAt": "2026-07-18T14:22:05.113Z"
      }
    ],
    "maxFiles": 10
  }
}
```

Chaque fichier indique un `status` : `ready` une fois son texte extrait, ou
`pending` tant qu'il est encore en cours de traitement.

## Importer un PDF

```
POST /v1/knowledge/files
```

Ajoute un PDF à votre base de connaissances. Envoyez-le en tant que
`multipart/form-data` avec un seul champ `file`.

### Requête

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -F "file=@product-catalog-2026.pdf" \
  https://api.linkz.ee/v1/knowledge/files
```

### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `file` | fichier (PDF) | Oui | Le PDF à importer. Taille maximale 10&nbsp;Mo. |

### Réponse

```json
{
  "error": false,
  "message": "File processed",
  "data": {
    "fileId": "8f3c1a7e-2b64-49d0-9d1e-5a2f0b7c4e11",
    "status": "ready",
    "pages": 12
  }
}
```

<Warning>
Les imports sont limités à quelques-uns par minute et par clé, car l'extraction
d'un PDF est une opération lourde. Un fichier de plus de 10&nbsp;Mo, ou une
requête qui dépasse votre limite de fichiers, renvoie `400 Bad Request`. Espacez
les imports et réessayez avec un délai progressif en cas de `429`.
</Warning>

## Supprimer un PDF

```
DELETE /v1/knowledge/files/:fileId
```

Retire un PDF de votre base de connaissances. Son texte est également supprimé de
l'index.

### Requête

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/knowledge/files/8f3c1a7e-2b64-49d0-9d1e-5a2f0b7c4e11
```

### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `fileId` | chaîne (chemin) | Oui | L'identifiant `fileId` du PDF à retirer. |

### Réponse

```json
{
  "error": false,
  "message": "File removed",
  "data": {
    "fileId": "8f3c1a7e-2b64-49d0-9d1e-5a2f0b7c4e11"
  }
}
```

## Réindexer la base de connaissances

```
POST /v1/knowledge/reindex
```

Planifie une reconstruction de l'index de recherche de l'assistant IA. La
réindexation s'exécute de façon asynchrone et les rafales de requêtes se
regroupent en une seule tâche, ce qui rend l'opération sûre après un lot d'imports
ou de suppressions.

### Requête

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/knowledge/reindex
```

### Réponse

```json
{
  "error": false,
  "message": "Reindex scheduled",
  "data": {
    "queued": true
  }
}
```

<Note>
Les imports déclenchent déjà l'indexation par eux-mêmes. N'appelez ceci que
lorsque vous souhaitez forcer une actualisation, par exemple après avoir supprimé
plusieurs fichiers.
</Note>
