Les endpoints de contenu exposent tout ce qu'un visiteur voit dans la zone de
liens d'une page — liens isolés, collections (groupes de liens) et éléments
d'assistant IA — ainsi qu'un bloc `meta` qui résume la vitrine de produits (compteurs,
puces de catégories, produits en vedette et première page du catalogue).

Toutes les requêtes sont adressées à `https://api.linkz.ee` et doivent inclure
votre clé d'API :

```
Authorization: Bearer lzk_your_key
```

<Note>
Les produits ne font pas partie de l'arborescence réordonnable. La vitrine est
ordonnée automatiquement (les plus récents d'abord), le réordonnancement
n'affecte donc que les liens, les collections et les éléments d'assistant IA. Les
entrées de produit envoyées à l'endpoint de réordonnancement sont ignorées.
</Note>

## Obtenir l'arborescence de contenu

```
GET /v1/content
```

Renvoie l'arborescence de contenu public de votre page, ainsi qu'un résumé `meta`
de la vitrine de produits.

### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/content
```

### Réponse

L'objet `data` comporte deux parties : `meta` (résumé de la vitrine) et `root`
(la liste ordonnée des entrées de contenu). Chaque entrée de `root` est de type

</Note>

`cardSize` vaut `"normal"` ou `"wide"` (une carte wide occupe les deux colonnes
de la grille) ; et `imageRatio` est un nombre (largeur de l'image divisée par sa
hauteur, par ex. `1` pour un carré).

## Réordonner le contenu

```
PUT /v1/content/order
```

Définit l'ordre de toute la zone de liens en un seul appel. Envoyez l'arborescence
complète dans l'ordre souhaité — la position de chaque entrée dans le tableau
devient son nouvel ordre. Nécessite une clé disposant de la portée **write**.

### Requête

```bash
curl -X PUT \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "root": [
      { "type": "link", "id": "507f1f77bcf86cd799439011" },
      {
        "type": "collection",
        "id": "507f1f77bcf86cd799439020",
        "children": [
          { "type": "link", "id": "507f1f77bcf86cd799439012" },
          { "type": "ai_assistant", "id": "507f1f77bcf86cd799439030" }
        ]
      }
    ]
  }' \
  https://api.linkz.ee/v1/content/order
```

### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `root` | array | Oui | Entrées de premier niveau dans leur nouvel ordre. Peut être vide. |
| `root[].type` | string | Oui | L'une des valeurs `link`, `collection`, `ai_assistant` ou `product`. |
| `root[].id` | string | Oui | L'ID de l'entrée. |
| `root[].children` | array | Non | Éléments enfants, dans l'ordre. Utilisé uniquement lorsque `type` vaut `collection`. |
| `root[].children[].type` | string | Oui | L'une des valeurs `link`, `ai_assistant` ou `product`. |
| `root[].children[].id` | string | Oui | L'ID de l'élément enfant. |

<Warning>
Les entrées de produit (à la racine ou dans une collection) sont acceptées mais
ignorées — la vitrine s'ordonne d'elle-même. N'envoyez que des entrées `link`,
`collection` et `ai_assistant` pour modifier ce qui est réellement réordonné. Les
ID inconnus sont ignorés silencieusement.
</Warning>

### Réponse

```json
{
  "error": false,
  "message": "Content reordered successfully",
  "data": { "ok": true }
}
```
