Les endpoints Agenda vous permettent de piloter votre agenda de réservation par
programmation : définir les **Services** que les gens peuvent réserver, votre
**équipe**, les **blocages** quand vous êtes absent, consulter la
**disponibilité** réelle pour créer et gérer les **réservations**, modérer les
**avis** que vous recevez et gérer la **liste d'attente**.

Tous les chemins se trouvent sous `https://api.linkz.ee/v1/agenda`. Chaque requête
nécessite l'en-tête `Authorization: Bearer lzk_your_key`, et les opérations
d'écriture (POST/PATCH/DELETE) requièrent une clé disposant du scope **write**.

<Note>
Les lectures (`GET`) fonctionnent avec n'importe quelle clé valide. Créer,
modifier, changer le statut, reprogrammer ou supprimer quoi que ce soit requiert
le scope **write**.
</Note>

## Services

Un service (prestation) est quelque chose que les gens peuvent réserver — une
coupe, une consultation, un appel. Chaque service a une durée et, éventuellement,
un prix.

### Lister les services

```
GET /v1/agenda/offerings
```

Renvoie tous les services de votre agenda, dans l'ordre d'affichage.

#### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/offerings
```

#### Réponse

```json
{
  "error": false,
  "message": "Services retrieved successfully",
  "data": [
    {
      "_id": "665f0a1b2c3d4e5f60718293",
      "name": "Strategy call",
      "durationMin": 45,
      "price": 150,
      "description": "A focused 45-minute planning session.",
      "color": "#2f80ed",
      "bufferAfterMin": 15,
      "meetEnabled": true,
      "order": 0,
      "isActive": true
    }
  ]
}
```

### Créer un service

```
POST /v1/agenda/offerings
```

Ajoute un nouveau service réservable.

#### Requête

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"name":"Strategy call","durationMin":45,"price":150,"meetEnabled":true}' \
  https://api.linkz.ee/v1/agenda/offerings
```

#### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `name` | string | Oui | Nom du service (max. 80 caractères). |
| `durationMin` | integer | Oui | Durée en minutes (5–720). |
| `price` | number | Non | Prix en R$. Omettez ou envoyez `null` pour un service gratuit. |
| `description` | string | Non | Description courte (max. 300 caractères). |
| `color` | string | Non | Couleur hexadécimale pour l'agenda, par ex. `#2f80ed`. |
| `bufferAfterMin` | integer | Non | Marge en minutes après chaque réservation (0–240). |
| `meetEnabled` | boolean | Non | Crée un lien Google Meet pour chaque réservation. |
| `isActive` | boolean | Non | Indique si le service est réservable. `true` par défaut. |
| `kind` | string | Non | `single` (par défaut) ou `combo`. Un combo regroupe plusieurs services simples en un seul forfait réservable. |
| `comboItemIds` | array of string | Non | Requis lorsque `kind` vaut `combo` : les identifiants de 2 à 6 services simples inclus dans le combo. |
| `chargeMode` | string | Non | Paiement en ligne : `none` (par défaut, paiement sur place), `deposit` (acompte payé d'avance) ou `full` (prix total payé d'avance — requiert un `price` supérieur à 0). |
| `chargeDepositType` | string | Non | Mode de calcul de l'acompte lorsque `chargeMode` vaut `deposit` : `percent` ou `fixed`. |
| `chargeDepositValue` | number | Non | Le montant de l'acompte : un pourcentage de 1 à 100 lorsque `chargeDepositType` vaut `percent`, ou un montant fixe dans la devise de votre boutique lorsqu'il vaut `fixed`. |

#### Réponse

```json
{
  "error": false,
  "message": "Service created successfully",
  "data": {
    "_id": "665f0a1b2c3d4e5f60718293",
    "name": "Strategy call",
    "durationMin": 45,
    "price": 150,
    "bufferAfterMin": 0,
    "meetEnabled": true,
    "order": 0,
    "isActive": true
  }
}
```

### Modifier un service

```
PATCH /v1/agenda/offerings/{id}
```

#### Requête

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"name":"Strategy call","durationMin":60,"price":180}' \
  https://api.linkz.ee/v1/agenda/offerings/665f0a1b2c3d4e5f60718293
```

#### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `id` | string | Oui | L'identifiant du service (dans le chemin). |

Le corps accepte les mêmes champs que [Créer un service](#créer-un-service).

#### Réponse

```json
{
  "error": false,
  "message": "Service updated successfully",
  "data": {
    "_id": "665f0a1b2c3d4e5f60718293",
    "name": "Strategy call",
    "durationMin": 60,
    "price": 180,

  }

```


#### Requête

```bash

  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/offerings/665f0a1b2c3d4e5f60718293
```

#### Réponse

```json
{
  "error": false,
  "message": "Service deleted successfully",
  "data": { "id": "665f0a1b2c3d4e5f60718293" }
}
```

## Équipe

L'équipe regroupe les personnes qui assurent vos services. Chacune peut avoir ses
propres horaires de travail et l'ensemble des services qu'elle propose.

### Lister l'équipe

```
GET /v1/agenda/staff
```

#### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/staff
```

#### Réponse

```json
{
  "error": false,
  "message": "ok",
  "data": [
    {
      "_id": "665f0c9a8b7d6e5f40312a11",
      "name": "Ana Souza",
      "title": "Senior consultant",
      "avatarUrl": "https://cdn.linkz.ee/staff/ana.webp",
      "hours": null,
      "offeringIds": ["665f0a1b2c3d4e5f60718293"],
      "order": 0,
      "isActive": true
    }
  ]
}
```

### Ajouter un membre de l'équipe

```
POST /v1/agenda/staff
```

#### Requête

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"name":"Ana Souza","title":"Senior consultant","offeringIds":["665f0a1b2c3d4e5f60718293"]}' \
  https://api.linkz.ee/v1/agenda/staff
```

#### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `name` | string | Oui | Nom du membre de l'équipe (max. 80 caractères). |
| `title` | string | Non | Fonction ou titre (max. 80 caractères). |
| `avatarUrl` | string | Non | URL de la photo (max. 500 caractères). |
| `hours` | array | Non | Horaires de travail hebdomadaires (voir ci-dessous). Envoyez `null` pour hériter des horaires de votre établissement. |
| `offeringIds` | array of string | Non | Services assurés par cette personne. `null` signifie tous les services. |
| `isActive` | boolean | Non | Indique si la personne est réservable. `true` par défaut. |

Chaque entrée de `hours` décrit un jour de la semaine :

| Champ | Type | Requis | Description |
| --- | --- | --- | --- |
| `day` | integer | Oui | Jour de la semaine, `0` = dimanche jusqu'à `6` = samedi. |
| `closed` | boolean | Non | Mettez `true` pour marquer le jour comme chômé. |
| `ranges` | array | Non | Plages de travail, chacune avec `startMin` et `endMin` (minutes depuis minuit, 0–1440). |

#### Réponse

```json
{
  "error": false,
  "message": "ok",
  "data": {
    "_id": "665f0c9a8b7d6e5f40312a11",
    "name": "Ana Souza",
    "title": "Senior consultant",
    "hours": null,
    "offeringIds": ["665f0a1b2c3d4e5f60718293"],
    "isActive": true
  }
}
```

#### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `id` | string | Oui | L'identifiant du membre de l'équipe (dans le chemin). |

## Blocages

Un blocage est une période pendant laquelle vous (ou un membre de l'équipe) êtes
indisponible — un jour férié, des vacances ou un jour de congé. Aucune réservation
ne peut tomber à l'intérieur d'un blocage.

<Note>
Les blocages n'ont pas d'endpoint de modification. Pour en changer un,
supprimez-le et créez-en un nouveau.
</Note>

### Lister les blocages

```
GET /v1/agenda/blocks
```

#### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/blocks
```

#### Réponse

```json
{
  "error": false,
  "message": "ok",
  "data": [
    {
      "_id": "665f0e5511aa22bb33cc44dd",
      "staffId": null,
      "startDate": "2026-12-24",
      "endDate": "2026-12-26",
      "allDay": true,
      "reason": "Holidays"
    }
  ]
}
```

### Créer un blocage

```
POST /v1/agenda/blocks
```

#### Requête

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"startDate":"2026-12-24","endDate":"2026-12-26","allDay":true,"reason":"Holidays"}' \
  https://api.linkz.ee/v1/agenda/blocks
```

#### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `startDate` | string | Oui | Premier jour bloqué, `YYYY-MM-DD`. |
| `endDate` | string | Oui | Dernier jour bloqué, `YYYY-MM-DD`. |
| `staffId` | string | Non | Bloque un seul membre de l'équipe. Omettez ou `null` bloque tout l'établissement. |
| `allDay` | boolean | Non | Indique si le blocage couvre toute la journée. `true` par défaut. |
| `startMin` | integer | Non | Minute de début depuis minuit pour un blocage partiel (0–1440). |
| `endMin` | integer | Non | Minute de fin depuis minuit pour un blocage partiel (0–1440). |
| `reason` | string | Non | Libellé court (max. 120 caractères). |

#### Réponse

```json
{
  "error": false,
  "message": "ok",
  "data": {
    "_id": "665f0e5511aa22bb33cc44dd",
    "startDate": "2026-12-24",
```

## Disponibilité

```
GET /v1/agenda/availability
```

Renvoie les jours ouverts et les créneaux horaires réels pour un service sur une
plage de dates — le même moteur qui alimente votre page de réservation publique,
donc il tient déjà compte des horaires de travail, des réservations existantes et
des blocages.

#### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  "https://api.linkz.ee/v1/agenda/availability?offeringId=665f0a1b2c3d4e5f60718293&from=2026-07-21&to=2026-07-25&detail=slots"
```

#### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `offeringId` | string | Oui | Le service à vérifier. |
| `from` | string | Oui | Date de début, `YYYY-MM-DD` (dans le fuseau horaire de votre agenda). |
| `to` | string | Oui | Date de fin, `YYYY-MM-DD`. |
| `staffId` | string | Non | Limite la disponibilité à un seul membre de l'équipe (mode équipe). |
| `extraOfferingIds` | string | Non | Identifiants, séparés par des virgules, de 4 services supplémentaires maximum réservés avec le service principal (un panier). La disponibilité tient alors compte de la durée combinée. |
| `detail` | string | Non | `days` (par défaut) renvoie uniquement l'état par jour ; `slots` renvoie aussi les heures de début réservables. |

#### Réponse

```json
{
  "error": false,
  "message": "Availability retrieved successfully",
  "data": {
    "days": [
      { "date": "2026-07-21", "state": "free", "density": "low" },
      { "date": "2026-07-22", "state": "full", "density": "high" },
      { "date": "2026-07-23", "state": "closed", "density": "none" }
    ],
    "slots": [
      { "startAt": "2026-07-21T12:00:00.000Z" },
      { "startAt": "2026-07-21T12:45:00.000Z" }
    ],
    "charge": {
      "mode": "deposit",
      "amountDueCents": 5000,
      "totalCents": 15000,
      "currency": "brl"
    },
    "stepMin": 15,
    "timezone": "America/Sao_Paulo"
  }
}
```

L'`state` de chaque jour est `free` (des créneaux sont disponibles), `full`
(complet) ou `closed` (jour non travaillé) ; `density` (`none`, `low`, `medium`,
`high`) indique à quel point la journée est déjà chargée. Les heures sont
renvoyées en UTC (`Z`).

Lorsque le service a un paiement en ligne configuré, `charge` décrit ce que le
visiteur paie au moment de la réservation : `mode` (`none`, `deposit` ou `full`),
`amountDueCents` (le montant dû à la réservation, en centimes), `totalCents`
(le prix complet du service, en centimes) et `currency`. Sans paiement configuré,
`mode` vaut `none` et les montants sont `0`.

### Créer une réservation

```
POST /v1/agenda/appointments
```

Réserve un créneau manuellement, selon les mêmes règles que la réservation
publique — le créneau doit être réellement disponible, sinon la requête est rejetée.

#### Requête

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"offeringId":"665f0a1b2c3d4e5f60718293","startAt":"2026-07-21T13:00:00.000Z","name":"João Lima","phone":"+5511999998888"}' \
  https://api.linkz.ee/v1/agenda/appointments
```

#### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `offeringId` | string | Oui | Le service réservé. |
| `startAt` | string | Oui | Heure de début au format ISO 8601, par ex. `2026-07-21T13:00:00.000Z`. |
| `name` | string | Oui | Nom du visiteur (max. 120 caractères). |
| `phone` | string | Oui | Téléphone du visiteur (max. 30 caractères). |
| `email` | string | Non | E-mail du visiteur (max. 160 caractères). |
| `notes` | string | Non | Notes internes (max. 500 caractères). |
| `leadId` | string | Non | Lie la réservation à un client (lead) existant au lieu de créer une fiche en double. |
| `staffId` | string | Non | Le membre de l'équipe qui prendra en charge la réservation (mode équipe). Ignoré en mode solo/pool. |

#### Réponse

```json
{
  "error": false,
  "message": "Appointment created successfully",
  "data": {
    "id": "665f1122aa33bb44cc55dd66",
    "manageToken": "8f3a1c22b90e4d1f",
    "status": "confirmed",
    "startAt": "2026-07-21T13:00:00.000Z",
    "endAt": "2026-07-21T13:45:00.000Z",
    "offeringName": "Strategy call",
    "timezone": "America/Sao_Paulo"
  }
}
```

## Google Agenda

### Statut de connexion

```
GET /v1/agenda/google
```

```bash
curl -X GET \
```

### Déconnecter Google Agenda

```
DELETE /v1/agenda/google
```

Déconnecte votre Google Agenda. La synchronisation s'arrête ; les réservations
existantes sont conservées.

#### Requête

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/google
```

#### Réponse

```json
{ "error": false, "message": "ok", "data": { "connected": false } }
```

<Warning>
La connexion d'un Google Agenda se fait via un flux de connexion dans le tableau
de bord Linkzee et ne peut pas être effectuée depuis l'API. L'API peut uniquement
lire le statut et déconnecter.
</Warning>

## Avis

Après une réservation terminée, les visiteurs peuvent laisser un avis. Les avis
ne sont **jamais modifiés ni supprimés** — la seule action de modération est d'en
masquer un de votre page publique (il reste visible pour vous, et vous pouvez le
réafficher à tout moment).

### Lister les avis

```
GET /v1/agenda/reviews
```

Renvoie tous les avis reçus par votre agenda, **y compris les avis masqués**.

#### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/reviews
```

#### Réponse

```json
{
  "error": false,
  "message": "Reviews retrieved successfully",
  "data": [
    {
      "id": "665f33aa11bb22cc33dd44ee",
      "rating": 5,
      "comment": "Great service, highly recommend!",
      "visitorName": "João Lima",
      "hidden": false,
      "createdAt": "2026-07-22T18:30:00.000Z"
    }
  ]
}
```

Renvoie les 50 avis les plus récents, du plus récent au plus ancien.

### Masquer ou afficher un avis

```
PATCH /v1/agenda/reviews/{id}
```

Bascule la visibilité d'un avis sur votre page publique. Requiert le scope **write**.

#### Requête

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"hidden":true}' \
  https://api.linkz.ee/v1/agenda/reviews/665f33aa11bb22cc33dd44ee
```

#### Paramètres

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `id` | string | Oui | L'identifiant de l'avis (dans le chemin). |
| `hidden` | boolean | Oui | `true` masque l'avis de la page publique ; `false` le réaffiche. |

#### Réponse

```json
{
  "error": false,
  "message": "Review updated successfully",
  "data": { "id": "665f33aa11bb22cc33dd44ee", "hidden": true }
}
```

<Note>
Il n'existe aucun endpoint pour modifier ou supprimer un avis — le masquage est
la seule action de modération, afin que les notes restent fiables.
</Note>

## Liste d'attente

Lorsqu'une période n'a plus de créneaux libres, les visiteurs peuvent rejoindre la
liste d'attente. Dès qu'un créneau compatible se libère, le système le propose
automatiquement à la première entrée compatible.

### Lister la liste d'attente

```
GET /v1/agenda/waitlist
```

Renvoie la file actuelle des visiteurs en attente d'un créneau.

#### Requête

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/waitlist
```

#### Réponse

```json
{
  "error": false,
  "message": "Waitlist retrieved successfully",
  "data": [
    {
      "id": "665f44bb55cc66dd77ee88ff",
      "position": 1,
      "name": "Maria Alves",
      "phone": "+5511988887777",
      "dateFrom": "2026-07-21",
      "dateTo": "2026-07-25",
      "periods": ["morning", "afternoon"],
      "status": "waiting",
      "offeringId": "665f0a1b2c3d4e5f60718293",
      "createdAt": "2026-07-19T10:12:00.000Z"
    }
  ]
}
```

Les entrées sont ordonnées par ordre d'arrivée (`position` commence à 1).
`periods` liste les moments de la journée préférés du visiteur (`morning`,
`afternoon`, `evening`) ; `status` vaut `waiting` ou `offered` (un créneau a été
proposé et attend une réponse).

### Supprimer une entrée de la liste d'attente

```
DELETE /v1/agenda/waitlist/{id}
```

Retire une entrée de la file. Requiert le scope **write**.

#### Requête

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/waitlist/665f44bb55cc66dd77ee88ff
```

#### Réponse

```json
{ "error": false, "message": "Waitlist entry removed", "data": { "id": "665f44bb55cc66dd77ee88ff" } }
```
