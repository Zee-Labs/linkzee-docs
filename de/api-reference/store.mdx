Ein Store trägt eine öffentliche Seite: seinen Namen, die Bio, die
Social-Handles, das Design, die Spezialkarten, die SEO-Felder sowie die
Tracking- und Marketing-Einstellungen. Ein Linkzee-Konto kann **mehrere
Stores** enthalten, daher wirken diese Endpunkte immer auf **einen** davon: den
Store, an den dein API-Schlüssel gebunden ist.

Alle Anfragen gehen an `https://api.linkz.ee` und müssen deinen API-Schlüssel
enthalten:

```
Authorization: Bearer lzk_your_key
```

<Note>
  Lesezugriffe benötigen den Scope **read**. Aktualisierungen erfordern einen
  Schlüssel mit dem Scope **write**. Um mit einem anderen Store zu arbeiten,
  verwende einen Schlüssel, der in diesem Store erstellt wurde. Siehe
  [Authentifizierung](/de/api-reference/authentication).
</Note>

## Store-Profil abrufen

```
GET /v1/store
```

Gibt die Inhaberansicht des Stores zurück. Es ist eine **Positivliste**: Nur die
unten aufgeführten Felder werden zurückgegeben, Geheimnisse nie. Es ist dieselbe
Ansicht, die das MCP-Tool `get_store` zurückgibt.

### Anfrage

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/store
```

### Was die Ansicht enthält

| Gruppe | Felder |
| --- | --- |
| Profil | `id`, `name`, `slug`, `bio`, `bioSignature`, `seoTitle`, `seoDescription`, `timezone`, `location`, `publicPreferences`, `publicUrl`, `pageHidden` |
| Design | `themeId`, `overrides`, Farben (`themeColor`, `buttonColor`, `buttonTextColor`, `buttonShadowColor`, `textColor`), `themeMode`, Hintergrundfelder (`background`, `bgColor2`, `bgFill`, `bgAngle`, `gradientPreset`, `bgAnimated`, `wallpaperUrl` und seine Optionen, Optionen für Aurora, Mesh und Muster), Buttons (`buttonStyle`, `buttonRadius`, `buttonShadow`, `buttonText`), `fontId`, `fontPairId`, `cardStyle`, `cardRadius`, `texture`, `motionLevel`, `stageMode`, `saleStyle`, `socialStyle`, `avatarFx`, `wallpaperVideo` |
| Header | `headerLayout`, `titleStyle`, `logoUrl`, `bannerUrl`, `headerSettings` (`heroMedia`, `heroAvatar`, `shapeId`, `shapeColor`, `wordmarkUrl`, `heroPhotoUrl`, `cutoutUrl`, `heroVideo`) |
| Soziale Netzwerke | `social`, `whatsapp`, `socialsPosition`, `socialOrder`, `socialCards` |
| Schaufenster und Karten | `vitrineEnabled`, `vitrineStyle`, `gridDensity`, `vitrineLayout`, `vitrinePhotoFit`, `mapAddress`, `mapTheme`, `mapLayout`, `openingHours`, `servicesEnabled`, `packagesEnabled`, `instagramEnabled`, `googleReviewEnabled`, `googleReviewUrl`, `reviewsBlock` |
| KI-Assistent | `aiAssistantTone`, `aiEmoji` |
| PIX-Trinkgelder | `tips` als Zusammenfassung: `enabled`, `pixKeyType`, `pixKeyPreview` (letzte 4 Zeichen), `recipientName`. Nie der Schlüssel. |
| Agenda | `agenda`-Einstellungen (keine personenbezogenen Daten). |
| Lead-Webhook | `leadWebhook` nur mit `host` und `enabled`. Nie der Pfad oder das Signaturgeheimnis. |
| Tracking | `tracking`: Pixel-IDs, `gtmId`, UTM-Standards und `capiTokenConfigured`. Nie das Token der Conversion API. |

<Note>
  `pageHidden: true` bedeutet, dass die öffentliche Seite ausgeschaltet ist
  (`isActive: false`). Das alte Feld `instagram` auf oberster Ebene wird für
  ältere Leser weiterhin zurückgegeben; verwende `social.instagram`.
</Note>

## Store-Profil aktualisieren

```
PATCH /v1/store
```

Aktualisiert ein oder mehrere Felder des Stores. Sende nur die Felder, die du
ändern möchtest; alles, was du weglässt, bleibt, wie es ist. Änderungen gehen
sofort auf der öffentlichen Seite live.

### Anfrage

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
        "bio": "Brows and lashes in Pinheiros. Book online in two taps.",
        "themeId": "editorial",
        "socialsPosition": "top",
        "publicPreferences": { "locale": "en" }
      }' \
  https://api.linkz.ee/v1/store
```

### Parameter

Jedes Feld ist optional; sende nur, was du ändern möchtest.

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| `name` | string | Anzeigename des Stores (max. 120 Zeichen). |
| `bio` | string | Kurze Beschreibung unter dem Namen (max. 500 Zeichen). |
| `bioSignature` | string | Einzeilige Signatur unter der Bio (max. 60 Zeichen, keine Zeilenumbrüche). |
| `titleStyle` | string | Titelstil des Headers: `text` oder `logo`. |
| `logoUrl`, `bannerUrl`, `wallpaperUrl` | string | Bild-URLs. Lade sie zuerst mit [`POST /v1/uploads/image`](/de/api-reference/uploads) hoch. |
| `headerLayout` | string | `classic`, `hero`, `banner`, `cutout` oder `shape`. |
| `headerSettings` | object | Header-Details: `wordmarkUrl`, `heroPhotoUrl`, `cutoutUrl`, `heroMedia`, `heroAvatar`, `shapeId`, `shapeColor`, `frames` und `media` (Layouts und Slots außerhalb der erlaubten Liste werden verworfen, und die Werte werden begrenzt). |
| `themeId` | string | ID eines vorgefertigten Themes (siehe den Theme-Katalog unten). |
| `overrides` | string[] | Fortgeschritten: die über `themeId` angepassten Designabschnitte. |
| Designfelder | verschiedene | Dieselben Designfelder wie beim MCP-Tool `update_design`: Farben, `themeMode`, Hintergrund, Buttons, `fontId`, `fontPairId`, `cardStyle`, `cardRadius`, `texture`, `motionLevel`, `stageMode`, `saleStyle`, `vitrineStyle`, `socialStyle`, `avatarFx`. |
| `social` | object | Social-Handles, zum Beispiel `{ "instagram": "handle", "tiktok": "handle" }`. Ein leerer String entfernt ein Netzwerk. |
| `whatsapp` | string | Nummer mit Ländervorwahl, nur Ziffern. |
| `socialsPosition` | string | Wo die Social-Leiste erscheint: `top` oder `bottom`. |
| `socialOrder` | string[] | Anzeigereihenfolge der Social-Icons. Nur gültige Netzwerkschlüssel (`whatsapp`, `instagram`, `tiktok`, `youtube` und die anderen). |
| `productsPosition` | string | Position des Schaufensters relativ zu den Links: `top` oder `bottom`. |
| `vitrineEnabled`, `vitrineLayout`, `vitrineStyle`, `gridDensity`, `vitrinePhotoFit` | verschiedene | Einstellungen des Schaufensters. `vitrineLayout`: `grid`, `masonry` oder `carousel`. `vitrineStyle`: `classic` oder `spotlight`. |
| `servicesEnabled`, `packagesEnabled`, `instagramEnabled` | boolean | Schaltet die Karten für Leistungen, Pakete und Instagram ein oder aus. |
| `googleReviewEnabled`, `googleReviewUrl` | boolean, string | Google-Bewertungskarte (Link von Google Maps, `g.page` oder `g.co`). |
| `reviewsBlock` | object | Bewertungskarte: `added`, `enabled`, `layout`, `limit` (1 bis 10), `minRating` (1 bis 5). |
| `mapAddress`, `mapTheme`, `mapLayout` | string | Kartenkarte. Ein leeres `mapAddress` entfernt sie; `mapLayout` ist `map` oder `card`. |
| `openingHours` | object | Das Badge "Jetzt geöffnet": `source`, `showStatus`, `week`, `closedDates`. |
| `agenda` | object | Einstellungen der Terminplanung, teilweise zusammengeführt. Siehe die [Referenz zur Terminplanung](/de/api-reference/agenda). Solange der [Qzee-Kalender](/de/scheduling/qzee-booking) in der Bio ist, liefert das Einschalten von `agenda.enabled` `409` mit `code: "AGENDA_QZEE_BOOKING_ON"`: Der Inhaber wechselt im Dashboard zurück. |
| `tips` | object | PIX-Trinkgeldkarte: `enabled`, `pixKey`, `pixKeyType` (`email` oder `random`), `recipientName` (max. 25), `recipientCity` (max. 15), `message`, `amounts`, `thanksMessage`, `highlight`. Mit einem Schlüssel sind Name und Stadt erforderlich. Der Inhaber erhält eine E-Mail, wenn sich der Schlüssel ändert. |
| `timezone` | string | IANA-Zeitzone, zum Beispiel `America/Sao_Paulo`. Ein ungültiger Name gibt `400` zurück. |
| `location` | object | `countryCode` (ISO, 2 Buchstaben), `state`, `city`. Steuert den Feiertagskalender. |
| `publicPreferences` | object | `locale` der öffentlichen Seite (`pt-BR`, `en`, `es`, `fr`, `de`) und `translationFallback` (`original` oder `dashboardLocale`). Wird mit dem Gespeicherten **zusammengeführt**: Wer nur `locale` sendet, behält den Fallback. |
| `seoTitle` | string | Titel der öffentlichen Seite für Suchmaschinen (max. 70 Zeichen). |
| `seoDescription` | string | Meta-Beschreibung der öffentlichen Seite (max. 160 Zeichen). |
| `gtmId` | string | ID des Google-Tag-Manager-Containers, zum Beispiel `GTM-ABC123`. |
| `utmSource`, `utmMedium`, `utmCampaign` | string | Standard-UTM-Parameter, die an ausgehende Links angehängt werden. |
| `pixels` | object | IDs der Tracking-Pixel: `metaPixelId`, `tiktokPixelId`, `gaMeasurementId`. |
| `capiToken` | string | Token der Meta Conversion API. Im Klartext gesendet, verschlüsselt gespeichert. Leer bedeutet "das aktuelle behalten". |
| `isActive` | boolean | Ob die öffentliche Seite live ist. `false` blendet sie aus. |

### Theme-Vererbung

Aktualisierungen über die API folgen denselben Regeln wie der Editor:

- `themeId` **ohne** `overrides` wendet das Preset sauber an: Die zuvor
  gespeicherten Overrides und die Bewegungsstufe werden zurückgesetzt.
- Jedes andere Designfeld in einem Store mit Preset passt **nur seinen
  Abschnitt** an (Farben, Hintergrund, Buttons, Text, Verlauf, Karte, Textur,
  Bewegung), der von der Palette des Themes startet. Der Rest folgt weiter dem
  Theme.
- Farben, die der Palette des Presets entsprechen, zählen nicht als eigene
  Farben und lösen daher die Premium-Sperre nicht aus. Kostenpflichtige Werte
  (Glas-Buttons, Bild-, Mesh-, Duotone- oder Video-Hintergründe, animierte oder
  vorgefertigte Verläufe, eigene Farben, kostenpflichtige Schriften,
  `stageMode`) geben in einem kostenlosen Tarif `403` mit
  `code: "PLAN_REQUIRED"` zurück.
- Sende `overrides`, wenn du die angepassten Abschnitte selbst auflisten
  willst.

<Warning>
  Der `slug` des Stores kann über die API nicht geändert werden. Ihn zu senden
  hat keine Wirkung: Er wird ignoriert, damit dein veröffentlichter Bio-Link nie
  kaputtgeht.
</Warning>

### Antwort

Die Antwort ist dieselbe Positivlisten-Ansicht wie bei `GET /v1/store`, dazu
`agentNotes`, wenn es etwas zu melden gibt:

```json
{
  "error": false,
  "message": "Store updated successfully",
  "data": {
    "id": "665f1c9a4b2e8a0012a3c9d1",
    "name": "Studio Ana",
    "bio": "Brows and lashes in Pinheiros. Book online in two taps.",
    "themeId": "editorial",
    "overrides": [],
    "socialsPosition": "top",
    "publicPreferences": { "locale": "en", "translationFallback": "original" },
    "pageHidden": false,
    "agentNotes": {
      "warnings": []
    }
  }
}
```

`agentNotes.warnings` listet Felder auf, die gespeichert wurden, aber noch nicht
sichtbar sind (zum Beispiel ein `cutout`-Header ohne Freisteller-Bild oder eine
`wallpaperUrl` ohne Bildhintergrund). Wenn sich der PIX-Schlüssel oder die
WhatsApp-Nummer ändert, enthält `agentNotes` auch die Änderung, nur mit den
letzten 4 Zeichen.

<Note>
  Die Reihenfolge des Schaufensters ist kein Store-Feld. Sie ist "neueste
  zuerst" bis zum ersten [`PUT /v1/products/order`](/de/api-reference/products),
  das sie ändert; ab dann folgt das Schaufenster deiner manuellen Reihenfolge.
  Nur das Dashboard stellt sie auf "neueste zuerst" zurück.
</Note>

## Theme-Katalog durchsuchen

```
GET /v1/themes
```

Listet die **23** vorgefertigten Themes auf, die du mit `themeId` anwenden
kannst. Jeder Eintrag enthält eine kurze Beschreibung, damit du einen Look zum
Stil eines Stores passend auswählen kannst, und `premium` für die
kostenpflichtigen.

### Anfrage

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/themes
```

### Antwort

```json
{
  "error": false,
  "message": "Themes loaded",
  "data": [
    {
      "id": "pure",
      "name": "Pure",
      "mode": "light",
      "description": "Minimal light, near-white background, full focus on the products.",
      "premium": false
    },
    {
      "id": "noir",
      "name": "Noir",
      "mode": "dark",
      "description": "Sober dark, graphite grey, elegant and neutral.",
      "premium": false
    }
  ]
}
```

Der vollständige Katalog hat 23 Themes. Kostenlos: `pure`, `noir`, `gesso`, `solar`, `midnight`, `groove`, `carbon`, `oceano`, `neon`, `pessego`, `selva`, `aurora`, `brutalista`, `editorial`, `pista`. Kostenpflichtig: `motion-neon`, `motion-clean`, `motion-achadinhos`, `motion-boutique`, `onix`, `cinema`, `perola`, `iridescente`.

<Note>
  Verwende eine beliebige `id` aus dieser Liste als `themeId`, wenn du den Store
  aktualisierst. Die `id`s sind stabil; `name` und `description` dienen nur der
  Information und werden auf Englisch zurückgegeben.
</Note>

## Leistungsübersicht abrufen

```
GET /v1/analytics/summary
```

Gibt die wichtigsten Kennzahlen des Schaufensters zurück: Summen sowie die
Top-Produkte und die neuesten Produkte.

### Anfrage

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/analytics/summary
```

### Antwort

```json
{
  "error": false,
  "message": "Dashboard retrieved successfully",
  "data": {
    "totalProducts": 42,
    "totalCategories": 6,
    "totalClicks": 1873,
    "topProducts": [
      {
        "id": "665f2a114b2e8a0012a3ca07",
        "name": "Bluetooth earbuds",
        "price": 79.9,
        "clicks": 312
      }
    ],
    "latestProducts": [
      {
        "id": "665f2b884b2e8a0012a3ca19",
        "name": "Desk lamp",
        "price": 129.9,
        "clicks": 4
      }
    ]
  }
}
```

| Feld | Typ | Beschreibung |
| --- | --- | --- |
| `totalProducts` | number | Gesamtzahl der Produkte im Schaufenster. |
| `totalCategories` | number | Gesamtzahl der Kategorien. |
| `totalClicks` | number | Summe aller Produktklicks. |
| `topProducts` | array | Bis zu 5 der meistgeklickten Produkte. |
| `latestProducts` | array | Bis zu 5 der zuletzt hinzugefügten Produkte. |
