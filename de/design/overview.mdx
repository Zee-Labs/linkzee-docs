**Design** ist der Bereich, in dem Sie festlegen, wie Ihre Seite aussieht. Öffnen
Sie **Design** in Ihrem Linkzee-Editor, um ein Theme auszuwählen und die Details
fein abzustimmen. Jede Änderung wird automatisch gespeichert und erscheint sofort
in der Live-Vorschau.

## Fertige Themes

Beginnen Sie mit einer **Galerie fertiger Themes**. Jedes Theme ist ein
vollständiger, harmonischer Look — Hintergrund, Buttons, Schriften und Textfarben,
die bereits gut zusammenpassen —, sodass Ihre Seite mit einem einzigen Tippen
großartig aussieht.

## Kuratierte Feinabstimmung

Möchten Sie sie noch persönlicher gestalten? Über das Theme hinaus können Sie
einige kuratierte Bereiche anpassen:

| Bereich | Was Sie steuern |
|---|---|
| **Kopfbereich** | Das Layout von Name, Foto oder Logo oben auf der Seite |
| **Hintergrund** | Der Hintergrundstil der Seite |
| **Buttons** | Form und Stil der Buttons |
| **Text** | Die Schriftart, aus einer kuratierten Liste |
| **Farben** | Akzent- und Textfarben, aus einer kuratierten Palette |

<Note>
  Die Optionen sind bewusst kuratiert — Sie wählen aus Möglichkeiten, die immer
  gut zusammen aussehen, sodass Sie sich keine Sorgen um unpassende Farben oder
  schwer lesbare Schriften machen müssen.
</Note>
