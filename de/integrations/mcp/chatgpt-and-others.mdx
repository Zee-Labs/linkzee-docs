Linkzee funktioniert mit **jedem MCP-kompatiblen Agenten**, nicht nur mit
Claude. Wenn dein Tool MCP unterstützt, kannst du es mit Linkzee verbinden und
deine Seite in natürlicher Sprache verwalten: **ChatGPT**, **Cursor**,
Automatisierungstools und mehr.

## Deinen Client verbinden

<Steps>
  <Step title="Einen API-Schlüssel erstellen">
    Öffne in deinem Dashboard **Einstellungen**, **API und MCP** und erstelle
    einen API-Schlüssel. Wähle **write**, wenn der Agent deine Seite ändern
    soll (er liest auch), oder **read** für einen Agenten, der nur liest. Die
    vollständige Anleitung findest du unter
    [API-Schlüssel](/de/integrations/api/api-keys).
  </Step>
  <Step title="Einen MCP-Server hinzufügen">
    Füge in deinem Client einen neuen MCP-Server (Streamable HTTP) hinzu, der
    auf diese Adresse verweist:

    ```
    https://api.linkz.ee/mcp
    ```
  </Step>
  <Step title="Deinen API-Schlüssel angeben">
    Sende deinen Schlüssel im Autorisierungs-Header:

    ```
    Authorization: Bearer lzk_your_key
    ```

    Bei Clients, die mit JSON konfiguriert werden, sieht der Block meist so aus:

    ```json
    {
      "mcpServers": {
        "linkzee": {
          "type": "http",
          "url": "https://api.linkz.ee/mcp",
          "headers": { "Authorization": "Bearer lzk_your_key" }
        }
      }
    }
    ```
  </Step>
  <Step title="In natürlicher Sprache fragen">
    Sobald die Verbindung steht, sprich mit deinem Agenten so, wie du mit einem
    Assistenten sprechen würdest: „füge dieses Produkt hinzu", „was ist diese
    Woche gebucht?" oder „ändere mein Theme".
  </Step>
</Steps>

<Note>
  Jeder Client fügt MCP-Server ein wenig anders hinzu. Sieh in der Dokumentation
  deines Clients nach, wo du den Endpunkt und den Header einfügst. Die Anmeldung
  mit deinem Linkzee-Konto (OAuth), ohne Schlüssel, funktioniert mit dem
  Claude-Konnektor und mit Apps, die auf deinem eigenen Computer laufen. Andere
  gehostete Clients verwenden einen API-Schlüssel.
</Note>

## Fotos und Videos senden

Viele Chat-Apps zeigen deine Anhänge dem Modell, geben die Datei aber nicht an
die Tools weiter. Wenn der Agent keine öffentliche URL für ein Foto oder Video
hat, nutzt er einen **Upload-Link**:

1. Der Agent ruft `create_upload_link` auf und gibt dir eine Seite wie
   `https://linkz.ee/u/...`.
2. Du öffnest sie auf deinem Handy oder Computer und wählst die Dateien aus
   (bis zu 10; Fotos bis 8 MB, Videos bis 40 MB). Der Link bleibt 15 Minuten
   lang offen.
3. Du sagst dem Agenten, dass du fertig bist. Er liest die Dateien mit
   `get_upload` und verwendet jede `uploadId` an der richtigen Stelle deiner
   Seite.

Agenten, die mit Dateizugriff laufen (Cursor, Skripte, Automatisierungen),
können die Dateien auch direkt an denselben Link senden. Wenn ein Foto bereits
online ist, übergibt der Agent einfach seine öffentliche URL. Siehe
[Dateien senden](/de/integrations/mcp/sending-files).
