Sobald du einen KI-Agenten über MCP verbindest, kann er fast jeden Teil deines
Linkzee für dich verwalten — einfach, indem du es in ganz normaler Sprache
verlangst. Diese Seite listet auf, was ein Agent tun kann, nach Bereichen
gruppiert, damit du weißt, worum du bitten kannst.

<Note>
  Aktionen, die deine Daten **lesen**, benötigen einen Schlüssel mit dem
  Berechtigungsbereich **read**. Aktionen, die **erstellen, aktualisieren oder
  löschen**, benötigen einen Schlüssel mit dem Berechtigungsbereich **write**.
  Siehe [API-Schlüssel](/integrations/api/api-keys), um den richtigen
  Berechtigungsbereich festzulegen.
</Note>

## Seite & Profil

| Tool-Bereich | Was der Agent tun kann |
| --- | --- |
| Storefront | Deine gesamte Seite lesen — dein Profil, deine Links und Produkte in einer Ansicht. |
| Profil | Deinen Namen, dein Foto, deine Bio und weitere Profildetails aktualisieren. |
| Erscheinungsbild | Dein Erscheinungsbild und Theme festlegen. |
| Karte & soziale Netzwerke | Deine Karte und deine sozialen Netzwerke aktualisieren. |

## Links & Sammlungen

| Tool-Bereich | Was der Agent tun kann |
| --- | --- |
| Links | Deine Links erstellen, aktualisieren und löschen. |
| Sammlungen | Links in Sammlungen gruppieren und verwalten. |
| Reihenfolge | Deine Inhalte neu anordnen, sodass deine besten Elemente zuerst kommen. |

## Produkte & Kategorien

| Tool-Bereich | Was der Agent tun kann |
| --- | --- |
| Produkte | Produkte einzeln oder im Stapel erstellen. |
| Produktbearbeitungen | Vorhandene Produkte aktualisieren oder löschen. |
| Kategorien | Deine Produktkategorien erstellen und verwalten. |

## Design

| Tool-Bereich | Was der Agent tun kann |
| --- | --- |
| Design | Dein Design aktualisieren und dein Theme wechseln. |

## Analytics & Leads

| Tool-Bereich | Was der Agent tun kann |
| --- | --- |
| Analytics | Eine Zusammenfassung lesen, wie sich deine Seite entwickelt. |
| Leads | Die von dir erfassten Leads auflisten. |

## Terminplanung

| Tool-Bereich | Was der Agent tun kann |
| --- | --- |
| Agenda | Deine Terminplanung einrichten. |
| Dienstleistungen & Team | Deine Dienstleistungen, dein Personal und Sperrzeiten verwalten. |
| Termine | Termine auflisten und erstellen sowie die Verfügbarkeit prüfen. |
| Änderungen | Termine verschieben und ihren Status ändern. |
| Google | Den Verbindungsstatus von Google prüfen. |

## KI-Assistent

| Tool-Bereich | Was der Agent tun kann |
| --- | --- |
| Assistent | Die Konfiguration deines KI-Assistenten verwalten. |

<Note>
  Alles, was ein Agent ändert, wird automatisch gespeichert und aktualisiert
  deine Live-Seite in Echtzeit — genau so, als hättest du die Änderung selbst
  im Editor vorgenommen.
</Note>
