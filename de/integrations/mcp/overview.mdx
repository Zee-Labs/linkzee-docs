**MCP** (Model Context Protocol) ermöglicht es KI-Agenten wie **Claude**,
**ChatGPT** oder **Cursor**, dein Linkzee in normaler Sprache zu steuern. Frag
einfach, und der Agent erledigt die Arbeit für dich:

- „Erstelle meine Bio von Grund auf mit diesen Leistungen und Fotos."
- „Füge dieses Produkt zu meiner Seite hinzu."
- „Was habe ich diese Woche gebucht?"
- „Ändere mein Theme und setze die Bewertungskarte über die Karte."

Ein mit Linkzee verbundener Agent kann alles tun, was du im Editor für deine
öffentliche Seite tust: den echten Zustand lesen, Links und Medienblöcke
erstellen, Fotos und Videos senden, Header und Design festlegen, die
Spezialkarten konfigurieren und die Reihenfolge der Seite bestimmen.

## So funktioniert es

Der Agent verbindet sich mit dem MCP-Endpunkt von Linkzee unter
`https://api.linkz.ee/mcp`. Es gibt zwei Arten, sich anzumelden:

| Art | Am besten für | Wie der Zugriff festgelegt wird |
| --- | --- | --- |
| **Claude-Konnektor** (OAuth) | claude.ai, die Claude-Desktop-App und die Claude-App fürs Handy. Kein Schlüssel zum Kopieren. | Du meldest dich bei Linkzee an und wählst die Gruppen: `content` (erforderlich), `agenda`, `leads` und `finance` (optional). |
| **API-Schlüssel** (`lzk_`) | Claude Code, Cursor, ChatGPT, Automatisierungen und jeder MCP-Client, der einen `Authorization`-Header sendet. | Die Scopes des Schlüssels: `read`, `write` und das optionale `finance`. |

Beide wirken auf **einen Store**: den Store, in dem der Schlüssel erstellt
wurde, oder den Store, den du beim Verbinden von Claude ausgewählt hast. Die
Nutzung von API und MCP erfordert einen Tarif, der sie enthält (Pro oder Scale).

<Note>
  Alles, was der Agent ändert, wird automatisch gespeichert und aktualisiert
  deine Live-Seite in Echtzeit, genau so, als würdest du sie selbst bearbeiten.
</Note>

## Was ein Agent von dir braucht

- **Fotos und Videos.** Der Agent kann öffentliche URLs verwenden. Wenn die
  Dateien nur auf deinem Handy oder im Chat liegen, erstellt er einen
  Upload-Link, und du wählst die Dateien auf einer Linkzee-Seite aus. Siehe
  [Dateien senden](/de/integrations/mcp/sending-files).
- **Einwilligung für Fotos von Personen.** Bevor Medienblöcke mit Fotos oder
  Videos von Personen online gehen, bittet dich der Agent zu bestätigen, dass
  die gezeigten Personen zugestimmt haben.
- **Deine Zustimmung vor einem Import.** Der Import einer Linktree- oder
  Beacons-Seite ersetzt dein Profil und fügt Links hinzu, daher zeigt dir der
  Agent zuerst eine Vorschau.
