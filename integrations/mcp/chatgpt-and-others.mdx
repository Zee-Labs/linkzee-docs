Linkzee works with **any MCP compatible agent**, not just Claude. If your tool
supports MCP, you can connect it to Linkzee and manage your page in natural
language: **ChatGPT**, **Cursor**, automation tools and more.

## Connect your client

<Steps>
  <Step title="Create an API key">
    In your dashboard, open **Settings**, **API and MCP**, and create an API key.
    Choose **write** if the agent should change your page (it also reads), or
    **read** for a read only agent. See [API keys](/integrations/api/api-keys)
    for the full walkthrough.
  </Step>
  <Step title="Add an MCP server">
    In your client, add a new MCP server (Streamable HTTP) pointing to:

    ```
    https://api.linkz.ee/mcp
    ```
  </Step>
  <Step title="Provide your API key">
    Send your key in the authorization header:

    ```
    Authorization: Bearer lzk_your_key
    ```

    For clients configured with JSON, the block usually looks like this:

    ```json
    {
      "mcpServers": {
        "linkzee": {
          "type": "http",
          "url": "https://api.linkz.ee/mcp",
          "headers": { "Authorization": "Bearer lzk_your_key" }
        }
      }
    }
    ```
  </Step>
  <Step title="Ask in natural language">
    Once connected, talk to your agent the way you would talk to an assistant:
    "add this product", "what is booked this week?" or "change my theme".
  </Step>
</Steps>

<Note>
  Every client adds MCP servers a little differently. Check your client's own
  documentation for where to paste the endpoint and the header. Signing in with
  your Linkzee account (OAuth), without a key, works with the Claude connector
  and with apps that run on your own computer. Other hosted clients use an API
  key.
</Note>

## Sending photos and videos

Many chat apps show your attachments to the model but do not hand the file to
the tools. When the agent has no public URL for a photo or video, it uses an
**upload link**:

1. The agent calls `create_upload_link` and gives you a page such as
   `https://linkz.ee/u/...`.
2. You open it on your phone or computer and pick the files (up to 10; photos up
   to 8 MB, videos up to 40 MB). The link stays open for 15 minutes.
3. You tell the agent you are done. It reads the files with `get_upload` and
   uses each `uploadId` in the right place of your page.

Agents that run with file access (Cursor, scripts, automations) can also send the
files straight to the same link. When a photo is already online, the agent just
passes its public URL. See [Sending files](/integrations/mcp/sending-files).

## Every client, the same tools

The available actions are the same across every client, limited only by the
scopes of your key. See the [tools reference](/integrations/mcp/tools-reference)
for everything an agent can do through MCP.
