---
title: Connect Linkzee in Claude
icon: comment
description: "Let Claude build and manage your Linkzee in plain language over MCP."
---

Connect Linkzee to **Claude** and you can manage your page by simply asking:
"build my bio", "add this product", "what do I have booked this week?", "switch
my theme". Claude talks to Linkzee through MCP, so you never leave the chat.

There are two ways to connect. Use the **connector** in claude.ai and the Claude
apps, and an **API key** in Claude Code.

## claude.ai and the Claude apps (connector)

No key to copy: you sign in to Linkzee and approve the access.

<Steps>
  <Step title="Add Linkzee as a connector">
    In Claude, open **Settings**, then **Connectors**, and add a custom
    connector with the URL `https://api.linkz.ee/mcp`.
  </Step>
  <Step title="Sign in and choose the access">
    Claude opens Linkzee. Sign in, pick the store and choose what Claude can
    use: **content** (your page, always included), and optionally **agenda**,
    **leads** and **finance**. Optional groups ask for a recent sign in.
  </Step>
  <Step title="Ask Claude in plain language">
    Open a chat and describe what you want. To build a new page, say
    "Build my bio on Linkzee." Claude asks the rest.
  </Step>
</Steps>

You can see and disconnect every connected app in **Settings**, **API and MCP**,
under **Connections**. Disconnecting takes effect right away.

<Note>
  The connector never sees three tools: tracking pixels and GTM
  (`configure_tracking`), the PIX tips key (`configure_tips`) and disconnecting
  Google Calendar (`disconnect_agenda_google`). Use an API key for them, or
  change them in the dashboard.
</Note>

## Claude Code (API key)

<Steps>
  <Step title="Create an API key">
    In your dashboard, open **Settings**, **API and MCP**, and create a key with
    the **write** scope (it also reads). Copy it when it is shown. See
    [API keys](/integrations/api/api-keys) for the full steps.
  </Step>
  <Step title="Add the server">
    Run this in your terminal, with your key in place of `lzk_your_key`:

    ```bash
    claude mcp add --transport http linkzee https://api.linkz.ee/mcp \
      --header "Authorization: Bearer lzk_your_key"
    ```
  </Step>
  <Step title="Ask Claude">
    Start Claude Code and ask, for example, "list my links and hide the ones
    that point to old promotions".
  </Step>
</Steps>

## Photos and videos from the chat

When you attach a photo in claude.ai, Claude sees the image but does not get the
file to send it. In that case Claude creates an **upload link** and gives it to
you: open it, pick the photos or videos on your phone or computer, and tell
Claude when you are done. Claude Code can send local files to that link by
itself. See [Sending files](/integrations/mcp/sending-files).

<Warning>
  Your API key acts on your store. Never paste it into a public chat or share it.
  Treat it like a password.
</Warning>
