Links are the buttons on your bio page. Collections are the named groups you can
sort those buttons into (for example "Cozinha" or "Favoritos"). This page covers
the read and write operations for both.

**Base URL:** `https://api.linkz.ee` · every path lives under `/v1`.
Send your key on every request:

```bash
Authorization: Bearer lzk_your_key
```

<Note>
Reads (`GET`) work with any key. Writes (`POST`, `PATCH`, `DELETE`, `PUT`) need a
key with the **write** scope. Send bodies as `application/json`.
</Note>

## Links

### List links

```
GET /v1/links
```

Returns every link on your page, in display order.

#### Request

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/links
```

#### Response

```json
{
  "error": false,
  "message": "Links retrieved successfully",
  "data": [
    {
      "id": "507f1f77bcf86cd799439011",
      "collectionId": "66a3c0f2e1b2a40012ab34cd",
      "title": "Meu Instagram",
      "url": "https://instagram.com/minhaloja",
      "thumbnailUrl": "",
      "mediaType": "",
      "mediaUrl": "",
      "isFeatured": false,
      "highlightFx": "",
      "order": 0,
      "isActive": true,
      "clicks": 128,
      "createdAt": "2026-07-01T14:02:11.000Z",
      "updatedAt": "2026-07-18T09:41:55.000Z"
    }
  ]
}
```

### Create a link

```
POST /v1/links
```

Adds a new button to the end of your page.

#### Request

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Meu Instagram",
    "url": "https://instagram.com/minhaloja",
    "collectionId": "66a3c0f2e1b2a40012ab34cd"
  }' \
  https://api.linkz.ee/v1/links
```

#### Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `title` | string | Yes | Button label. Up to 120 characters. |
| `url` | string | Conditional | Destination URL, including `https://`. Required unless `mediaType` is `"image"`, `"video"`, `"before_after"` or `"gallery"` (a media card can be content only). |
| `collectionId` | string | No | ID of the collection this link belongs to. Leave it out to keep the link ungrouped. |
| `thumbnailUrl` | string | No | Thumbnail image URL. Upload the image first, then pass the returned URL. |
| `isActive` | boolean | No | Whether the link is visible on your page. Defaults to `true`. |
| `isFeatured` | boolean | No | Show the link with extra prominence. Defaults to `false`. |
| `highlightFx` | string | No | Animated highlight (Premium): `""` (none), `"shake"`, `"shine"`, `"pulse"`, or `"bounce"`. |
| `mediaType` | string | No | Media style: `""`, `"image"`, `"video"`, `"embed"`, `"before_after"` (two photos with a draggable edge) or `"gallery"` (2–10 photos). `before_after`/`gallery` are Premium and use `mediaItems` instead of `mediaUrl`. |
| `mediaUrl` | string | No | Cover media URL for the chosen `mediaType` (`image`/`video`/`embed`). |
| `caption` | string | No | Visible caption of a media card (max 160). The `title` stays the internal name. |
| `mediaConsent` | boolean | No | Media blocks: confirms you have permission from the people photographed. Required once before photos are saved; stored as `mediaConsentAt`. |
| `posterUrl` | string | No | Poster image URL for a video cover. |
| `scheduledStartAt` | string \| null | No | Schedule: instant (ISO 8601, UTC) from which the link appears. `null` clears it. Both `null` means always visible. |
| `scheduledEndAt` | string \| null | No | Schedule: instant (ISO 8601, UTC) at which the link disappears. Must be after `scheduledStartAt`. `null` clears it. |

#### Response

```json
{
  "error": false,
  "message": "Link created successfully",
  "data": {
    "id": "66b8f1aa77bcf86cd7994400",
    "collectionId": "66a3c0f2e1b2a40012ab34cd",
    "title": "Meu Instagram",
    "url": "https://instagram.com/minhaloja",
    "isActive": true,
    "isFeatured": false,
    "order": 4,
    "clicks": 0,
    "createdAt": "2026-07-21T11:20:03.000Z",
    "updatedAt": "2026-07-21T11:20:03.000Z"
  }
}
```

<Note>
  **Media blocks (`before_after` / `gallery`)** are created in three steps: create the link with `mediaType` and no `url` (it stays unpublished), upload each photo with `POST /v1/uploads/image` (`kind=linkMediaSlot`, `linkId`, `slot` 0–9 — resized to 1344px wide (fit inside 1344×2016)), then update the link with the full `mediaItems` list (+ `mediaConsent: true`). A block is published only when complete (exactly 2 photos for `before_after`, 2–10 for `gallery`). Both are Premium: the API answers `403` with `code: "PLAN_REQUIRED"` on free plans.
</Note>

### Update a link

```
PATCH /v1/links/{id}
```

Changes one or more fields on an existing link. Send only what you want to update.

#### Request

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{ "title": "Sigo lá!", "isActive": false }' \
  https://api.linkz.ee/v1/links/507f1f77bcf86cd799439011
```

#### Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | Yes | Path parameter. ID of the link to update. |
| `title` | string | No | New button label. Up to 120 characters. |
| `url` | string | No | New destination URL, including `https://`. |
| `collectionId` | string \| null | No | Move the link to a collection, or send `null` to remove it from its collection. |
| `thumbnailUrl` | string | No | New thumbnail image URL. |
| `isActive` | boolean | No | Show or hide the link. |
| `isFeatured` | boolean | No | Toggle extra prominence. |
| `highlightFx` | string | No | `""` (none), `"shake"`, `"shine"`, `"pulse"`, or `"bounce"` (Premium). |
| `mediaType` | string | No | `""`, `"image"`, `"video"`, `"embed"`, `"before_after"` or `"gallery"`. |
| `caption` | string | No | Visible caption of a media card (max 160). |
| `mediaItems` | array | No | Media blocks: the FULL photo list (replace). Each item is `{ slot, url, w, h, alt?, frame?, label?, offeringId?, productId?, cta? }` — `slot` (0–9) is the stable file id used in the upload, the array order is the display order; `frame` `{ zoom 1–3, focalX 0–1, focalY 0–1 }` is an optional non-destructive reframe (zoom + focal point, applied with CSS on the page; omit = centered) (`before_after`: `[0]` = before, `[1]` = after, exactly 2; `gallery`: 2–10). URLs must come from `POST /v1/uploads/image` with `kind=linkMediaSlot` for this link and slot. | In a `gallery` with `galleryLayout: "reel"` each item may also carry `label` (card label, max 40), `offeringId` (agenda service of its "Book this" button), `productId` (a product of the store: the button opens the product link through the tracked redirect) and `cta` (`"inherit"` default, `"none"` or `"whatsapp"`). The button is resolved per photo: service → product → WhatsApp → none.
| `mediaLabels` | object | No | `before_after`: `{ "before": "", "after": "" }` labels (max 24 each). Empty = localized default. |
| `mediaStartPct` | integer | No | `before_after`: where the draggable edge starts, as % of the width from the left (10–90, default 50). Lower = more of the "after" photo visible at first. |
| `mediaConsent` | boolean | No | Media blocks: permission confirmation (see Create). |
| `galleryLayout` | string | No | `gallery` block: `"carousel"` (default), `"strip"` (3 thumbnails under a `before_after`) or `"reel"` (vertical 9:16 showcase with a full-screen viewer). |
| `reelCta` | string | No | `reel` gallery: default button of photos without a service/product — `"none"` (default) or `"whatsapp"` (opens the store WhatsApp with the product name and the photo link `https://linkz.ee/<slug>/look/<linkId>-<slot>` in the message, in the page language; requires the store `whatsapp` number). |
| `mediaUrl` | string | No | Cover media URL. |
| `posterUrl` | string | No | Poster image URL for a video cover. |
| `scheduledStartAt` | string \| null | No | Schedule: instant (ISO 8601, UTC) from which the link appears. `null` clears it. |
| `scheduledEndAt` | string \| null | No | Schedule: instant (ISO 8601, UTC) at which the link disappears. Must be after `scheduledStartAt`. `null` clears it. |

#### Response

```json
{
  "error": false,
  "message": "Link updated successfully",
  "data": {
    "id": "507f1f77bcf86cd799439011",
    "title": "Sigo lá!",
    "url": "https://instagram.com/minhaloja",
    "isActive": false,
    "order": 0,
    "updatedAt": "2026-07-21T11:32:47.000Z"
  }
}
```

```
DELETE /v1/links/{id}
```

Removes a link from your page.

#### Request

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/links/507f1f77bcf86cd799439011
```

#### Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | Yes | Path parameter. ID of the link to delete. |

#### Response

```json
{
  "error": false,
  "message": "Link deleted successfully"
}
```

### Reorder links

```
PUT /v1/links/order
```

Sets the display order of your links. Send each link ID with its new position.

#### Request

```bash
curl -X PUT \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "items": [
      { "id": "507f1f77bcf86cd799439011", "order": 0 },
      { "id": "66b8f1aa77bcf86cd7994400", "order": 1 }
    ]
  }' \
  https://api.linkz.ee/v1/links/order
```

#### Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `items` | array | Yes | List of items to reorder. At least one entry. |
| `items[].id` | string | Yes | ID of the link. |
| `items[].order` | integer | Yes | New position (lower shows first). |

#### Response

```json
{
  "error": false,
  "message": "Links reordered successfully"
}
```

## Collections

Collections group your links into named sections on the page. A collection can
carry a name, emoji and short description.

<Note>
Collections group **links** only. To organize products, use categories instead —
see the Categories reference.
</Note>

### List collections

```
GET /v1/collections
```

Returns every collection on your page, in display order.

#### Request

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/collections
```

#### Response

```json
{
  "error": false,
  "message": "Collections retrieved successfully",
  "data": [
    {
      "id": "66a3c0f2e1b2a40012ab34cd",
      "name": "Cozinha",

      "createdAt": "2026-06-28T18:10:00.000Z",
```

### Create a collection

```
POST /v1/collections
```

Adds a new group your links can be sorted into.

#### Request

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Cozinha", "emoji": "🍳" }' \
  https://api.linkz.ee/v1/collections
```

#### Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | No | Display name, 1–80 characters. When omitted, a slug is generated for you. |
| `slug` | string | No | URL-friendly identifier, up to 60 characters. Derived from `name` when omitted. |
| `emoji` | string | No | An emoji shown next to the name. Up to 16 characters. |
| `description` | string | No | Short description. Up to 280 characters. |
| `isActive` | boolean | No | Whether the collection is visible. Defaults to `true`. |
| `order` | integer | No | Display position. |

#### Response

```json
{
  "error": false,
  "message": "Collection created successfully",
  "data": {
    "id": "66a3c0f2e1b2a40012ab34cd",
    "name": "Cozinha",
    "slug": "cozinha",
    "emoji": "🍳",
    "description": "",
    "isActive": true,
    "order": 3,
    "createdAt": "2026-07-21T11:40:52.000Z",
    "updatedAt": "2026-07-21T11:40:52.000Z"
  }
}
```

### Reorder collections

```
PUT /v1/collections/order
```

```bash
curl -X PUT \

```

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `items` | array | Yes | List of items to reorder. At least one entry. |
| `items[].id` | string | Yes | ID of the collection. |

```json

```

<Warning>
IDs are unique to your account. A request for a link or collection that doesn't
exist on your page returns `404 Not Found`.
</Warning>
