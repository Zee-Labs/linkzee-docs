Products are the items in your public showcase. Each product has a name, an
optional price, an image and an affiliate or product link. Use these endpoints to
keep your catalog in sync from your own systems.

All requests go to `https://api.linkz.ee` and must include your API key:

```
Authorization: Bearer lzk_your_key
```

<Note>
Reading products (`GET`) needs the **read** scope. Creating, updating, deleting
or reordering a product requires a key with the **write** scope.
</Note>

## Showcase order

The showcase has two order modes:

- **Newest first** (default): the most recent products come first.
- **Manual**: turned on by the first reorder (see "Reorder products" below) that changes the
  order visitors see. From then on the showcase follows the `order` of each
  product, and new products enter at the top.

`GET /v1/products`, the MCP tool `list_products` and the public page always
return the products in the order visitors see.

The owner switches between the two modes in the dashboard, with the **Showcase
order** selector (**Newest first** or **Custom**) on the **Products** screen.
Going back to newest first keeps the manual order saved, and choosing custom
again restores it. The API and MCP don't switch the mode: there is no endpoint
to go back to newest first.

## List products

```
GET /v1/products
```

Returns every product in your store, in the order of the showcase.

### Request

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/products
```

## Get a product

```
GET /v1/products/{id}
```

Returns a single product by its ID. The answer is an allow list of the product
fields (the same view as the MCP tool `get_product`); internal fields are never
returned.

### Request

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/products/665f1a2b9c4e1f0012a3b4c5
```

### Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string (path) | Yes | The product ID. |

## Create a product

```
POST /v1/products
```

Creates a product in your showcase. Requires the **write** scope.

You can either send the product fields directly, or send just a marketplace
`url` and let Linkzee fetch the name, price and image for you. If the automatic
lookup comes back incomplete, send at least `name` so the product can be saved.

### Request

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: sync-SKU-1042" \
  -d '{
    "name": "Wireless Headphones XYZ",
    "description": "Bluetooth 5.3, 30h battery",
    "price": 99.9,
    "priceOriginal": 149.9,
    "imageUrl": "https://example.com/headphones.jpg",
    "externalLink": "https://shopee.com.br/product/123",
    "badge": "Deal",
    "isFeatured": true,
    "externalId": "SKU-1042"
  }' \
  https://api.linkz.ee/v1/products
```

### Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Conditional | Product name (max 160). Optional when `url` is sent: it is filled from the marketplace lookup. |
| `url` | string | No | Marketplace URL. When sent without `name` or `price`, Linkzee tries to fill them automatically. |
| `slug` | string | No | Custom slug (max 80). Derived from the name when omitted; unique per store. |
| `description` | string | No | Short description (max 2000). |
| `price` | number | No | Current price in R$. Leave it out for a "no price" product. |
| `priceOriginal` | number | No | Original price, used to show a discount. |
| `installments` | string | No | Installment text, for example `3x of R$ 33.30` (max 80). |
| `imageUrl` | string | No | Main image URL (http or https). Outside URLs are copied to the Linkzee CDN. |
| `gallery` | string[] | No | Up to 10 extra image URLs. |
| `externalLink` | string | No | Affiliate or product link (http or https). A product without a link stays a hidden draft. |
| `buttonText` | string | No | Call to action label (max 60), for example `Buy`. |
| `badge` | string | No | Short promo tag (max 28), for example `Deal`. |
| `categoryId` | string | No | ID of the category this product belongs to. |
| `isActive` | boolean | No | Whether the product is visible in the showcase. Defaults to `true`. |
| `isFeatured` | boolean | No | Adds the product to the highlights carousel. |
| `highlightFx` | string | No | Animated highlight (Premium): `""`, `"shake"`, `"shine"`, `"pulse"` or `"bounce"`. |
| `cardSize` | string | No | `normal` or `wide` (a `wide` card spans both grid columns). |
| `offerEndsAt` | string | No | Offer end date (ISO 8601). |
| `offerDurationMinutes` | number | No | Scarcity countdown duration, in minutes (relative, restarts per visitor). |
| `showCountdown` | boolean | No | Shows the countdown timer on the card. |
| `externalId` | string | No | Your own reference for this product (a CRM or ERP id, or a SKU) to match it with your systems (max 64). Never shown on your public page. |
| `barcode` | string | No | Product barcode: EAN, GTIN or UPC (max 32). Never shown publicly. |

<Note>
Send an `Idempotency-Key` header to retry safely: repeating the request with the
same key and the same body within 24 hours returns the product created the first
time instead of a duplicate. The same key with a different body returns `409`.
See [Rate limits](/api-reference/rate-limits).
</Note>

### Response

```json
{
  "error": false,
  "message": "Product created successfully",
  "data": {
    "id": "665f1a2b9c4e1f0012a3b4c5",
    "name": "Wireless Headphones XYZ",
    "slug": "wireless-headphones-xyz",
    "price": 99.9,
    "priceOriginal": 149.9,
    "imageUrl": "https://cdn.linkz.ee/u/abc/products/665f1a2b.webp",

    "badge": "Deal",
    "isActive": true,
    "isFeatured": true,
    "clicks": 0,
    "createdAt": "2026-07-21T09:15:00.000Z"
  }
}
```

## Update a product

```
PATCH /v1/products/{id}
```

Updates any subset of a product's fields. Requires the **write** scope. Only the
fields you send are changed.

### Request

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "price": 89.9,
    "badge": "Flash sale",
    "isActive": false
  }' \
  https://api.linkz.ee/v1/products/665f1a2b9c4e1f0012a3b4c5
```

### Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string (path) | Yes | The product ID. |

The body accepts the same fields as **Create a product**, except `url` (the
automatic lookup only runs on creation). All fields are optional. Send
`categoryId: null` to remove the product from its category and
`offerEndsAt: null` to clear the offer end date.

### Response

```json
{
  "error": false,
  "message": "Product updated successfully",
  "data": {
    "id": "665f1a2b9c4e1f0012a3b4c5",
    "name": "Wireless Headphones XYZ",
    "price": 89.9,
    "badge": "Flash sale",
    "isActive": false
  }
}
```

## Delete a product

```
DELETE /v1/products/{id}
```

Removes a product from your showcase. Requires the **write** scope.

### Request

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/products/665f1a2b9c4e1f0012a3b4c5
```

### Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string (path) | Yes | The product ID. |

### Response

```json
{
  "error": false,
  "message": "Product deleted successfully"
}
```

## Reorder products

```
PUT /v1/products/order
```

Sets the position of products in the showcase. Requires the **write** scope.
Each item moves to the position given by `order` (`0` is the top):

- Send the **complete** list for an exact order.
- Send only the products you want to move: the others keep their relative order.

The first reorder that changes what visitors see turns the showcase to manual
order (see "Showcase order" above).

### Request

```bash
curl -X PUT \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "items": [
      { "id": "665f1a2b9c4e1f0012a3b4c5", "order": 0 },
      { "id": "665f1a2b9c4e1f0012a3b4c6", "order": 1 }
    ]
  }' \
  https://api.linkz.ee/v1/products/order
```

### Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `items` | array | Yes | 1 to 5000 items. |
| `items[].id` | string | Yes | The product ID. |
| `items[].order` | integer | Yes | New position (`0` is the top). |

### Response

Returns the products in the new order, in the same format as
`GET /v1/products`.
