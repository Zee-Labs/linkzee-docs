---

The content endpoints expose everything a visitor sees on a page's link zone —
loose links, collections (groups of links), and AI assistant items — plus a `meta`
block that summarizes the product showcase (counters, category chips, featured
products, and the first page of the catalog).

All requests go to `https://api.linkz.ee` and must include your API key:

```
Authorization: Bearer lzk_your_key
```

<Note>
Products are not part of the reorderable tree. The showcase is ordered
automatically (newest first), so reordering only affects links, collections, and
AI assistant items. Product entries sent to the reorder endpoint are ignored.
</Note>

## Get content tree

```
GET /v1/content
```

Returns the public content tree for your page, plus a `meta` summary of the
product showcase.

### Request

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/content
```

### Response

The `data` object has two parts: `meta` (showcase summary) and `root` (the
ordered list of content entries). Each `root` entry is one of `link`,
`collection`, or `ai_assistant`.

## Reorder content

```
PUT /v1/content/order
```

Sets the order of the entire link zone in one call. Send the full tree in the
order you want — each entry's position in the array becomes its new order.
Requires a key with the **write** scope.

### Request

```bash
curl -X PUT \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "root": [
      { "type": "link", "id": "507f1f77bcf86cd799439011" },
      {
        "type": "collection",
        "id": "507f1f77bcf86cd799439020",
        "children": [
          { "type": "link", "id": "507f1f77bcf86cd799439012" },
          { "type": "ai_assistant", "id": "507f1f77bcf86cd799439030" }
        ]
      }
    ]
  }' \
  https://api.linkz.ee/v1/content/order
```

### Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `root` | array | Yes | Top-level entries in their new order. May be empty. |
| `root[].type` | string | Yes | One of `link`, `collection`, `ai_assistant`, or `product`. |
| `root[].id` | string | Yes | The entry's ID. |
| `root[].children` | array | No | Child items, in order. Only used when `type` is `collection`. |
| `root[].children[].type` | string | Yes | One of `link`, `ai_assistant`, or `product`. |
| `root[].children[].id` | string | Yes | The child item's ID. |

<Warning>
Product entries (at the root or inside a collection) are accepted but ignored —
the showcase orders itself. Send only `link`, `collection`, and `ai_assistant`
entries to change what actually reorders. Unknown IDs are silently skipped.
</Warning>

### Response

```json
{
  "error": false,
  "message": "Content reordered successfully",
  "data": { "ok": true }
}
```
