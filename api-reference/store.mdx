A store holds a public page: its name, bio, social handles, design, special
cards, SEO fields, tracking and marketing settings. One Linkzee account can hold
**several stores**, so these endpoints always act on **one** of them: the store
your API key is bound to.

All requests go to `https://api.linkz.ee` and must include your API key:

```
Authorization: Bearer lzk_your_key
```

<Note>
  Reads need the **read** scope. Updates require a key with the **write** scope.
  To work with a different store, use a key created in that store. See
  [Authentication](/api-reference/authentication).
</Note>

## Get the store profile

```
GET /v1/store
```

Returns the owner view of the store. It is an **allow list**: only the fields
below are returned, and secrets never are. It is the same view the MCP tool
`get_store` returns.

### Request

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/store
```

### What the view includes

| Group | Fields |
| --- | --- |
| Profile | `id`, `name`, `slug`, `bio`, `bioSignature`, `seoTitle`, `seoDescription`, `timezone`, `location`, `publicPreferences`, `publicUrl`, `pageHidden` |
| Design | `themeId`, `overrides`, colors (`themeColor`, `buttonColor`, `buttonTextColor`, `buttonShadowColor`, `textColor`), `themeMode`, background fields (`background`, `bgColor2`, `bgFill`, `bgAngle`, `gradientPreset`, `bgAnimated`, `wallpaperUrl` and its options, aurora, mesh and pattern options), buttons (`buttonStyle`, `buttonRadius`, `buttonShadow`, `buttonText`), `fontId`, `fontPairId`, `cardStyle`, `cardRadius`, `texture`, `motionLevel`, `stageMode`, `saleStyle`, `socialStyle`, `avatarFx`, `wallpaperVideo` |
| Header | `headerLayout`, `titleStyle`, `logoUrl`, `bannerUrl`, `headerSettings` (`heroMedia`, `heroAvatar`, `shapeId`, `shapeColor`, `wordmarkUrl`, `heroPhotoUrl`, `cutoutUrl`, `heroVideo`) |
| Socials | `social`, `whatsapp`, `socialsPosition`, `socialOrder`, `socialCards` |
| Storefront and cards | `vitrineEnabled`, `vitrineStyle`, `gridDensity`, `vitrineLayout`, `vitrinePhotoFit`, `mapAddress`, `mapTheme`, `mapLayout`, `openingHours`, `servicesEnabled`, `packagesEnabled`, `instagramEnabled`, `googleReviewEnabled`, `googleReviewUrl`, `reviewsBlock` |
| AI assistant | `aiAssistantTone`, `aiEmoji` |
| PIX tips | `tips` as a summary: `enabled`, `pixKeyType`, `pixKeyPreview` (last 4 characters), `recipientName`. Never the key. |
| Agenda | `agenda` settings (no personal data). |
| Lead webhook | `leadWebhook` with only `host` and `enabled`. Never the path or the signing secret. |
| Tracking | `tracking`: pixel ids, `gtmId`, UTM defaults and `capiTokenConfigured`. Never the Conversion API token. |

<Note>
  `pageHidden: true` means the public page is off (`isActive: false`). The legacy
  root field `instagram` is still returned for old readers; use
  `social.instagram`.
</Note>

## Update the store profile

```
PATCH /v1/store
```

Updates one or more fields on the store. Send only the fields you want to change;
anything you omit stays as it is. Changes go live on the public page right away.

### Request

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
        "bio": "Brows and lashes in Pinheiros. Book online in two taps.",
        "themeId": "editorial",
        "socialsPosition": "top",
        "publicPreferences": { "locale": "en" }
      }' \
  https://api.linkz.ee/v1/store
```

### Parameters

Every field is optional; send only what you want to change.

| Parameter | Type | Description |
| --- | --- | --- |
| `name` | string | Display name of the store (max 120 chars). |
| `bio` | string | Short description shown under the name (max 500 chars). |
| `bioSignature` | string | One line signature below the bio (max 60 chars, no line breaks). |
| `titleStyle` | string | Header title style: `text` or `logo`. |
| `logoUrl`, `bannerUrl`, `wallpaperUrl` | string | Image URLs. Upload them first with [`POST /v1/uploads/image`](/api-reference/uploads). |
| `headerLayout` | string | `classic`, `hero`, `banner`, `cutout` or `shape`. |
| `headerSettings` | object | Header details: `wordmarkUrl`, `heroPhotoUrl`, `cutoutUrl`, `heroMedia`, `heroAvatar`, `shapeId`, `shapeColor`, `frames` and `media` (layouts and slots outside the allowed list are dropped, and the values are clamped). |
| `themeId` | string | Id of a ready made theme (see the theme catalog below). |
| `overrides` | string[] | Advanced: the design sections customized over `themeId`. |
| Design fields | various | The same design fields as the MCP tool `update_design`: colors, `themeMode`, background, buttons, `fontId`, `fontPairId`, `cardStyle`, `cardRadius`, `texture`, `motionLevel`, `stageMode`, `saleStyle`, `vitrineStyle`, `socialStyle`, `avatarFx`. |
| `social` | object | Social handles, for example `{ "instagram": "handle", "tiktok": "handle" }`. An empty string removes a network. |
| `whatsapp` | string | Number with country code, digits only. |
| `socialsPosition` | string | Where the social row appears: `top` or `bottom`. |
| `socialOrder` | string[] | Display order of the social icons. Only valid network keys (`whatsapp`, `instagram`, `tiktok`, `youtube` and the others). |
| `productsPosition` | string | Showcase position relative to links: `top` or `bottom`. |
| `vitrineEnabled`, `vitrineLayout`, `vitrineStyle`, `gridDensity`, `vitrinePhotoFit` | various | Showcase settings. `vitrineLayout`: `grid`, `masonry` or `carousel`. `vitrineStyle`: `classic` or `spotlight`. |
| `servicesEnabled`, `packagesEnabled`, `instagramEnabled` | boolean | Turn the services, packages and Instagram cards on or off. |
| `googleReviewEnabled`, `googleReviewUrl` | boolean, string | Google review card (Google Maps, `g.page` or `g.co` link). |
| `reviewsBlock` | object | Reviews card: `added`, `enabled`, `layout`, `limit` (1 to 10), `minRating` (1 to 5). |
| `mapAddress`, `mapTheme`, `mapLayout` | string | Map card. An empty `mapAddress` removes it; `mapLayout` is `map` or `card`. |
| `openingHours` | object | The "open now" badge: `source`, `showStatus`, `week`, `closedDates`. |
| `agenda` | object | Scheduling settings, merged partially. See the [Scheduling reference](/api-reference/agenda). |
| `tips` | object | PIX tips card: `enabled`, `pixKey`, `pixKeyType` (`email` or `random`), `recipientName` (max 25), `recipientCity` (max 15), `message`, `amounts`, `thanksMessage`, `highlight`. With a key, the name and the city are required. The owner gets an email when the key changes. |
| `timezone` | string | IANA time zone, for example `America/Sao_Paulo`. An invalid name returns `400`. |
| `location` | object | `countryCode` (ISO 2 letters), `state`, `city`. Drives the holiday calendar. |
| `publicPreferences` | object | `locale` of the public page (`pt-BR`, `en`, `es`, `fr`, `de`) and `translationFallback` (`original` or `dashboardLocale`). **Merged** with what is saved: sending only `locale` keeps the fallback. |
| `seoTitle` | string | Public page title for search engines (max 70 chars). |
| `seoDescription` | string | Public page meta description (max 160 chars). |
| `gtmId` | string | Google Tag Manager container id, for example `GTM-ABC123`. |
| `utmSource`, `utmMedium`, `utmCampaign` | string | Default UTM parameters added to outbound links. |
| `pixels` | object | Tracking pixel ids: `metaPixelId`, `tiktokPixelId`, `gaMeasurementId`. |
| `capiToken` | string | Meta Conversion API token. Sent in plain text, stored encrypted. Empty means "keep the current one". |
| `isActive` | boolean | Whether the public page is live. `false` hides it. |

### Theme inheritance

Updates through the API follow the same rules as the editor:

- `themeId` **without** `overrides` applies the preset clean: the overrides and
  the motion level saved before are reset.
- Any other design field on a preset store customizes **only its section**
  (colors, wallpaper, buttons, text, gradient, card, texture, motion), which
  starts from the theme palette. The rest keeps following the theme.
- Colors equal to the preset palette do not count as custom colors, so they do
  not hit the premium gate. Paid values (glass buttons, image, mesh, duotone or
  video backgrounds, animated or preset gradients, custom colors, paid fonts,
  `stageMode`) return `403` with `code: "PLAN_REQUIRED"` on a free plan.
- Send `overrides` when you want to list the customized sections yourself.

<Warning>
  The store `slug` cannot be changed through the API. Sending it has no effect:
  it is ignored so your published bio link never breaks.
</Warning>

### Response

The response is the same allow list view as `GET /v1/store`, plus `agentNotes`
when there is something to report:

```json
{
  "error": false,
  "message": "Store updated successfully",
  "data": {
    "id": "665f1c9a4b2e8a0012a3c9d1",
    "name": "Studio Ana",
    "bio": "Brows and lashes in Pinheiros. Book online in two taps.",
    "themeId": "editorial",
    "overrides": [],
    "socialsPosition": "top",
    "publicPreferences": { "locale": "en", "translationFallback": "original" },
    "pageHidden": false,
    "agentNotes": {
      "warnings": []
    }
  }
}
```

`agentNotes.warnings` lists fields that were saved but are not visible yet (for
example a `cutout` header without a cutout image, or a `wallpaperUrl` without an
image background). When the PIX key or the WhatsApp number changes,
`agentNotes` also carries the change with only the last 4 characters.

<Note>
  The showcase order is not a store field. It is newest first until the first
  [`PUT /v1/products/order`](/api-reference/products) that changes it; from then
  on the showcase follows your manual order.
</Note>

## Browse the theme catalog

```
GET /v1/themes
```

Lists the **18** ready made themes you can apply with `themeId`. Each entry
includes a short description to help you match a look to a store's style, and
`premium` for the paid ones.

### Request

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/themes
```

### Response

```json
{
  "error": false,
  "message": "Themes loaded",
  "data": [
    {
      "id": "pure",
      "name": "Pure",
      "mode": "light",
      "description": "Minimal light, near-white background, full focus on the products.",
      "premium": false
    },
    {
      "id": "noir",
      "name": "Noir",
      "mode": "dark",
      "description": "Sober dark, graphite grey, elegant and neutral.",
      "premium": false
    }
  ]
}
```

The full catalog has 18 themes: `pure`, `noir`, `gesso`, `solar`, `midnight`,
`groove`, `carbon`, `oceano`, `neon`, `pessego`, `selva`, `aurora`,
`brutalista`, `editorial`, `onix`, `perola`, `cinema` and `pista`. `onix`,
`perola` and `cinema` are paid.

<Note>
  Use any `id` from this list as the `themeId` when you update the store. The
  `id`s are stable; `name` and `description` are informational and returned in
  English.
</Note>

## Get a performance summary

```
GET /v1/analytics/summary
```

Returns headline metrics for the showcase: totals plus the top and most recent
products.

### Request

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/analytics/summary
```

### Response

```json
{
  "error": false,
  "message": "Dashboard retrieved successfully",
  "data": {
    "totalProducts": 42,
    "totalCategories": 6,
    "totalClicks": 1873,
    "topProducts": [
      {
        "id": "665f2a114b2e8a0012a3ca07",
        "name": "Bluetooth earbuds",
        "price": 79.9,
        "clicks": 312
      }
    ],
    "latestProducts": [
      {
        "id": "665f2b884b2e8a0012a3ca19",
        "name": "Desk lamp",
        "price": 129.9,
        "clicks": 4
      }
    ]
  }
}
```

| Field | Type | Description |
| --- | --- | --- |
| `totalProducts` | number | Total products in the showcase. |
| `totalCategories` | number | Total categories. |
| `totalClicks` | number | Sum of all product clicks. |
| `topProducts` | array | Up to 5 most clicked products. |
| `latestProducts` | array | Up to 5 most recently added products. |
