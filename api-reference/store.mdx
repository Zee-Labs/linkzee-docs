A store holds a public page: its name, bio, social handles, theme, SEO fields,
tracking pixels, and marketing settings. One Linkzee account can hold **several
stores**, so these endpoints always act on **one** of them — the store your API
key is bound to. They let you read the full profile, apply changes, list the
ready‑made themes, and fetch a quick performance summary.

All requests go to `https://api.linkz.ee` and must include your API key:

```
Authorization: Bearer lzk_your_key
```

<Note>
  Reads work with any key. Updates require a key with the **write** scope.
</Note>

<Note>
  To work with a different store, use a key created in that store — see
  [Authentication](/api-reference/authentication#which-store-a-key-acts-on).
</Note>

## Get the store profile

```
GET /v1/store
```

Returns the full profile for the store the key belongs to — identity, theme,
socials, SEO, and marketing settings.

### Request

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/store
```

### Response

```json
{
  "error": false,
  "message": "Store loaded successfully",
  "data": {
    "id": "665f1c9a4b2e8a0012a3c9d1",
    "slug": "achadinhos-da-gabi",
    "name": "Achadinhos da Gabi",
    "bio": "As melhores ofertas dos marketplaces, todo dia.",
    "titleStyle": "text",
    "themeId": "aurora",
    "themeMode": "dark",
    "socialsPosition": "top",
    "socialOrder": ["instagram", "tiktok", "whatsapp"],
    "productsPosition": "top",
    "social": {
      "instagram": "achadinhosdagabi",
      "tiktok": "achadinhosdagabi"
    },
    "seoTitle": "Achadinhos da Gabi",
    "seoDescription": "Ofertas selecionadas de Shopee, Amazon e Mercado Livre.",
    "gtmId": "GTM-ABC123",
    "capiTokenConfigured": true,
    "capiTokenPreview": "9f3a",
    "isActive": true
  }
}
```

<Note>
  The Conversion API token is never returned in full — you only see
  `capiTokenConfigured` and the last four characters in `capiTokenPreview`.
</Note>

## Update the store profile

```
PATCH /v1/store
```

Updates one or more fields on the store. Send only the fields you want to
change — anything you omit stays as it is. Changes go live on the public page
right away.

### Request

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
        "name": "Achadinhos da Gabi",
        "bio": "As melhores ofertas dos marketplaces.",
        "themeId": "aurora",
        "socialsPosition": "top",
        "seoTitle": "Achadinhos da Gabi"
      }' \
  https://api.linkz.ee/v1/store
```

### Parameters

Every field is optional; send only what you want to change.

| Parameter | Type | Description |
| --- | --- | --- |
| `name` | string | Display name of the store (max 120 chars). |
| `bio` | string | Short description shown under the name (max 500 chars). |
| `titleStyle` | string | Header title style: `text` or `logo`. |
| `logoUrl` | string | Logo image URL (http/https). |
| `bannerUrl` | string | Banner image URL (http/https). |
| `themeId` | string | Id of a ready‑made theme (see [themes](#browse-the-theme-catalog)); empty string means a custom design. |
| `themeMode` | string | Color mode: `dark` or `light`. |
| `socialsPosition` | string | Where the social row appears: `top` or `bottom`. |
| `socialOrder` | string[] | Display order of social networks. |
| `productsPosition` | string | Showcase position relative to links: `top` or `bottom`. |
| `vitrineLayout` | string | Showcase layout: `grid` (classic grid), `masonry` (mosaic) or `carousel` (one horizontal shelf per category with an inline "See all"). |
| `agenda` | object | Scheduling settings (enable/disable, title, timezone, business hours, reminders and more). Merged partially — send only the keys you want to change. See the [Scheduling reference](/api-reference/agenda). |
| `social` | object | Social handles, e.g. `{ "instagram": "handle", "tiktok": "handle" }`. |
| `seoTitle` | string | Public page title for search engines (max 70 chars). |
| `seoDescription` | string | Public page meta description (max 160 chars). |
| `gtmId` | string | Google Tag Manager container id, e.g. `GTM-ABC123`. |
| `utmSource` | string | Default UTM source added to outbound links. |
| `utmMedium` | string | Default UTM medium. |
| `utmCampaign` | string | Default UTM campaign. |
| `pixels` | object | Tracking pixel ids: `metaPixelId`, `tiktokPixelId`, `gaMeasurementId`. |
| `capiToken` | string | Meta Conversion API token. Sent in plain text, stored encrypted. Empty means "keep the current one". |
| `isActive` | boolean | Whether the page is published and live. |

<Warning>
  The store `slug` cannot be changed through the API. Sending it has no effect —
  it is ignored so your published bio link never breaks.
</Warning>

### Response

```json
{
  "error": false,
  "message": "Store updated successfully",
  "data": {
    "id": "665f1c9a4b2e8a0012a3c9d1",
    "slug": "achadinhos-da-gabi",
    "name": "Achadinhos da Gabi",
    "bio": "As melhores ofertas dos marketplaces.",
    "themeId": "aurora",
    "socialsPosition": "top",
    "seoTitle": "Achadinhos da Gabi",
    "isActive": true
  }
}
```

## Browse the theme catalog

```
GET /v1/themes
```

Lists the **15** ready‑made themes you can apply with `themeId`. Each entry
includes a short description to help you match a look to a store's style.

### Request

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/themes
```

### Response

```json
{
  "error": false,
  "message": "Themes loaded",
  "data": [
    {
      "id": "pure",
      "name": "Pure",
      "mode": "light",
      "description": "Minimal light, near-white background, full focus on the products."
    },
    {
      "id": "noir",
      "name": "Noir",
      "mode": "dark",
      "description": "Sober dark, graphite grey, elegant and neutral."
    },
    {
      "id": "aurora",
      "name": "Aurora",
      "mode": "dark",
      "description": "Animated violet/blue gradient, modern and premium."
    }
  ]
}
```

The full catalog has 15 themes: `pure`, `noir`, `gesso`, `solar`, `midnight`,
`groove`, `carbon`, `oceano`, `neon`, `pessego`, `selva`, `aurora`,
`brutalista`, `editorial` and `pista`.

<Note>
  Use any `id` from this list as the `themeId` when you update the store. The
  `id`s are stable — `name` and `description` are informational and returned in
  English.
</Note>

## Get a performance summary

```
GET /v1/analytics/summary
```

Returns headline metrics for the showcase — totals plus the top and most recent
products.

### Request

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/analytics/summary
```

### Response

```json
{
  "error": false,
  "message": "Dashboard retrieved successfully",
  "data": {
    "totalProducts": 42,
    "totalCategories": 6,
    "totalClicks": 1873,
    "topProducts": [
      {
        "id": "665f2a114b2e8a0012a3ca07",
        "name": "Fone Bluetooth TWS",
        "price": 79.9,
        "clicks": 312
      }
    ],
    "latestProducts": [
      {
        "id": "665f2b884b2e8a0012a3ca19",
        "name": "Luminária de mesa articulada",
        "price": 129.9,
        "clicks": 4
      }
    ]
  }
}
```

| Field | Type | Description |
| --- | --- | --- |
| `totalProducts` | number | Total products in the showcase. |
| `totalCategories` | number | Total categories. |
| `totalClicks` | number | Sum of all product clicks. |
| `topProducts` | array | Up to 5 most‑clicked products. |
| `latestProducts` | array | Up to 5 most recently added products. |
