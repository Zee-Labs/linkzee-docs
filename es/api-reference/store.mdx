Una tienda contiene una página pública: su nombre, bio, redes sociales, diseño,
tarjetas especiales, campos de SEO, ajustes de seguimiento y de marketing. Una sola
cuenta de Linkzee puede tener **varias tiendas**, así que estos endpoints siempre
actúan sobre **una** de ellas: la tienda a la que está vinculada tu clave de API.

Todas las solicitudes van a `https://api.linkz.ee` y deben incluir tu clave de API:

```
Authorization: Bearer lzk_your_key
```

<Note>
  Las lecturas necesitan el alcance **read**. Las actualizaciones requieren una
  clave con el alcance **write**. Para trabajar con otra tienda, usa una clave
  creada en esa tienda. Consulta [Autenticación](/es/api-reference/authentication).
</Note>

## Obtener el perfil de la tienda

```
GET /v1/store
```

Devuelve la vista del dueño de la tienda. Es una **lista permitida**: solo se
devuelven los campos de abajo, y los secretos nunca. Es la misma vista que devuelve
la herramienta MCP `get_store`.

### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/store
```

### Qué incluye la vista

| Grupo | Campos |
| --- | --- |
| Perfil | `id`, `name`, `slug`, `bio`, `bioSignature`, `seoTitle`, `seoDescription`, `timezone`, `location`, `publicPreferences`, `publicUrl`, `pageHidden` |
| Diseño | `themeId`, `overrides`, colores (`themeColor`, `buttonColor`, `buttonTextColor`, `buttonShadowColor`, `textColor`), `themeMode`, campos de fondo (`background`, `bgColor2`, `bgFill`, `bgAngle`, `gradientPreset`, `bgAnimated`, `wallpaperUrl` y sus opciones, opciones de aurora, mesh y pattern), botones (`buttonStyle`, `buttonRadius`, `buttonShadow`, `buttonText`), `fontId`, `fontPairId`, `cardStyle`, `cardRadius`, `texture`, `motionLevel`, `stageMode`, `saleStyle`, `socialStyle`, `avatarFx`, `wallpaperVideo` |
| Encabezado | `headerLayout`, `titleStyle`, `logoUrl`, `bannerUrl`, `headerSettings` (`heroMedia`, `heroAvatar`, `shapeId`, `shapeColor`, `wordmarkUrl`, `heroPhotoUrl`, `cutoutUrl`, `heroVideo`) |
| Redes | `social`, `whatsapp`, `socialsPosition`, `socialOrder`, `socialCards` |
| Vitrina y tarjetas | `vitrineEnabled`, `vitrineStyle`, `gridDensity`, `vitrineLayout`, `vitrinePhotoFit`, `mapAddress`, `mapTheme`, `mapLayout`, `openingHours`, `servicesEnabled`, `packagesEnabled`, `instagramEnabled`, `googleReviewEnabled`, `googleReviewUrl`, `reviewsBlock` |
| Asistente de IA | `aiAssistantTone`, `aiEmoji` |
| Propinas PIX | `tips` como resumen: `enabled`, `pixKeyType`, `pixKeyPreview` (últimos 4 caracteres), `recipientName`. Nunca la clave. |
| Agenda | Ajustes de `agenda` (sin datos personales). |
| Webhook de leads | `leadWebhook` solo con `host` y `enabled`. Nunca la ruta ni el secreto de firma. |
| Seguimiento | `tracking`: ids de los píxeles, `gtmId`, UTM predeterminadas y `capiTokenConfigured`. Nunca el token de la Conversion API. |

<Note>
  `pageHidden: true` significa que la página pública está desactivada
  (`isActive: false`). El campo heredado de raíz `instagram` todavía se devuelve
  para lectores antiguos; usa `social.instagram`.
</Note>

## Actualizar el perfil de la tienda

```
PATCH /v1/store
```

Actualiza uno o más campos de la tienda. Envía solo los campos que quieras cambiar;
todo lo que omitas permanece igual. Los cambios se publican en la página pública de
inmediato.

### Solicitud

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
        "bio": "Brows and lashes in Pinheiros. Book online in two taps.",
        "themeId": "editorial",
        "socialsPosition": "top",
        "publicPreferences": { "locale": "en" }
      }' \
  https://api.linkz.ee/v1/store
```

### Parámetros

Todos los campos son opcionales; envía solo lo que quieras cambiar.

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| `name` | string | Nombre visible de la tienda (máx. 120 caracteres). |
| `bio` | string | Descripción corta que se muestra bajo el nombre (máx. 500 caracteres). |
| `bioSignature` | string | Firma de una línea bajo la bio (máx. 60 caracteres, sin saltos de línea). |
| `titleStyle` | string | Estilo del título del encabezado: `text` o `logo`. |
| `logoUrl`, `bannerUrl`, `wallpaperUrl` | string | URLs de imágenes. Súbelas primero con [`POST /v1/uploads/image`](/es/api-reference/uploads). |
| `headerLayout` | string | `classic`, `hero`, `banner`, `cutout` o `shape`. |
| `headerSettings` | object | Detalles del encabezado: `wordmarkUrl`, `heroPhotoUrl`, `cutoutUrl`, `heroMedia`, `heroAvatar`, `shapeId`, `shapeColor`, `frames` y `media` (los layouts y slots fuera de la lista permitida se descartan, y los valores se acotan). |
| `themeId` | string | Id de un tema predefinido (consulta el catálogo de temas más abajo). |
| `overrides` | string[] | Avanzado: las secciones de diseño personalizadas sobre `themeId`. |
| Campos de diseño | varios | Los mismos campos de diseño que la herramienta MCP `update_design`: colores, `themeMode`, fondo, botones, `fontId`, `fontPairId`, `cardStyle`, `cardRadius`, `texture`, `motionLevel`, `stageMode`, `saleStyle`, `vitrineStyle`, `socialStyle`, `avatarFx`. |
| `social` | object | Usuarios de redes sociales, por ejemplo `{ "instagram": "handle", "tiktok": "handle" }`. Un string vacío elimina una red. |
| `whatsapp` | string | Número con código de país, solo dígitos. |
| `socialsPosition` | string | Dónde aparece la fila de redes sociales: `top` o `bottom`. |
| `socialOrder` | string[] | Orden de visualización de los íconos de redes. Solo claves de red válidas (`whatsapp`, `instagram`, `tiktok`, `youtube` y las demás). |
| `productsPosition` | string | Posición de la vitrina respecto a los enlaces: `top` o `bottom`. |
| `vitrineEnabled`, `vitrineLayout`, `vitrineStyle`, `gridDensity`, `vitrinePhotoFit` | varios | Ajustes de la vitrina. `vitrineLayout`: `grid`, `masonry` o `carousel`. `vitrineStyle`: `classic` o `spotlight`. |
| `servicesEnabled`, `packagesEnabled`, `instagramEnabled` | boolean | Activa o desactiva las tarjetas de servicios, paquetes e Instagram. |
| `googleReviewEnabled`, `googleReviewUrl` | boolean, string | Tarjeta de reseña de Google (enlace de Google Maps, `g.page` o `g.co`). |
| `reviewsBlock` | object | Tarjeta de reseñas: `added`, `enabled`, `layout`, `limit` (de 1 a 10), `minRating` (de 1 a 5). |
| `mapAddress`, `mapTheme`, `mapLayout` | string | Tarjeta de mapa. Un `mapAddress` vacío la elimina; `mapLayout` es `map` o `card`. |
| `openingHours` | object | El distintivo "abierto ahora": `source`, `showStatus`, `week`, `closedDates`. |
| `agenda` | object | Ajustes de reservas, combinados parcialmente. Consulta la [referencia de Agenda](/es/api-reference/agenda). |
| `tips` | object | Tarjeta de propinas PIX: `enabled`, `pixKey`, `pixKeyType` (`email` o `random`), `recipientName` (máx. 25), `recipientCity` (máx. 15), `message`, `amounts`, `thanksMessage`, `highlight`. Con una clave, el nombre y la ciudad son obligatorios. El dueño recibe un email cuando cambia la clave. |
| `timezone` | string | Zona horaria IANA, por ejemplo `America/Sao_Paulo`. Un nombre inválido devuelve `400`. |
| `location` | object | `countryCode` (ISO de 2 letras), `state`, `city`. Define el calendario de feriados. |
| `publicPreferences` | object | `locale` de la página pública (`pt-BR`, `en`, `es`, `fr`, `de`) y `translationFallback` (`original` o `dashboardLocale`). Se **combina** con lo guardado: enviar solo `locale` conserva la alternativa. |
| `seoTitle` | string | Título de la página pública para los buscadores (máx. 70 caracteres). |
| `seoDescription` | string | Meta descripción de la página pública (máx. 160 caracteres). |
| `gtmId` | string | Id del contenedor de Google Tag Manager, por ejemplo `GTM-ABC123`. |
| `utmSource`, `utmMedium`, `utmCampaign` | string | Parámetros UTM predeterminados que se añaden a los enlaces de salida. |
| `pixels` | object | Ids de los píxeles de seguimiento: `metaPixelId`, `tiktokPixelId`, `gaMeasurementId`. |
| `capiToken` | string | Token de la Meta Conversion API. Se envía en texto plano y se almacena cifrado. Vacío significa "mantener el actual". |
| `isActive` | boolean | Si la página pública está en línea. `false` la oculta. |

### Herencia del tema

Las actualizaciones por la API siguen las mismas reglas que el editor:

- `themeId` **sin** `overrides` aplica el preset limpio: se restablecen las
  personalizaciones y el nivel de movimiento guardados antes.
- Cualquier otro campo de diseño en una tienda con preset personaliza **solo su
  sección** (colores, fondo de pantalla, botones, texto, degradado, tarjeta,
  textura, movimiento), que parte de la paleta del tema. El resto sigue el tema.
- Los colores iguales a la paleta del preset no cuentan como colores
  personalizados, así que no activan el bloqueo premium. Los valores de pago
  (botones de vidrio, fondos de imagen, mesh, duotone o video, degradados animados
  o predefinidos, colores personalizados, fuentes de pago, `stageMode`) devuelven
  `403` con `code: "PLAN_REQUIRED"` en un plan gratuito.
- Envía `overrides` cuando quieras listar tú mismo las secciones personalizadas.

<Warning>
  El `slug` de la tienda no se puede cambiar a través de la API. Enviarlo no tiene
  efecto: se ignora para que el enlace de tu bio publicada nunca se rompa.
</Warning>

### Respuesta

La respuesta es la misma vista de lista permitida que `GET /v1/store`, más
`agentNotes` cuando hay algo que informar:

```json
{
  "error": false,
  "message": "Store updated successfully",
  "data": {
    "id": "665f1c9a4b2e8a0012a3c9d1",
    "name": "Studio Ana",
    "bio": "Brows and lashes in Pinheiros. Book online in two taps.",
    "themeId": "editorial",
    "overrides": [],
    "socialsPosition": "top",
    "publicPreferences": { "locale": "en", "translationFallback": "original" },
    "pageHidden": false,
    "agentNotes": {
      "warnings": []
    }
  }
}
```

`agentNotes.warnings` lista los campos que se guardaron pero todavía no son
visibles (por ejemplo un encabezado `cutout` sin imagen recortada, o un
`wallpaperUrl` sin fondo de imagen). Cuando cambia la clave PIX o el número de
WhatsApp, `agentNotes` también trae el cambio con solo los últimos 4 caracteres.

<Note>
  El orden de la vitrina no es un campo de la tienda. Es de los más nuevos primero
  hasta el primer [`PUT /v1/products/order`](/es/api-reference/products) que lo
  cambia; a partir de entonces la vitrina sigue tu orden manual.
</Note>

## Explorar el catálogo de temas

```
GET /v1/themes
```

Lista los **23** temas predefinidos que puedes aplicar con `themeId`. Cada entrada
incluye una descripción corta para ayudarte a combinar un estilo con la estética de
una tienda, y `premium` para los de pago.

### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/themes
```

### Respuesta

```json
{
  "error": false,
  "message": "Themes loaded",
  "data": [
    {
      "id": "pure",
      "name": "Pure",
      "mode": "light",
      "description": "Minimal light, near-white background, full focus on the products.",
      "premium": false
    },
    {
      "id": "noir",
      "name": "Noir",
      "mode": "dark",
      "description": "Sober dark, graphite grey, elegant and neutral.",
      "premium": false
    }
  ]
}
```

El catálogo completo tiene 23 temas. Gratis: `pure`, `noir`, `gesso`, `solar`, `midnight`, `groove`, `carbon`, `oceano`, `neon`, `pessego`, `selva`, `aurora`, `brutalista`, `editorial`, `pista`. De pago: `motion-neon`, `motion-clean`, `motion-achadinhos`, `motion-boutique`, `onix`, `cinema`, `perola`, `iridescente`.

<Note>
  Usa cualquier `id` de esta lista como `themeId` cuando actualices la tienda. Los
  `id` son estables; `name` y `description` son informativos y se devuelven en
  inglés.
</Note>

## Obtener un resumen de rendimiento

```
GET /v1/analytics/summary
```

Devuelve las métricas principales de la vitrina: totales más los productos con más
clics y los más recientes.

### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/analytics/summary
```

### Respuesta

```json
{
  "error": false,
  "message": "Dashboard retrieved successfully",
  "data": {
    "totalProducts": 42,
    "totalCategories": 6,
    "totalClicks": 1873,
    "topProducts": [
      {
        "id": "665f2a114b2e8a0012a3ca07",
        "name": "Bluetooth earbuds",
        "price": 79.9,
        "clicks": 312
      }
    ],
    "latestProducts": [
      {
        "id": "665f2b884b2e8a0012a3ca19",
        "name": "Desk lamp",
        "price": 129.9,
        "clicks": 4
      }
    ]
  }
}
```

| Campo | Tipo | Descripción |
| --- | --- | --- |
| `totalProducts` | number | Total de productos en la vitrina. |
| `totalCategories` | number | Total de categorías. |
| `totalClicks` | number | Suma de todos los clics en productos. |
| `topProducts` | array | Hasta 5 productos con más clics. |
| `latestProducts` | array | Hasta 5 productos añadidos más recientemente. |
