La tienda es el corazón de una cuenta de Linkzee: su nombre, biografía, redes
sociales, tema, campos de SEO, píxeles de seguimiento y ajustes de marketing.
Estos endpoints te permiten leer el perfil completo, aplicar cambios, listar los
temas predefinidos y obtener un resumen rápido de rendimiento.

Todas las solicitudes van a `https://api.linkz.ee` y deben incluir tu clave de API:

```
Authorization: Bearer lzk_your_key
```

<Note>
  Las lecturas funcionan con cualquier clave. Las actualizaciones requieren una clave con el permiso **write**.
</Note>

## Obtener el perfil de la tienda

```
GET /v1/store
```

Devuelve el perfil completo de la tienda a la que pertenece la clave: identidad,
tema, redes sociales, SEO y ajustes de marketing.

### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/store
```

### Respuesta

```json
{
  "error": false,
  "message": "Store loaded successfully",
  "data": {
    "id": "665f1c9a4b2e8a0012a3c9d1",
    "slug": "achadinhos-da-gabi",
    "name": "Achadinhos da Gabi",
    "bio": "As melhores ofertas dos marketplaces, todo dia.",
    "titleStyle": "text",
    "themeId": "aurora",
    "themeMode": "dark",
    "socialsPosition": "top",
    "socialOrder": ["instagram", "tiktok", "whatsapp"],
    "productsPosition": "top",
    "social": {
      "instagram": "achadinhosdagabi",
      "tiktok": "achadinhosdagabi"
    },
    "seoTitle": "Achadinhos da Gabi",
    "seoDescription": "Ofertas selecionadas de Shopee, Amazon e Mercado Livre.",
    "gtmId": "GTM-ABC123",
    "capiTokenConfigured": true,
    "capiTokenPreview": "9f3a",
    "isActive": true
  }
}
```

<Note>
  El token de la Conversion API nunca se devuelve completo: solo ves
  `capiTokenConfigured` y los últimos cuatro caracteres en `capiTokenPreview`.
</Note>

## Actualizar el perfil de la tienda

```
PATCH /v1/store
```

Actualiza uno o más campos de la tienda. Envía solo los campos que quieras
cambiar; todo lo que omitas permanece igual. Los cambios se publican en la
página pública de inmediato.

### Solicitud

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
        "name": "Achadinhos da Gabi",
        "bio": "As melhores ofertas dos marketplaces.",
        "themeId": "aurora",
        "socialsPosition": "top",
        "seoTitle": "Achadinhos da Gabi"
      }' \
  https://api.linkz.ee/v1/store
```

### Parámetros

Todos los campos son opcionales; envía solo lo que quieras cambiar.

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| `name` | string | Nombre visible de la tienda (máx. 120 caracteres). |
| `bio` | string | Descripción corta que se muestra bajo el nombre (máx. 500 caracteres). |
| `titleStyle` | string | Estilo del título del encabezado: `text` o `logo`. |
| `logoUrl` | string | URL de la imagen del logo (http/https). |
| `bannerUrl` | string | URL de la imagen del banner (http/https). |
| `themeId` | string | Id de un tema predefinido (ver [temas](#browse-the-theme-catalog)); una cadena vacía significa un diseño personalizado. |
| `themeMode` | string | Modo de color: `dark` o `light`. |
| `socialsPosition` | string | Dónde aparece la fila de redes sociales: `top` o `bottom`. |
| `socialOrder` | string[] | Orden de visualización de las redes sociales. |
| `productsPosition` | string | Posición de la vitrina respecto a los enlaces: `top` o `bottom`. |
| `social` | object | Usuarios de redes sociales, p. ej. `{ "instagram": "handle", "tiktok": "handle" }`. |
| `seoTitle` | string | Título de la página pública para los buscadores (máx. 70 caracteres). |
| `seoDescription` | string | Meta descripción de la página pública (máx. 160 caracteres). |
| `gtmId` | string | Id del contenedor de Google Tag Manager, p. ej. `GTM-ABC123`. |
| `utmSource` | string | Origen UTM predeterminado añadido a los enlaces de salida. |
| `utmMedium` | string | Medio UTM predeterminado. |
| `utmCampaign` | string | Campaña UTM predeterminada. |
| `pixels` | object | Ids de los píxeles de seguimiento: `metaPixelId`, `tiktokPixelId`, `gaMeasurementId`. |
| `capiToken` | string | Token de la Meta Conversion API. Se envía en texto plano y se almacena cifrado. Vacío significa "mantener el actual". |
| `isActive` | boolean | Si la página está publicada y activa. |

<Warning>
  El `slug` de la tienda no se puede cambiar a través de la API. Enviarlo no tiene
  efecto: se ignora para que el enlace de tu biografía publicada nunca se rompa.
</Warning>

### Respuesta

```json
{
  "error": false,
  "message": "Store updated successfully",
  "data": {
    "id": "665f1c9a4b2e8a0012a3c9d1",
    "slug": "achadinhos-da-gabi",
    "name": "Achadinhos da Gabi",
    "bio": "As melhores ofertas dos marketplaces.",
    "themeId": "aurora",
    "socialsPosition": "top",
    "seoTitle": "Achadinhos da Gabi",
    "isActive": true
  }
}
```

## Explorar el catálogo de temas

```
GET /v1/themes
```

Lista los temas predefinidos que puedes aplicar con `themeId`. Cada entrada
incluye una descripción corta para ayudarte a combinar un estilo con la estética
de una tienda.

### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/themes
```

### Respuesta

```json
{
  "error": false,
  "message": "Themes loaded",
  "data": [
    {
      "id": "pure",
      "name": "Puro",
      "mode": "light",
      "description": "Claro minimalista, fundo quase branco, foco total nos produtos."
    },
    {
      "id": "noir",
      "name": "Noir",
      "mode": "dark",
      "description": "Escuro sóbrio, cinza-grafite, elegante e neutro."
    },
    {
      "id": "aurora",
      "name": "Aurora",
      "mode": "dark",
      "description": "Gradiente violeta/azul animado, moderno e premium."
    }
  ]
}
```

<Note>
  Usa cualquier `id` de esta lista como `themeId` cuando actualices la tienda.
</Note>

## Obtener un resumen de rendimiento

```
GET /v1/analytics/summary
```

Devuelve las métricas principales de la vitrina: totales más los productos
destacados y los más recientes.

### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/analytics/summary
```

### Respuesta

```json
{
  "error": false,
  "message": "Dashboard retrieved successfully",
  "data": {
    "totalProducts": 42,
    "totalCategories": 6,
    "totalClicks": 1873,
    "topProducts": [
      {
        "id": "665f2a114b2e8a0012a3ca07",
        "name": "Fone Bluetooth TWS",
        "price": 79.9,
        "clicks": 312
      }
    ],
    "latestProducts": [
      {
        "id": "665f2b884b2e8a0012a3ca19",
        "name": "Luminária de mesa articulada",
        "price": 129.9,
        "clicks": 4
      }
    ]
  }
}
```

| Campo | Tipo | Descripción |
| --- | --- | --- |
| `totalProducts` | number | Total de productos en la vitrina. |
| `totalCategories` | number | Total de categorías. |
| `totalClicks` | number | Suma de todos los clics en productos. |
| `topProducts` | array | Hasta 5 productos con más clics. |
| `latestProducts` | array | Hasta 5 productos añadidos más recientemente. |
