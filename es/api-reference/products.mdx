Los productos son los ítems de tu vitrina pública. Cada producto tiene un nombre,
un precio opcional, una imagen y un enlace de afiliado o de producto. Usa estos
endpoints para mantener tu catálogo sincronizado desde tus propios sistemas.

Todas las solicitudes van a `https://api.linkz.ee` y deben incluir tu clave de API:

```
Authorization: Bearer lzk_your_key
```

<Note>
Leer productos (`GET`) necesita el alcance **read**. Crear, actualizar, eliminar o
reordenar un producto requiere una clave con el alcance **write**.
</Note>

## Orden de la vitrina

La vitrina tiene dos modos de orden:

- **Los más nuevos primero** (por defecto): los productos más recientes van primero.
- **Manual**: se activa con la primera reordenación (consulta "Reordenar productos"
  más abajo) que cambia el orden que ven los visitantes. A partir de entonces la
  vitrina sigue el `order` de cada producto, y los productos nuevos entran arriba.

`GET /v1/products`, la herramienta MCP `list_products` y la página pública siempre
devuelven los productos en el orden que ven los visitantes. No hay endpoint para
volver a los más nuevos primero.

## Listar productos

```
GET /v1/products
```

Devuelve todos los productos de tu tienda, en el orden de la vitrina.

### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/products
```

## Obtener un producto

```
GET /v1/products/{id}
```

Devuelve un único producto por su ID. La respuesta es una lista permitida de los
campos del producto (la misma vista que la herramienta MCP `get_product`); los
campos internos nunca se devuelven.

### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/products/665f1a2b9c4e1f0012a3b4c5
```

### Parámetros

| `id` | string (ruta) | Sí | El ID del producto. |

## Crear un producto

```
POST /v1/products
```

Crea un producto en tu vitrina. Requiere el alcance **write**.

Puedes enviar los campos del producto directamente, o enviar solo una `url` de
marketplace y dejar que Linkzee obtenga el nombre, el precio y la imagen por ti. Si
la búsqueda automática vuelve incompleta, envía al menos `name` para que el
producto se pueda guardar.

### Solicitud

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: sync-SKU-1042" \
  -d '{
    "name": "Wireless Headphones XYZ",
    "description": "Bluetooth 5.3, 30h battery",
    "price": 99.9,
    "priceOriginal": 149.9,
    "imageUrl": "https://example.com/headphones.jpg",
    "externalLink": "https://shopee.com.br/product/123",
    "badge": "Deal",
    "isFeatured": true,
    "externalId": "SKU-1042"
  }' \
  https://api.linkz.ee/v1/products
```

### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `name` | string | Condicional | Nombre del producto (máx. 160). Opcional cuando se envía `url`: se completa con la búsqueda en el marketplace. |
| `url` | string | No | URL del marketplace. Cuando se envía sin `name` o `price`, Linkzee intenta completarlos automáticamente. |
| `slug` | string | No | Slug personalizado (máx. 80). Se deriva del nombre si se omite; único por tienda. |
| `description` | string | No | Descripción corta (máx. 2000). |
| `price` | number | No | Precio actual en R$. Omítelo para un producto "sin precio". |
| `priceOriginal` | number | No | Precio original, usado para mostrar un descuento. |
| `installments` | string | No | Texto de las cuotas, por ejemplo `3x of R$ 33.30` (máx. 80). |
| `imageUrl` | string | No | URL de la imagen principal (http o https). Las URLs externas se copian a la CDN de Linkzee. |
| `gallery` | string[] | No | Hasta 10 URLs de imágenes adicionales. |
| `externalLink` | string | No | Enlace de afiliado o de producto (http o https). Un producto sin enlace queda como borrador oculto. |
| `buttonText` | string | No | Texto del botón de acción (máx. 60), por ejemplo `Buy`. |
| `badge` | string | No | Etiqueta promocional corta (máx. 28), por ejemplo `Deal`. |
| `categoryId` | string | No | ID de la categoría a la que pertenece este producto. |
| `isActive` | boolean | No | Si el producto es visible en la vitrina. Por defecto `true`. |
| `isFeatured` | boolean | No | Agrega el producto al carrusel de destacados. |
| `highlightFx` | string | No | Resaltado animado (Premium): `""`, `"shake"`, `"shine"`, `"pulse"` o `"bounce"`. |
| `cardSize` | string | No | `normal` o `wide` (una tarjeta `wide` ocupa las dos columnas de la cuadrícula). |
| `offerEndsAt` | string | No | Fecha de fin de la oferta (ISO 8601). |
| `offerDurationMinutes` | number | No | Duración de la cuenta regresiva de escasez, en minutos (relativa, se reinicia por visitante). |
| `showCountdown` | boolean | No | Muestra la cuenta regresiva en la tarjeta. |
| `externalId` | string | No | Tu propia referencia para este producto (un id de CRM o ERP, o un SKU) para relacionarlo con tus sistemas (máx. 64). Nunca se muestra en tu página pública. |
| `barcode` | string | No | Código de barras del producto: EAN, GTIN o UPC (máx. 32). Nunca se muestra públicamente. |

<Note>
Envía un header `Idempotency-Key` para reintentar con seguridad: repetir la
solicitud con la misma clave y el mismo cuerpo dentro de 24 horas devuelve el
producto creado la primera vez en lugar de un duplicado. La misma clave con un
cuerpo distinto devuelve `409`. Consulta [Límites de tasa](/es/api-reference/rate-limits).
</Note>

### Respuesta

  "message": "Product created successfully",
  "data": {
    "id": "665f1a2b9c4e1f0012a3b4c5",
    "name": "Wireless Headphones XYZ",

## Actualizar un producto

```
PATCH /v1/products/{id}
```

Actualiza cualquier subconjunto de los campos de un producto. Requiere el alcance
**write**. Solo cambian los campos que envías.

### Solicitud

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "price": 89.9,
    "badge": "Flash sale",
    "isActive": false
  }' \
  https://api.linkz.ee/v1/products/665f1a2b9c4e1f0012a3b4c5
```

### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `id` | string (ruta) | Sí | El ID del producto. |

El cuerpo acepta los mismos campos que **Crear un producto**, excepto `url` (la
búsqueda automática solo se ejecuta al crear). Todos los campos son opcionales.
Envía `categoryId: null` para quitar el producto de su categoría y
`offerEndsAt: null` para borrar la fecha de fin de la oferta.

### Respuesta

```json
{
  "error": false,
  "message": "Product updated successfully",
  "data": {
    "id": "665f1a2b9c4e1f0012a3b4c5",
    "name": "Wireless Headphones XYZ",
    "price": 89.9,
    "badge": "Flash sale",
    "isActive": false
  }
}
```

## Eliminar un producto

```
DELETE /v1/products/{id}
```

Quita un producto de tu vitrina. Requiere el alcance **write**.

### Solicitud

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/products/665f1a2b9c4e1f0012a3b4c5
```

### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `id` | string (ruta) | Sí | El ID del producto. |

### Respuesta

```json
{
  "error": false,
  "message": "Product deleted successfully"
}
```

## Reordenar productos

```
PUT /v1/products/order
```

Define la posición de los productos en la vitrina. Requiere el alcance **write**.
Cada ítem se mueve a la posición indicada por `order` (`0` es arriba):

- Envía la lista **completa** para un orden exacto.
- Envía solo los productos que quieras mover: los demás conservan su orden relativo.

La primera reordenación que cambia lo que ven los visitantes pasa la vitrina a orden
manual (consulta "Orden de la vitrina" más arriba).

### Solicitud

```bash
curl -X PUT \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "items": [
      { "id": "665f1a2b9c4e1f0012a3b4c5", "order": 0 },
      { "id": "665f1a2b9c4e1f0012a3b4c6", "order": 1 }
    ]
  }' \
  https://api.linkz.ee/v1/products/order
```

### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `items` | array | Sí | De 1 a 5000 ítems. |
| `items[].id` | string | Sí | El ID del producto. |
| `items[].order` | integer | Sí | Nueva posición (`0` es arriba). |

### Respuesta

Devuelve los productos en el nuevo orden, en el mismo formato que
`GET /v1/products`.
