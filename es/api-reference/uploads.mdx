Usa estos endpoints para llevar imágenes y videos a Linkzee. Las imágenes vuelven
como una URL permanente alojada en CDN que colocas en un producto, un enlace o tu
tienda. Los videos se optimizan en segundo plano y se aplican a tu página cuando
están listos.

Los endpoints se encuentran bajo la URL base `https://api.linkz.ee` y requieren el
header `Authorization: Bearer lzk_your_key`. Subir archivos modifica tu página, así
que necesita una clave con el alcance **write**. Leer un trabajo de video solo
necesita **read**.

## Subir una imagen

```
POST /v1/uploads/image
```

Sube una única imagen y devuelve su URL alojada. Envía la petición como
`multipart/form-data`, no como JSON. Cada imagen se convierte a **WebP**, se
redimensiona para caber dentro de 1600&nbsp;px y se sirve con caché de larga
duración.

### Petición

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -F "file=@/path/to/photo.jpg" \
  -F "kind=product" \
  -F "productId=507f1f77bcf86cd799439011" \
  https://api.linkz.ee/v1/uploads/image
```

### Parámetros

Envía estos como campos de formulario multipart.

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `file` | file | Sí | La imagen, hasta **8&nbsp;MB**. JPEG, PNG, WebP, GIF o AVIF. El formato se verifica por los bytes del archivo. HEIC, SVG, TIFF y PDF se rechazan. |
| `kind` | string | Sí | Dónde pertenece la imagen. Define una ubicación de almacenamiento fija, de modo que una nueva subida del mismo tipo reemplaza la imagen anterior. Consulta la tabla de abajo. Una petición sin `kind` se rechaza. |
| `productId` | string | Con `kind=product` | El producto al que pertenece la imagen, en tu propia tienda. |
| `linkId` | string | Con `link`, `linkMedia`, `linkPoster` o `linkMediaSlot` | El enlace al que pertenece la imagen, en tu propia tienda. |
| `slot` | string | Con `kind=linkMediaSlot` | El slot de foto (`0` a `9`) de un bloque Antes y Después o Galería. Volver a subir el mismo slot reemplaza la foto. |
| `staffId` | string | Con `kind=staffAvatar` | El miembro del equipo al que pertenece el avatar. |
| `socialKey` | string | Con `kind=socialCard` | La red social de la portada de la tarjeta, por ejemplo `instagram`. |

#### Valores para `kind`

| `kind` | Úsalo para | Envía también |
| --- | --- | --- |
| `logo` | El logo de tu tienda | |
| `product` | La imagen de un producto | `productId` |
| `wallpaper` | El fondo de pantalla de tu página | |
| `banner` | El banner de tu encabezado | |
| `cutout` | Una imagen recortada del encabezado (usa un PNG o WebP con transparencia) | |
| `wordmark` | El logotipo horizontal que se muestra en lugar del nombre de la tienda (estilo de título **Logo**). Guarda la URL en `headerSettings.wordmarkUrl` con `PATCH /v1/store` | |
| `heroPhoto` | La foto de portada del encabezado **Hero**, separada del logo. Guarda la URL en `headerSettings.heroPhotoUrl` | |
| `link` | La miniatura de un enlace | `linkId` |
| `linkMedia` | La portada de la tarjeta de un enlace | `linkId` |
| `linkPoster` | El póster del video de un enlace | `linkId` |
| `linkMediaSlot` | Una foto de un bloque Antes y Después o Galería (Premium; redimensionada para caber dentro de 1344×2016) | `linkId`, `slot` |
| `aiAssistantAvatar` | El avatar de tu asistente de IA | |
| `staffAvatar` | La foto de un miembro del equipo | `staffId` |
| `socialCard` | La portada de la tarjeta de una red social | `socialKey` |
| `wallpaperPoster`, `heroPoster` | Heredados. Los pósteres de video ahora se generan a partir del video | |

<Warning>
Los archivos de más de 8&nbsp;MB se rechazan con `413`. Un archivo que no es una
imagen aceptada devuelve `400 Bad Request`. Cuando envías `productId`, `linkId` o
`staffId`, debe hacer referencia a un recurso de tu propia tienda.
</Warning>

### Respuesta

La URL termina con un marcador de versión `?v=` que cambia en cada subida, de modo
que una imagen reemplazada nunca se sirve desde una caché antigua. Usa siempre la
URL exacta que recibes de vuelta.

```json
{
  "error": false,
  "message": "Upload completed successfully",
  "data": {
    "url": "https://cdn.linkz.ee/u/abc/products/507f1f77bcf86cd799439011.webp?v=1721577600000",
    "width": 1200,
    "height": 1200,
    "format": "webp",
    "hasAlpha": false
  }
}
```

| Campo | Tipo | Descripción |
| --- | --- | --- |
| `url` | string | La URL de la imagen alojada, con invalidación de caché. |
| `width` | integer | Ancho de la imagen procesada, en píxeles. |
| `height` | integer | Alto de la imagen procesada, en píxeles. |
| `format` | string | Siempre `webp`. |
| `hasAlpha` | boolean | Si la imagen tiene un canal transparente. |

<Note>
Para asociar la imagen, coloca la `url` devuelta en el recurso: por ejemplo
`imageUrl` de un producto, `thumbnailUrl` de un enlace o `logoUrl` de la tienda.
</Note>

## Crear un enlace de subida

```
POST /v1/upload-links
```

Crea un enlace de subida de corta duración para archivos que todavía no están en
línea. Le das la página a una persona ("ábrela y elige las fotos"), o envías los
archivos tú mismo a la dirección de subida directa. Es lo mismo que la herramienta
MCP `create_upload_link`. Requiere el alcance **write**.

### Petición

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{ "maxFiles": 4, "accept": "image" }' \
  https://api.linkz.ee/v1/upload-links
```

### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `maxFiles` | integer | No | Archivos que acepta el enlace, de 1 a 10. Por defecto 10. |
| `accept` | string | No | `image`, `video` o `any`. Por defecto `any`. |

### Respuesta

```json
{
  "error": false,
  "message": "Upload link created",
  "data": {
    "ticketId": "6740b1f2c3d4e5f6a7b8c9d0",
    "uploadPageUrl": "https://linkz.ee/u/lzu_AbC123...",
    "directUpload": {
      "method": "POST",
      "url": "https://api.linkz.ee/upload-tickets/files",
      "header": "Authorization: Bearer lzu_AbC123...",
      "field": "file"
    },
    "expiresAt": "2026-11-22T15:15:00.000Z",
    "maxFiles": 4,
    "accept": "image"
  }
}
```

El secreto `lzu_...` aparece solo en `uploadPageUrl` y en `directUpload.header`.
El enlace queda abierto durante **15 minutos**; puede haber hasta 20 enlaces
abiertos por tienda al mismo tiempo, y se pueden crear 60 por hora.

### Enviar un archivo al enlace

```
POST https://api.linkz.ee/upload-tickets/files
```

Envía un archivo por petición, como `multipart/form-data` con el campo `file` y el
header `Authorization: Bearer lzu_...` (nunca tu clave `lzk_`, y nunca el secreto
en la URL).

```bash
curl -X POST \
  -H "Authorization: Bearer lzu_AbC123..." \
  -F "file=@/path/to/after.jpg" \
  https://api.linkz.ee/upload-tickets/files
```

```json
{
  "error": false,
  "message": "File received",
  "data": {
    "uploadId": "6740b2a1c3d4e5f6a7b8c9d2",
    "kind": "image",
    "status": "done",
    "name": "after.jpg",
    "size": 512044,
    "w": 1600,
    "h": 1200
  }
}
```

| Regla | Valor |
| --- | --- |
| Fotos | JPEG, PNG, WebP, GIF o AVIF, hasta 8&nbsp;MB. HEIC se rechaza (en un iPhone, usa el formato de cámara **Más compatible** o elige desde la galería). |
| Videos | MP4 o MOV (H.264 o HEVC), hasta 40&nbsp;MB. |
| Por tienda | 26 archivos por minuto (fotos 20, videos 6), 60 videos por día, 2.560&nbsp;MB por día. |

Un **contenido** rechazado (archivo dañado, formato incorrecto) devuelve `200` con
`"status": "failed"` y un mensaje en `error`; el archivo no ocupa lugar. Una
**petición** rechazada devuelve el error estándar: `400` sin archivo o un tipo que
el enlace no acepta, `401` enlace inválido, `403` clave revocada o plan sin la API,
`409` enlace lleno, `410` enlace expirado, `413` archivo demasiado grande, `429`
límite de la tienda.

### Leer el estado del enlace

```
GET https://api.linkz.ee/upload-tickets/status
```

Con el mismo header `Authorization: Bearer lzu_...`. No consume el enlace.

```json
{
  "error": false,
  "message": "Upload link loaded",
  "data": {
    "status": "open",
    "expiresAt": "2026-11-22T15:15:00.000Z",
    "maxFiles": 4,
    "accept": "image",
    "storeName": "Studio Ana",
    "files": [
      { "uploadId": "6740b2a1c3d4e5f6a7b8c9d2", "kind": "image", "status": "done", "name": "after.jpg", "size": 512044 }
    ]
  }
}
```

`status` es `open`, `full` o `expired`; cada archivo está `uploading`, `done` o
`failed`.

<Note>
Un `uploadId` se usa en los campos de imagen y video de las herramientas MCP como
`{ "uploadId": "..." }`, durante 24 horas y hasta 5 veces. Los endpoints REST
reciben URLs: con una clave de API, sube imágenes con `POST /v1/uploads/image`.
Consulta [Enviar archivos](/es/integrations/mcp/sending-files).
</Note>

## Subidas de video (hero, fondo de pantalla y elementos de Reel)

```
POST /v1/uploads/video?kind=hero|wallpaper|media
```

Sube un video corto para tu encabezado **Hero**, el **fondo de pantalla** de tu
página o un elemento de video de una galería Reel, y lo optimiza en segundo plano.
Envíalo como `multipart/form-data` con un único campo `file` (MP4 o MOV, hasta
**40&nbsp;MB**). Requiere el alcance **write** y un plan **Premium**.

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -F "file=@/path/to/clip.mp4" \
  "https://api.linkz.ee/v1/uploads/video?kind=hero"
```

| Parámetro | Dónde | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `kind` | query | Sí | `hero` para el video del encabezado Hero, `wallpaper` para el fondo de la página, `media` para un elemento de video de una galería Reel. |
| `linkId` | query | Con `kind=media` | El bloque de galería (layout `reel`) al que pertenece el video, en tu propia tienda. |
| `slot` | query | Con `kind=media` | El slot del elemento, de `0` a `9`. |
| `file` | multipart | Sí | El video, MP4 o MOV, hasta **40&nbsp;MB**. |

### Elementos de video de una galería Reel

Con `kind=media`, el video se convierte en un elemento de un bloque de galería con
el layout `reel`. Un elemento **conserva su audio** (los visitantes pueden activar
el sonido) y los primeros 30 segundos. Después de subirlo, guarda el elemento con
`PATCH /v1/links/{id}`, enviando `{ "type": "video", "slot": 0, "jobId": "<job id>" }`
en `mediaItems`. El video se completa cuando el trabajo está listo.

<Note>
Un **video de tarjeta de enlace** (`mediaType: "video"` en un enlace normal) no se
puede enviar por URL ni por este endpoint. Va solo por un enlace de subida y la
herramienta MCP `set_link_media` con `{ "uploadId": "..." }`.
</Note>

### Respuesta

La petición devuelve `200` en cuanto se recibe el archivo, con un **trabajo** y una
pista `pollMs` de cada cuánto consultarlo.

```json
{
  "error": false,
  "message": "Video queued for processing",
  "data": {
    "id": "66f1c2a9e4b0c1d2f3a4b5c6",
    "kind": "hero",
    "status": "queued",
    "error": "",
    "errorCode": "",
    "tries": 0,
    "result": null,
    "createdAt": "2026-10-14T12:00:00.000Z",
    "finishedAt": null,
    "pollMs": 1500
  }
}
```

| Campo | Tipo | Descripción |
| --- | --- | --- |
| `id` | string | El id del trabajo. Úsalo para consultar el progreso. |
| `kind` | string | `hero`, `wallpaper` o `media`. |
| `status` | string | `queued`, `processing` y luego `ready`, `failed` o `superseded` (una subida más reciente del mismo tipo reemplazó a esta). |
| `error` | string \| null | Un mensaje legible cuando el trabajo falló. |
| `errorCode` | string \| null | Un código de error estable cuando el trabajo falló. |
| `tries` | integer | Cuántas veces se intentó la optimización. |
| `result` | object \| null | Se rellena cuando `status` es `ready`. |
| `createdAt` | string | Cuándo se creó el trabajo (ISO 8601). |
| `finishedAt` | string \| null | Cuándo terminó el trabajo, si ya terminó. |

Cuando el trabajo está `ready`, `result` contiene el video optimizado y ya está
**aplicado** a tu página, así que no hace falta ningún `PATCH` adicional:

| Campo | Tipo | Descripción |
| --- | --- | --- |
| `url` | string | La URL alojada del video optimizado. |
| `posterUrl` | string | La imagen de portada, generada a partir del primer fotograma. |
| `durationMs` | integer | Duración, en milisegundos. |
| `width` | integer | Ancho en píxeles. |
| `height` | integer | Alto en píxeles. |
| `bytes` | integer | Tamaño del archivo optimizado. |
| `trimmed` | boolean | `true` cuando el original duraba más de 30 segundos y se recortó. |

### Consultar y gestionar trabajos de video

```
GET    /v1/uploads/video/jobs/{id}
GET    /v1/uploads/video/latest?kind=hero
DELETE /v1/uploads/video/{kind}
```

- `GET /v1/uploads/video/jobs/{id}` (alcance **read**) devuelve el trabajo en su
  estado actual. Consúltalo cada `pollMs` milisegundos hasta que `status` sea
  `ready` o `failed`. También sigue trabajos iniciados desde el panel o por un
  agente.
- `GET /v1/uploads/video/latest?kind=hero` (o `kind=wallpaper`, alcance **read**)
  devuelve el trabajo más reciente de ese tipo, o `null`.
- `DELETE /v1/uploads/video/{kind}` (alcance **write**) elimina de tu página el
  video publicado de `hero` o `wallpaper`.

### Perfil de salida

Los videos hero y de fondo de pantalla se codifican con el mismo perfil, para que
arranquen al instante en el teléfono:

| Ajuste | Valor |
| --- | --- |
| Resolución | **720p** en el lado corto, nunca se escala hacia arriba |
| Fotogramas por segundo | 24 fps |
| Códec | H.264 (MP4) |
| Duración | Los **primeros 30 segundos** |
| Audio | Eliminado: estos videos siempre son silenciosos |
| Tamaño | Como máximo **unos 6&nbsp;MB** |

<Note>
Los videos de más de 30 segundos nunca se rechazan por su duración: se recortan, y
el resultado indica `trimmed: true`. Una subida solo se rechaza cuando el archivo
supera los 40&nbsp;MB o no es un video válido. La cámara lenta con muchos cuadros
por segundo se recorta un poco antes: un clip de 240 fps conserva sus primeros 15
segundos.
</Note>

## Generar un video hero con las fotos de los productos

```
POST /v1/uploads/video/montage
```

Crea un montaje corto con las fotos de tus productos (zooms y desplazamientos
lentos, fundidos, unos 14 segundos) y lo pone en cola como video **hero**, con el
mismo trabajo y la misma consulta que una subida. Usa los productos más recientes
que tienen foto, o los que envíes en `productIds` (hasta 6, en orden). Requiere el
alcance **write**, un plan **Premium** y al menos 3 productos con foto alojada en
Linkzee. Es lo mismo que la herramienta MCP `set_hero_video` con `fromProducts`.

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"productIds":["665f1a2b9c4e1f0012a3b4c5","665f1a2b9c4e1f0012a3b4c6","665f1a2b9c4e1f0012a3b4c7"]}' \
  https://api.linkz.ee/v1/uploads/video/montage
```

| Parámetro | Dónde | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `productIds` | body | No | Hasta 6 ids de producto, en el orden en que deben aparecer. Si se omite: los productos más recientes con foto. |

Devuelve el trabajo de procesamiento, igual que la subida de video. Errores: `400`
cuando menos de 3 productos tienen foto, `403` con `code: "PLAN_REQUIRED"` en un
plan gratuito.
