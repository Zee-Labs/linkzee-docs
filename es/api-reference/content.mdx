Los endpoints de contenido exponen todo lo que un visitante ve en la zona de
enlaces de una página: enlaces sueltos, colecciones (grupos de enlaces) e ítems
de Concierge, además de un bloque `meta` que resume la vitrina de productos
(contadores, chips de categoría, productos destacados y la primera página del
catálogo).

Todas las solicitudes van a `https://api.linkz.ee` y deben incluir tu clave de API:

```
Authorization: Bearer lzk_your_key
```

<Note>
Los productos no forman parte del árbol reordenable. La vitrina se ordena
automáticamente (los más nuevos primero), así que reordenar solo afecta a los
enlaces, las colecciones y los ítems de Concierge. Las entradas de producto
enviadas al endpoint de reordenamiento se ignoran.
</Note>

## Obtener el árbol de contenido

```
GET /v1/content
```

Devuelve el árbol de contenido público de tu página, más un resumen `meta` de la
vitrina de productos.

### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/content
```

### Respuesta

El objeto `data` tiene dos partes: `meta` (resumen de la vitrina) y `root` (la
lista ordenada de entradas de contenido). Cada entrada de `root` es de tipo

## Reordenar el contenido

```
PUT /v1/content/order
```

Establece el orden de toda la zona de enlaces en una sola llamada. Envía el árbol
completo en el orden que quieras: la posición de cada entrada en el arreglo se
convierte en su nuevo orden. Requiere una clave con el alcance **write**.

### Solicitud

```bash
curl -X PUT \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "root": [
      { "type": "link", "id": "507f1f77bcf86cd799439011" },
      {
        "type": "collection",
        "id": "507f1f77bcf86cd799439020",
        "children": [
          { "type": "link", "id": "507f1f77bcf86cd799439012" },
          { "type": "concierge", "id": "507f1f77bcf86cd799439030" }
        ]
      }
    ]
  }' \
  https://api.linkz.ee/v1/content/order
```

### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `root` | array | Sí | Entradas de nivel superior en su nuevo orden. Puede estar vacío. |
| `root[].type` | string | Sí | Uno de `link`, `collection`, `concierge` o `product`. |
| `root[].id` | string | Sí | El ID de la entrada. |
| `root[].children` | array | No | Ítems hijos, en orden. Solo se usa cuando `type` es `collection`. |
| `root[].children[].type` | string | Sí | Uno de `link`, `concierge` o `product`. |
| `root[].children[].id` | string | Sí | El ID del ítem hijo. |

<Warning>
Las entradas de producto (en la raíz o dentro de una colección) se aceptan pero
se ignoran: la vitrina se ordena a sí misma. Envía solo entradas `link`,
`collection` y `concierge` para cambiar lo que realmente se reordena. Los IDs
desconocidos se omiten silenciosamente.
</Warning>

### Respuesta

```json
{
  "error": false,
  "message": "Conteúdo reordenado com sucesso",
  "data": { "ok": true }
}
```
