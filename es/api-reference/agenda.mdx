Los endpoints de Agenda te permiten gestionar tu calendario de reservas de forma
programática: define los **servicios** que la gente puede reservar, tu **equipo**,
los **bloqueos** de los días en que no estás disponible, consulta la
**disponibilidad** real para crear y gestionar **citas**, modera las **valoraciones**
que recibes y gestiona la **lista de espera**.

Todas las rutas están bajo `https://api.linkz.ee/v1/agenda`. Cada solicitud
necesita la cabecera `Authorization: Bearer lzk_your_key`, y las operaciones de
escritura (POST/PATCH/DELETE) requieren una clave con el permiso **write**.

<Note>
Las lecturas (`GET`) funcionan con cualquier clave válida. Crear, actualizar,
cambiar de estado, reprogramar o eliminar algo requiere el permiso **write**.
</Note>

## Servicios

Un servicio (oferta) es algo que la gente puede reservar: un corte de pelo, una
consultoría, una llamada. Cada servicio tiene una duración y, opcionalmente, un
precio.

### Listar servicios

```
GET /v1/agenda/offerings
```

Devuelve todos los servicios de tu agenda, en orden de visualización.

#### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/offerings
```

#### Respuesta

```json
{
  "error": false,
  "message": "Services retrieved successfully",
  "data": [
    {
      "_id": "665f0a1b2c3d4e5f60718293",
      "name": "Strategy call",
      "durationMin": 45,
      "price": 150,
      "description": "A focused 45-minute planning session.",
      "color": "#2f80ed",
      "bufferAfterMin": 15,
      "meetEnabled": true,
      "order": 0,
      "isActive": true
    }
  ]
}
```

### Crear un servicio

```
POST /v1/agenda/offerings
```

Agrega un nuevo servicio reservable.

#### Solicitud

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"name":"Strategy call","durationMin":45,"price":150,"meetEnabled":true}' \
  https://api.linkz.ee/v1/agenda/offerings
```

#### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `name` | string | Sí | Nombre del servicio (máx. 80 caracteres). |
| `durationMin` | integer | Sí | Duración en minutos (5–720). |
| `price` | number | No | Precio en R$. Omítelo o envía `null` para que sea gratis. |
| `description` | string | No | Descripción corta (máx. 300 caracteres). |
| `color` | string | No | Color hexadecimal para el calendario, p. ej. `#2f80ed`. |
| `bufferAfterMin` | integer | No | Margen en minutos después de cada reserva (0–240). |
| `meetEnabled` | boolean | No | Crea un enlace de Google Meet para cada reserva. |
| `isActive` | boolean | No | Si el servicio es reservable. Por defecto es `true`. |
| `kind` | string | No | `single` (por defecto) o `combo`. Un combo agrupa varios servicios simples en un solo paquete reservable. |
| `comboItemIds` | array of string | No | Obligatorio cuando `kind` es `combo`: los IDs de 2–6 servicios simples incluidos en el combo. |
| `chargeMode` | string | No | Cobro online: `none` (por defecto, pago presencial), `deposit` (importe parcial por adelantado) o `full` (precio completo por adelantado — requiere un `price` mayor que 0). |
| `chargeDepositType` | string | No | Cómo se calcula la seña cuando `chargeMode` es `deposit`: `percent` o `fixed`. |
| `chargeDepositValue` | number | No | El importe de la seña: un porcentaje de 1 a 100 cuando `chargeDepositType` es `percent`, o un importe fijo en la moneda de tu tienda cuando es `fixed`. |

#### Respuesta

```json
{
  "error": false,
  "message": "Service created successfully",
  "data": {
    "_id": "665f0a1b2c3d4e5f60718293",
    "name": "Strategy call",
    "durationMin": 45,
    "price": 150,
    "bufferAfterMin": 0,
    "meetEnabled": true,
    "order": 0,
    "isActive": true
  }
}
```

```
PATCH /v1/agenda/offerings/{id}
```

#### Solicitud

```bash

  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"name":"Strategy call","durationMin":60,"price":180}' \
  https://api.linkz.ee/v1/agenda/offerings/665f0a1b2c3d4e5f60718293
```

#### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `id` | string | Sí | El ID del servicio (en la ruta). |

El cuerpo acepta los mismos campos que [Crear un servicio](#create-a-service).

#### Respuesta

```json
{
  "error": false,
  "message": "Service updated successfully",
  "data": {
    "_id": "665f0a1b2c3d4e5f60718293",
    "name": "Strategy call",
    "durationMin": 60,

    "isActive": true
  }

```

```

```

#### Solicitud

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/offerings/665f0a1b2c3d4e5f60718293
```

#### Respuesta

```json
{
  "error": false,
  "message": "Service deleted successfully",
  "data": { "id": "665f0a1b2c3d4e5f60718293" }
}
```

### Crear un profesional

```
POST /v1/agenda/staff
```

#### Solicitud

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"name":"Ana Souza","title":"Senior consultant","offeringIds":["665f0a1b2c3d4e5f60718293"]}' \
  https://api.linkz.ee/v1/agenda/staff
```

#### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `name` | string | Sí | Nombre del profesional (máx. 80 caracteres). |
| `title` | string | No | Función o cargo (máx. 80 caracteres). |
| `avatarUrl` | string | No | URL de la foto (máx. 500 caracteres). |
| `hours` | array | No | Horario de trabajo semanal (ver abajo). Envía `null` para heredar el horario de tu negocio. |
| `offeringIds` | array of string | No | Servicios que presta esta persona. `null` significa todos los servicios. |
| `isActive` | boolean | No | Si la persona es reservable. Por defecto es `true`. |

Cada entrada de `hours` describe un día de la semana:

| Campo | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `day` | integer | Sí | Día de la semana, `0` = domingo hasta `6` = sábado. |
| `closed` | boolean | No | Ponlo en `true` para marcar el día como libre. |
| `ranges` | array | No | Franjas de trabajo, cada una con `startMin` y `endMin` (minutos desde la medianoche, 0–1440). |

#### Respuesta

```json
{
  "error": false,
  "message": "ok",
  "data": {
    "_id": "665f0c9a8b7d6e5f40312a11",
    "name": "Ana Souza",
    "title": "Senior consultant",
    "hours": null,
    "offeringIds": ["665f0a1b2c3d4e5f60718293"],
    "isActive": true

}
```

## Bloqueos

Un bloqueo es un intervalo de tiempo en el que tú (o un profesional) no están
disponibles: un feriado, unas vacaciones o un día libre. Las reservas no pueden
caer dentro de un bloqueo.

<Note>
Los bloqueos no tienen endpoint de actualización. Para cambiar uno, elimínalo y crea uno nuevo.
</Note>

### Listar bloqueos

```
GET /v1/agenda/blocks
```

#### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/blocks
```

#### Respuesta

```json
{
  "error": false,
  "message": "ok",
  "data": [
    {
      "_id": "665f0e5511aa22bb33cc44dd",
      "staffId": null,
      "startDate": "2026-12-24",
      "endDate": "2026-12-26",
      "allDay": true,
      "reason": "Holidays"
    }
  ]
}
```

### Crear un bloqueo

```

```

#### Solicitud

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"startDate":"2026-12-24","endDate":"2026-12-26","allDay":true,"reason":"Holidays"}' \
  https://api.linkz.ee/v1/agenda/blocks
```

#### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `startDate` | string | Sí | Primer día bloqueado, `YYYY-MM-DD`. |
| `endDate` | string | Sí | Último día bloqueado, `YYYY-MM-DD`. |

| `endMin` | integer | No | Minuto de fin desde la medianoche para un bloqueo de día parcial (0–1440). |
| `reason` | string | No | Etiqueta corta (máx. 120 caracteres). |

#### Respuesta

## Disponibilidad

```
GET /v1/agenda/availability
```

Devuelve los días abiertos y las franjas horarias reales de un servicio en un
rango de fechas: el mismo motor que impulsa tu página pública de reservas, así que
ya tiene en cuenta los horarios de trabajo, las citas existentes y los bloqueos.

#### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  "https://api.linkz.ee/v1/agenda/availability?offeringId=665f0a1b2c3d4e5f60718293&from=2026-07-21&to=2026-07-25&detail=slots"
```

#### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `offeringId` | string | Sí | El servicio a consultar. |
| `from` | string | Sí | Fecha de inicio, `YYYY-MM-DD` (en la zona horaria de tu calendario). |
| `to` | string | Sí | Fecha de fin, `YYYY-MM-DD`. |
| `staffId` | string | No | Limita la disponibilidad a un solo profesional (modo equipo). |
| `extraOfferingIds` | string | No | IDs separados por comas de hasta 4 servicios extra que se reservan junto con el principal (un carrito). La disponibilidad tiene entonces en cuenta la duración combinada. |
| `detail` | string | No | `days` (por defecto) devuelve solo el estado por día; `slots` también devuelve las horas de inicio reservables. |

#### Respuesta

```json
{
  "error": false,
  "message": "Availability retrieved successfully",
  "data": {
    "days": [
      { "date": "2026-07-21", "state": "free", "density": "low" },
      { "date": "2026-07-22", "state": "full", "density": "high" },
      { "date": "2026-07-23", "state": "closed", "density": "none" }
    ],
    "slots": [
      { "startAt": "2026-07-21T12:00:00.000Z" },
      { "startAt": "2026-07-21T12:45:00.000Z" }
    ],
    "charge": {
      "mode": "deposit",
      "amountDueCents": 5000,
      "totalCents": 15000,
      "currency": "brl"
    },
    "stepMin": 15,
    "timezone": "America/Sao_Paulo"
  }
}
```

El `state` de cada día es `free` (tiene franjas libres), `full` (totalmente
reservado) o `closed` (no es día laborable); `density` (`none`, `low`, `medium`,
`high`) te indica cuán ocupado está ya el día. Las horas se devuelven en UTC (`Z`).

Cuando el servicio tiene el cobro online configurado, `charge` describe lo que el
visitante paga al reservar: `mode` (`none`, `deposit` o `full`),
`amountDueCents` (el importe a pagar en el momento de la reserva, en centavos),
`totalCents` (el precio completo del servicio, en centavos) y `currency`. Sin
cobro configurado, `mode` es `none` y los importes son `0`.

### Crear una cita

```
POST /v1/agenda/appointments
```

Reserva una cita manualmente, con las mismas reglas que la reserva pública: la
franja debe estar realmente disponible o la solicitud se rechaza.

#### Solicitud

```bash
curl -X POST \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"offeringId":"665f0a1b2c3d4e5f60718293","startAt":"2026-07-21T13:00:00.000Z","name":"João Lima","phone":"+5511999998888"}' \
  https://api.linkz.ee/v1/agenda/appointments
```

#### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `offeringId` | string | Sí | El servicio que se reserva. |
| `startAt` | string | Sí | Hora de inicio en ISO 8601, p. ej. `2026-07-21T13:00:00.000Z`. |
| `name` | string | Sí | Nombre del visitante (máx. 120 caracteres). |
| `phone` | string | Sí | Teléfono del visitante (máx. 30 caracteres). |
| `email` | string | No | Correo del visitante (máx. 160 caracteres). |
| `notes` | string | No | Notas internas (máx. 500 caracteres). |
| `leadId` | string | No | Vincula la cita a un cliente existente (lead) en lugar de crear un registro duplicado. |
| `staffId` | string | No | El profesional que atenderá la cita (modo equipo). Se ignora en modo solo/pool. |

#### Respuesta

```json
{
  "error": false,
  "message": "Appointment created successfully",
  "data": {
    "id": "665f1122aa33bb44cc55dd66",
    "manageToken": "8f3a1c22b90e4d1f",
    "status": "confirmed",
    "startAt": "2026-07-21T13:00:00.000Z",
    "endAt": "2026-07-21T13:45:00.000Z",
    "offeringName": "Strategy call",
    "timezone": "America/Sao_Paulo"
  }
}
```

## Google Calendar

### Desconectar Google Calendar

```
DELETE /v1/agenda/google
```

#### Solicitud

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/google
```

#### Respuesta

```json
{ "error": false, "message": "ok", "data": { "connected": false } }
```

<Warning>
Conectar un Google Calendar se hace a través de un flujo de inicio de sesión en el
panel de Linkzee y no se puede hacer desde la API. La API solo puede leer el estado
y desconectar.
</Warning>

## Valoraciones

Tras una cita completada, los visitantes pueden dejar una valoración. Las valoraciones
**nunca se editan ni se eliminan**: la única acción de moderación es ocultar una
de tu página pública (sigue siendo visible para ti y puedes volver a mostrarla
en cualquier momento).

### Listar valoraciones

```
GET /v1/agenda/reviews
```

Devuelve todas las valoraciones que ha recibido tu agenda, **incluidas las ocultas**.

#### Solicitud

```bash
curl -X GET \
```

```json
      "hidden": false,
      "featured": false,
      "followedUpAt": null,
      "createdAt": "2026-07-22T18:30:00.000Z"
    }
  ]
}
```

#### Campos

| Campo | Descripción |
| --- | --- |
| `rating` | De 1 a 5 estrellas. |
| `comment` | Lo que escribió el cliente. Nunca editable. |
| `visitorName` / `visitorPhone` / `visitorEmail` | El cliente que reservó, para que puedas darle seguimiento. Los mismos datos de la cita. |
| `offeringId` / `offeringName` | El servicio que se valoró. |
| `staffId` | El profesional que atendió la cita, cuando tienes equipo. |
| `appointmentAt` | Cuándo ocurrió la cita (ISO 8601, UTC). |
| `hidden` | `true` significa que no cuenta en tu promedio público. |
| `featured` | `true` significa que aparece primero en el bloque de valoraciones de tu página. |
| `followedUpAt` | Cuándo marcaste la valoración como atendida, o `null`. |

<Note>
  `visitorPhone` y `visitorEmail` son los datos de contacto de tu cliente —
  los mismos que devuelve el endpoint de citas. Trata la respuesta como dato
  personal y mantén tu clave de API privada.
</Note>

### Ocultar o mostrar una valoración

```
PATCH /v1/agenda/reviews/{id}
```

Alterna la visibilidad de una valoración en tu página pública. Requiere el permiso
**write**.

Las valoraciones nunca se editan ni se eliminan a través de la API — ocultar es la
única acción de moderación disponible aquí. Destacar una valoración y marcarla
como atendida son acciones de tu panel.

#### Solicitud

```bash
curl -X PATCH \
  -H "Authorization: Bearer lzk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"hidden":true}' \
  https://api.linkz.ee/v1/agenda/reviews/665f33aa11bb22cc33dd44ee
```

#### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
| --- | --- | --- | --- |
| `id` | string | Sí | El ID de la valoración (en la ruta). |
| `hidden` | boolean | Sí | `true` oculta la valoración de la página pública; `false` la muestra de nuevo. |

#### Respuesta

```json
{
  "error": false,
  "message": "Review updated successfully",
  "data": { "id": "665f33aa11bb22cc33dd44ee", "hidden": true }
}
```

<Note>
No hay endpoint para editar o eliminar una valoración: ocultar es la única acción de
moderación, para que las valoraciones sigan siendo confiables.
</Note>

## Lista de espera

Cuando un período no tiene franjas libres, los visitantes pueden unirse a la
lista de espera. En cuanto se abre una franja compatible, el sistema se la ofrece
automáticamente a la primera entrada compatible.

### Listar la lista de espera

```
GET /v1/agenda/waitlist
```

Devuelve la cola actual de visitantes que esperan una franja.

#### Solicitud

```bash
curl -X GET \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/waitlist
```

#### Respuesta

```json
{
  "error": false,
  "message": "Waitlist retrieved successfully",
  "data": [
    {
      "id": "665f44bb55cc66dd77ee88ff",
      "position": 1,
      "name": "Maria Alves",
      "phone": "+5511988887777",
      "dateFrom": "2026-07-21",
      "dateTo": "2026-07-25",
      "periods": ["morning", "afternoon"],
      "status": "waiting",
      "offeringId": "665f0a1b2c3d4e5f60718293",
      "createdAt": "2026-07-19T10:12:00.000Z"
    }
  ]
}
```

Las entradas se ordenan por llegada (`position` empieza en 1). `periods` lista
las partes del día preferidas por el visitante (`morning`, `afternoon`,
`evening`); `status` es `waiting` u `offered` (se le ofreció una franja y está
pendiente de respuesta).

### Eliminar una entrada de la lista de espera

```
DELETE /v1/agenda/waitlist/{id}
```

Elimina una entrada de la cola. Requiere el permiso **write**.

#### Solicitud

```bash
curl -X DELETE \
  -H "Authorization: Bearer lzk_your_key" \
  https://api.linkz.ee/v1/agenda/waitlist/665f44bb55cc66dd77ee88ff
```

#### Respuesta

```json
{ "error": false, "message": "Waitlist entry removed", "data": { "id": "665f44bb55cc66dd77ee88ff" } }
```
