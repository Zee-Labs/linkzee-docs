Una vez que conectas un agente de IA a través de MCP, puede crear y gestionar toda
tu bio por ti, con solo pedírselo en lenguaje natural. Esta página lista las
**70 herramientas**, lo que hace cada una y el acceso que necesita, para que sepas
qué pedir y qué permisos conceder.

## Qué herramientas ve un agente

Lo que ve el agente depende de cómo se conecta.

**Con una clave de API** (`lzk_`), deciden los alcances de la clave:

| Alcances de la clave | Herramientas que ve el agente |
| --- | --- |
| `read` | Las 26 herramientas de lectura (página, enlaces, productos, agenda, leads). |
| `write` | Las 26 herramientas de lectura más las 43 herramientas de escritura (69 en total). En MCP, `write` implica `read`: un agente que escribe siempre lee el estado primero. |
| `finance` solo | Solo `get_earnings`. Una clave solo finance no lee nada más. |
| `read` o `write`, más `finance` | Lo anterior más `get_earnings` (hasta 70). |

**Con el conector de Claude** (OAuth), eliges los grupos en la pantalla de consentimiento:

| Grupo | Obligatorio | Herramientas |
| --- | --- | --- |
| `content` | Sí | Página, enlaces, productos, categorías, colecciones, diseño, medios, tarjetas especiales y onboarding (44 herramientas, de lectura y escritura). |
| `agenda` | No | Agenda, servicios, equipo, bloqueos, citas, reseñas y paquetes (19 herramientas). |
| `leads` | No | Leads (3 herramientas). |
| `finance` | No | `get_earnings`. |

<Warning>
  Tres herramientas son **solo con clave** y nunca aparecen por OAuth, sean cuales
  sean los grupos: `configure_tracking` (los píxeles y GTM van en un script de tu
  página), `configure_tips` (la clave PIX es un destino de dinero) y
  `disconnect_agenda_google` (cambia tu cuenta de Google). Usa una clave de API con
  el alcance **write** para ellas.
</Warning>

## Cómo responden las herramientas

- Cada respuesta tiene una frase corta y, cuando esa frase no es JSON, un segundo
  bloque de texto con el mismo resultado en JSON compacto. Los clientes que leen
  `structuredContent` reciben el mismo objeto ahí.
- Las herramientas de escritura pueden devolver `warnings` (guardado, pero con una
  salvedad), `pending` (trabajos de video para seguir con `get_media_job`) y
  `published` con un `reason` cuando el resultado todavía no está en la página
  pública: `missing_photos`, `pending_video`, `plan_required` o `consent_required`.
- Cada campo de imagen acepta una URL pública de imagen (descargada, verificada y
  alojada en la CDN de Linkzee) **o** `{ "uploadId": "..." }` de un enlace de
  subida (consulta [Enviar archivos](/es/integrations/mcp/sending-files)). Las
  herramientas de medios nunca publican un archivo que no pudieron copiar: en su
  lugar, la llamada falla. Las imágenes de productos mantienen el comportamiento
  anterior: una foto que no se puede obtener se omite con una advertencia y el
  producto se guarda.
- Las herramientas de creación que aceptan `idempotencyKey` devuelven el elemento ya
  creado cuando repites la misma clave con el mismo payload, en lugar de un
  duplicado. Consulta [Límites de tasa](/es/api-reference/rate-limits).

<Note>
  Todo lo que un agente cambia se guarda automáticamente y actualiza tu página en
  vivo al instante, exactamente como si hubieras hecho el cambio en el editor.
  Mientras haya un onboarding guiado abierto, la primera escritura directa en la
  página lo cierra, y la respuesta lo indica.
</Note>

## Página y perfil

| Herramienta | Acceso | Qué hace |
| --- | --- | --- |
| `get_store` | read | Vista del dueño de la tienda: perfil, diseño, encabezado, redes, ajustes de la vitrina y del mapa, `pageHidden` y (según el acceso) ajustes de la agenda, un resumen de PIX y el host del webhook de leads. Nunca devuelve secretos. |
| `get_storefront` | read | Lo que ven los visitantes: perfil, la zona de enlaces y el resumen de la vitrina. También funciona con la página oculta, y entonces devuelve `pageHidden: true`. |
| `update_profile` | write | Nombre, bio, firma de la bio, título SEO y descripción SEO. |
| `update_socials` | write | Usuarios de redes sociales, WhatsApp (dígitos con código de país), `socialsPosition` (`top` o `bottom`) y `socialOrder`. Un string vacío elimina una red. El dueño recibe un email cuando cambia el número de WhatsApp. |
| `update_page` | write | `isActive` (`false` oculta toda la página pública), `publicPreferences` (idioma de la página y alternativa de traducción, combinadas con lo guardado), `timezone` (nombre IANA, validado) y `location` (país, estado, ciudad; define el calendario de feriados). El slug no se puede cambiar. |
| `update_map` | write | Tarjeta de mapa: `mapAddress` (un string vacío la elimina), `mapTheme` y `mapLayout` (`map` o `card`). |
| `configure_bio_cards` | write | Activa o desactiva secciones de la página (`vitrineEnabled`, `servicesEnabled`, `packagesEnabled`, `instagramEnabled`, `agendaEnabled`, `agendaTopCard`) y configura la tarjeta de reseña de Google, el bloque de reseñas y las tarjetas de fotos de redes. |
| `configure_vitrine` | write | Cuadrícula de la vitrina: `gridDensity`, `vitrineLayout` (`grid`, `masonry`, `carousel`) y `vitrinePhotoFit`. |
| `configure_tips` | solo con clave | Tarjeta de propinas PIX. Devuelve `pixKeyPreview` (últimos 4 caracteres), nunca la clave. El dueño recibe un email cuando cambia la clave. |
| `configure_tracking` | solo con clave | Píxeles de Meta, TikTok y GA4, el token de la Conversion API de Meta, GTM y los parámetros UTM predeterminados. |

## Diseño y video

| Herramienta | Acceso | Qué hace |
| --- | --- | --- |
| `list_themes` | read | Los 23 temas predefinidos (8 son de pago). |
| `update_design` | write | Tema, colores, fondo de pantalla, botones, fuente, tarjeta, textura, movimiento, layout del encabezado e imágenes del encabezado. Consulta "Herencia del tema" más abajo. Los valores de pago responden `PLAN_REQUIRED` en un plan gratuito. |
| `set_appearance` | write | **Obsoleta.** Aplica un tema predefinido; usa `update_design` con `themeId`. |
| `set_hero_video` | write | Video hero a partir de una URL pública de MP4 o MOV, un `uploadId` o `fromProducts` (un video generado a partir de 3 a 6 fotos de productos). Devuelve un trabajo. Premium. |
| `set_background_video` | write | Video de fondo de la página a partir de una URL o un `uploadId`. Devuelve un trabajo. Premium. |
| `remove_hero_video` | write | Elimina el video hero. |
| `remove_background_video` | write | Elimina el video de fondo. |
| `get_media_job` | read | Estado de cualquier trabajo de video (hero, fondo, elemento de bloque, tarjeta de enlace): `queued`, `processing`, `ready` o `failed`. |

### Herencia del tema

`update_design` funciona como el editor. `themeId` aplica un preset y lo empieza
limpio: se restablecen las personalizaciones y el nivel de movimiento guardados
antes. Cualquier otro campo de diseño en una tienda con preset personaliza **solo su
sección** (colores, fondo de pantalla, botones, texto, degradado, tarjeta, textura,
movimiento) y esa sección parte de la paleta del tema; el resto sigue el tema. Los
colores iguales a la paleta del preset no cuentan como colores personalizados. Envía
`overrides` solo cuando quieras listar tú mismo las secciones personalizadas.

## Enlaces, bloques y colecciones

| Herramienta | Acceso | Qué hace |
| --- | --- | --- |
| `list_links` | read | Cada enlace y bloque de medios, incluidos los ocultos, programados y sin terminar. Cada elemento indica `published` y, cuando es `false`, un `reason`: `hidden`, `scheduled`, `missing_destination`, `missing_photos`, `pending_video` o `failed_video`. Los elementos de medios traen `slot`, `type` y `status` (`ready`, `pending` o `failed`). |
| `list_collections` | read | Grupos de enlaces: id, nombre, emoji, descripción, `isActive`, orden. |
| `get_content_tree` | read | El árbol de la zona de enlaces en el orden de la página, en el formato exacto que acepta `reorder_content`, con las tarjetas especiales como `{ "type": "section", "key": "..." }`. |
| `create_link` | write | Agrega un enlace o un bloque de medios. Acepta `thumbnail`, `isActive`, `isFeatured`, `highlightFx`, `emphasis`, una ventana de programación (ISO 8601 con offset) y los campos del bloque. `idempotencyKey` opcional. |
| `update_link` | write | Cambia solo los campos enviados. `mediaItems` es la lista completa; omitir un slot de video requiere `confirmRemoveVideos: true`. |
| `delete_link` | write | Elimina un enlace (`confirm: true`). |
| `set_block_media` | write | Define la lista completa de elementos de un bloque Antes y Después o Galería: fotos, videos (solo galería Reel), etiquetas y botones. Los archivos nuevos requieren `mediaConsent: true`. |
| `set_link_media` | write | Portada de una tarjeta de enlace: `image`, `embed` (YouTube, Vimeo, TikTok, Spotify o Panda), `video` (solo un `uploadId`, más un póster) o `none`. |
| `manage_collection` | write | Crea, actualiza o elimina un grupo de enlaces (`description`, `isActive`). |
| `reorder_content` | write | Reordena enlaces, colecciones, asistentes de IA y tarjetas especiales. Los elementos omitidos conservan su lugar. |

## Productos y categorías

| Herramienta | Acceso | Qué hace |
| --- | --- | --- |
| `list_products` | read | Productos de la vitrina en el orden en que los ven los visitantes (los más nuevos primero, o tu orden manual). Acepta `q` y `limit`. |
| `get_product` | read | Todos los campos editables de un producto. |
| `list_categories` | read | Categorías (chips de la vitrina): id, nombre, emoji, descripción, `isActive`, orden. |
| `create_product` | write | Crea un producto. Acepta `installments`, `highlightFx`, `showCountdown`, `offerEndsAt`, `offerDurationMinutes`, `isActive`, `externalId` y `barcode`. `idempotencyKey` opcional. |
| `create_products_bulk` | write | Hasta 20 productos a la vez, cada uno con su propio `idempotencyKey` opcional. |
| `update_product` | write | Cambia solo los campos enviados. `price: null` elimina el precio. |
| `delete_product` | write | Elimina un producto (`confirm: true`). |
| `manage_category` | write | Crea, actualiza, elimina o reordena categorías (`description`, `isActive`). |

<Note>
  Un producto solo aparece en la página pública cuando tiene un enlace de destino
  (`sourceUrl` o `externalLink`). El orden de los productos se define en el panel o
  con `PUT /v1/products/order` (consulta [Productos](/es/api-reference/products)); no
  hay herramienta MCP para eso.
</Note>

## Archivos e importación

| Herramienta | Acceso | Qué hace |
| --- | --- | --- |
| `create_upload_link` | write | Crea un enlace de subida para fotos y videos que no tienes como URLs públicas. Consulta [Enviar archivos](/es/integrations/mcp/sending-files). |
| `get_upload` | read | Estado de un enlace de subida (`open`, `full`, `expired`) y sus archivos con su `uploadId`. |
| `import_from_url` | read | Solo lee y no guarda nada: `prefill_link` (título e imagen de cualquier página) o `preview_bio` (lo que `import_bio` traería de una página de Linktree o Beacons). |
| `import_bio` | write | Importa una página de Linktree o Beacons a la tienda. Requiere `idempotencyKey`; 3 por hora. Solo después de que la persona esté de acuerdo. |

| Herramienta | Acceso | Qué hace |
| --- | --- | --- |
| `list_ai_assistants` | read | Tarjetas de asistente de IA: id, título, avatar, apertura, botones de inicio, `isActive`. |
| `manage_ai_assistant` | write | Crea, actualiza o elimina un asistente (`personality`, `instructions`, `collectionId`, `isActive`, captura de leads) o cambia los ajustes globales (`op: "settings"`). |
| `get_onboarding_brief` | read | Durante el onboarding guiado: las respuestas ya dadas y el guion de la entrevista en el idioma del dueño. |
| `propose_onboarding_bio` | write | Durante el onboarding guiado: guarda la propuesta en el borrador. La persona la revisa y la publica en Linkzee. |
| `get_bio_playbook` | read | El estándar de calidad de Linkzee para una bio, el plan actual y las guías de campos (`toolGuide`: design, links, agenda). |
| `get_analytics_summary` | read | Métricas agregadas de la vitrina. |

## Agenda

Todas las herramientas de abajo están en el grupo OAuth `agenda`, excepto la última.

| Herramienta | Acceso | Qué hace |
| --- | --- | --- |
| `list_offerings` | read | Servicios reservables. |
| `list_staff` | read | Miembros del equipo (sin emails). |
| `list_blocks` | read | Bloqueos de tiempo (feriados, vacaciones). |
| `list_appointments` | read | Citas en un rango de fechas. El texto de los visitantes es dato no confiable. |
| `get_agenda_availability` | read | Horarios libres reales de un servicio, por miembro del equipo o para un carrito de servicios extra. |
| `get_agenda_google` | read | Si Google Calendar está disponible y conectado. |
| `list_reviews` | read | Reseñas, incluidas las ocultas. |
| `list_waitlist` | read | Visitantes que esperan una franja. |
| `configure_agenda` | write | Ajustes de la agenda, recordatorios, horario de atención y el servicio que se muestra en la tarjeta de reserva. |
| `set_opening_hours` | write | El distintivo "abierto ahora": origen `agenda` o `custom`, y fechas cerradas. |
| `manage_offering` | write | Crea, actualiza o elimina un servicio, incluidos los combos y el cobro online. |
| `manage_staff` | write | Crea, actualiza o elimina un miembro del equipo. `update` reemplaza el registro. |
| `manage_block` | write | Crea o elimina un bloqueo de tiempo. |
| `create_appointment` | write | Reserva una cita. `idempotencyKey` opcional. |
| `transition_appointment` | write | Cambia el estado de una cita. |
| `reschedule_appointment` | write | Mueve una cita a un horario libre exacto. |
| `update_review` | write | Oculta o muestra (`hidden`) y destaca (`featured`) una reseña. Solo cambian los campos enviados. |
| `set_review_hidden` | write | **Obsoleta.** Oculta o muestra una reseña; usa `update_review`. |
| `manage_package` | write | Paquetes de sesiones (`kind: "package"`) y planes de suscripción (`kind: "subscription_plan"`): `list`, `create` (requiere `idempotencyKey`), `update` y `delete` (`confirm: true`). |
| `disconnect_agenda_google` | solo con clave | Desconecta Google Calendar (`confirm: true`). |

| Herramienta | Acceso | Qué hace |
| --- | --- | --- |
| `list_leads` | read | Leads capturados por el asistente de IA. |
| `search_leads` | read | Busca un cliente por nombre, teléfono, email o Instagram. |

## Obsoletas

Estas todavía funcionan durante una versión más. Migra al reemplazo.

| Obsoleta | Usa en su lugar |
| --- | --- |
| `set_appearance` | `update_design` con `themeId` (mismo efecto). |
| `set_review_hidden` | `update_review` con `hidden`. |
| `manage_category` con `op: "list"` | `list_categories`. |
| `manage_collection` con `op: "list"` | `list_collections`. |
| `instagram`, `whatsapp`, `tiktok` y `youtube` en `update_profile` | `update_socials`. |
| `vitrineEnabled` en `configure_vitrine` | `configure_bio_cards` con `vitrineEnabled`. |
| `enabled` y `showTopCard` en `configure_agenda` | `configure_bio_cards` con `agendaEnabled` y `agendaTopCard`. |
| `agendaOrder` en `configure_agenda` | Nada: no tiene efecto (la tarjeta de reserva está fijada arriba). |

<Warning>
  El texto escrito por visitantes o terceros (citas, reseñas, leads, la lista de
  espera y las páginas importadas) llega al agente como dato. Linkzee le indica al
  agente que nunca siga instrucciones que encuentre en él, y las herramientas que
  mueven dinero o cambian cuentas son solo con clave.
</Warning>
